# Anchor benchmark data

This directory preserves the complete four-anchor experiment directory from
`textpa/artifacts/anchor-benchmark` (copied on 2026-08-09). It includes raw
46-item JSONL responses and the corresponding finalized JSONL files for the
Luna max baseline, the four-anchor run, and the paper-model comparison runs.

The files are retained verbatim so the reported anchor experiment can be
audited after the disposable test environment is gone. The raw 50-item model
runs remain in `../llm-benchmark/`; no API keys are present in these files.
