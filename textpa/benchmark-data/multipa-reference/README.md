# MultiPA reference snapshot

This directory preserves the small public reference snapshot copied from
`textpa/artifacts/multipa-reference` on 2026-08-09:

- `annotation.csv` and the paper acoustic cues;
- the paper GPT-4o-mini and Gemini 2 Flash outputs;
- the downloaded `multiPA.zip` source bundle; and
- the reference audio sample used by the diagnostic smoke test.

The larger upstream checkout and model caches are intentionally excluded. The
source revision, download URL, and hashes needed to rebuild them are recorded
in the TextPA documentation and manifests.
