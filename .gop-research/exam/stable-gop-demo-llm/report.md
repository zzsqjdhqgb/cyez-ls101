# 低 GOP 数据的 LLM 整理结果

本报告把达到阈值的全部 GOP 音素行交给 LLM 归纳；LLM 看不到音频，以下不是自动判错。

- 输入：`/workspace/.gop-research/exam/stable-gop-demo/result.json`
- GOP 阈值：`gop_log_ratio <= -0.35`
- 送入 LLM：`15` 条
- 模型：`agnes-2.5-flash`

## LLM 总结

低 GOP 证据提示若干可关注的音素模式，主要涉及元音前移、清浊对立弱化及 /n/、/t/ 向 /l/ 的替换倾向，但部分证据存在对齐或自然变体可能，需结合复听确认。

## LLM 认为值得反馈或复听

### likely_issue

证据：GOP-0080, GOP-0012

"books" 的声母 /b/（AE 预期）在两次出现中均被声学模型更倾向于识别为清音 /p/，GOP 分别为 -6.51 与 -2.28，呈现一致的清化模式。

理由：两条证据同词同位、同向偏移，且 GOP-0080 差距较大（-6.51），说明 /b/ 的浊音特征在该语境下较弱，值得针对声母清浊对立的发声练习。

练习：朗读 "books" 时特意保持声带振动感，可在手触喉部时确认 /b/ 起始即有振颤，再逐步过渡到完整词中。

原始行：
- `GOP-0080` `books` 00:13.82-00:13.85: /b/ (B) -> /p/ (P)，GOP -6.508749
- `GOP-0012` `books` 00:02.56-00:02.58: /b/ (B) -> /p/ (P)，GOP -2.277763

### likely_issue

证据：GOP-0267

"advantages" 首音节 /æ/ 被识别为 /ʌ/（GOP = -7.63），元音开口度低于模型预期。

理由：GOP 差距显著，且 /æ/→/ʌ/ 是低频学习者常见迁移模式；同词另一音素 GOP-0268 也显示次低分（-3.97），提示该词整体元音空间可能偏紧。

练习：在镜子前练习 "ah" 音（如 cat、bad），把下颌明显下落、口腔开大；对比 "advantages" /ədˈvɑːntɪdʒɪz/ 首音的开口幅度。

原始行：
- `GOP-0267` `advantages` 00:38.67-00:38.69: /æ/ (AE) -> /ʌ/ (AH)，GOP -7.631584

### needs_listening

证据：GOP-0261

"to" 的元音预期为 /uː/，但声学Winner为 /eɪ/（GOP = -6.84）。

理由：差距很大，但 "to" 在非重读语境下常弱化为 [tə] 或 [də]，属合法语音变体；需人工复听以区分弱化现象与真实发音偏差。

练习：先用重读形式 [tuː] 清晰读出 "to"，确保唇形圆拢、舌位靠后；再与弱化形式 [də] 对比，体会同义词在不同位置的实际读音差异。

原始行：

证据：GOP-0102

"storage" 第二音节 /ɒ/（转写为 AH）被识别为 /iː/（GOP = -6.20），元音空间严重前移。

理由：GOP 差距明确，且 /ɒ/→/iː/ 属于跨度很大的元音替换，可能反映学习者在非重读音节中对元音区分敏感度不足。

练习：对比练习 "store" /stɔː/ 与 "steer" /stɪər/，把 /ɒ/ 的圆唇后舌位固定住；再读 "storage" 时把注意力集中在第二音节的后元音开口上。

原始行：

### likely_issue

练习：分开练习 "wan"（注意 /n/ 舌尖抵上齿龈的鼻音终点）和 "watch"（/t/ 的清晰塞音释放），再合并为 "want"；用最小对立体区分 /n/、/l/、/t/。

## 限制

- 所有证据均为 GOP 声学偏好信号，不代表已确认的发音错误。
- 无法听到音频，不能验证连读、弱读、方言变体或 ASR 对齐偏差的真实来源。
- "to" 的 UW→EY 大 GOP 可能是非重读弱化而非发音错误。
- "books" 的 B→P 清化在非重读词首位置存在自然语音学上的合法性。
- 部分证据间隔很近（如 want、best 的多条）可能共享同一段声学片段，独立性受限。
- 本反馈未考虑音高、重音、语调、语速等超音段维度。
- GOP 是模型内部声学证据，不是校准概率；低 GOP 可能来自模型混淆、强制对齐边界、
  连读/弱读或 ASR 临时文本错误。最终应复听原音频。
