# 低 GOP 数据的 LLM 整理结果

本报告把达到阈值的全部 GOP 音素行交给 LLM 归纳；LLM 看不到音频，以下不是自动判错。

- 输入：`/workspace/.gop-research/exam/stable-gop-demo/result.json`
- GOP 阈值：`gop_log_ratio <= -0.35`
- 送入 LLM：`15` 条
- 模型：`agnes-2.5-flash`

## LLM 总结

证据显示书类词汇中b/p辅音清化、最佳/任何词汇中的元音偏高倾向，以及want词汇内多个音素同时偏离预期，建议针对性练习；其余差异可能受连读、弱读或对齐边界影响，暂不直接报错。

## LLM 认为值得反馈或复听

### likely_issue

证据：GOP-0080, GOP-0012

books 一词两次均显示预期浊塞音 b 被声学证据识别为清塞音 p，且两者 GOP 均为较强负值。

理由：同一词首辅音在同一单词中出现两次相同方向的偏离，符合 b/p 清化重复模式，值得明确反馈。

练习：练习 b 时注意声带振动，可与 p 做最小对比（如 bad vs pad），在词首位置刻意加重浊音感。

原始行：
- `GOP-0080` `books` 00:13.82-00:13.85: /b/ (B) -> /p/ (P)，GOP -6.508749
- `GOP-0012` `books` 00:02.56-00:02.58: /b/ (B) -> /p/ (P)，GOP -2.277763

### likely_issue

证据：GOP-0267

advantages 的首音节预期为 æ，声学证据偏向 ʌ，GOP 为 -7.63，是本次最强的单条证据之一。

理由：元音 æ 与 ʌ 区分明显且 GOP 极低，不属于常见弱读或连读范围，具有教学价值。

练习：练习 advantages 首音节时，保持口腔开度更大、舌位更低，接近 '哎' 的开口元音，避免缩紧成 ʌ。

原始行：
- `GOP-0267` `advantages` 00:38.67-00:38.69: /æ/ (AE) -> /ʌ/ (AH)，GOP -7.631584

练习：练习 best 时，元音 ɛ 注意舌位略高于 æ 但低于 i，口腔开度适中；末尾 t 保持清晰的爆破感，避免摩擦成 s。

练习：分别练习 want 中的 n 和 t：n 强调舌尖抵上齿龈的鼻音爆破，t 保持清晰的气流爆破，避免滑向 l 的侧边气流。

## 限制

- 本整理仅基于 GOP 声学证据，未涉及音频本身，无法验证实际发音。
- 部分证据（如 to、me、books 词尾）可能受功能词弱读或词边界连读影响，不一定反映独立音素错误。
- same-word 内相反方向的偏移（如 best 的 t→s 与 s→t）提示模型对齐不确定性，已合并或暂缓处理。
- 交叉证据（如 best 与 any 的元音偏移方向一致）用于判断重复模式，但不构成对任何单一条目的额外证明。
- GOP 是模型内部声学证据，不是校准概率；低 GOP 可能来自模型混淆、强制对齐边界、
  连读/弱读或 ASR 临时文本错误。最终应复听原音频。
