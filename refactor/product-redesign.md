## 产品定位

一款面向中学英语教师的听说考试工具。核心价值是：**帮教师出卷、帮学生考试、帮教师批改**。

---

## 设计原则

1. **以用户任务而非内部数据模型组织界面**。教师打开软件时想的是"我要出一张卷子"或"我要批改"，而不是"我要操作草稿实体"。
2. **以试卷为唯一核心实体**。模板是创建试卷的快捷方式，草稿是未完成的试卷，作答是学生完成试卷的结果。所有事物围绕试卷展开。
3. **减少概念暴露**。`.cyexam`、`.cytmpl`、`.cydraft` 这些文件后缀是技术细节，用户只需知道"导出试卷文件"、"导入试卷文件"。

---

## 信息架构

侧边栏三个一级入口：

```
┌─────────────┐
│  试卷        │  ← 创建、编辑、管理试卷。考试也在这里发起。
│  批改        │  ← 导入作答、评分、导出成绩。
│  历史        │  ← 过往的考试作答记录，浏览和导出。
└─────────────┘
```

### 为什么这样设计

- **试卷**是教师工作的起点。创建试卷、预览试卷、让学生考试，都围绕试卷展开。
- **批改**是独立的高频任务。教师收集学生作答后，集中进行评分和导出。
- **历史**是被动查阅场景。教师偶尔需要回溯某次考试的作答情况，不需要频繁访问。

## 模块设计

## 一、试卷

### 1.1 试卷列表

试卷列表是默认首页。展示所有试卷，每张试卷卡片包含：
- 标题
- 题目数量
- 创建/修改时间
- 状态标签（草稿 / 已完成）

卡片操作：
- **预览**：以学生视角完整走一遍试卷（不录音，不出现在历史中）
- **编辑**：进入试卷编辑器
- **开始考试**：进入考试入场页面，供学生正式考试
- **导出**：导出为试卷文件，供其他电脑使用
- **删除**

顶部操作栏：
- **新建试卷**：从模板创建 / 空白创建
- **导入试卷**：从文件导入

### 1.2 新建试卷流程

点击"新建试卷"后弹出模板选择器：

- 展示所有可用模板，按分类标签（高考、中考、听力、口语等）分组
- 每个模板显示名称、描述、题目数量预览
- 支持预览模板结构（查看含哪些题型 section）
- 选择模板后进入编辑器；空白创建则直接进入空白编辑器

### 1.3 试卷编辑器

本质上是当前"草稿编辑"功能的升级版，但不再区分"模板"和"草稿"概念：

- **左侧**：试卷结构树（Section → Question 层级）
- **右侧**：当前选中题目的编辑面板

题目编辑：
- 5 种内容节点（文本、图片、视频、音频、四宫格图片）
- 3 种时间控制模式（倒计时、录音、内容控制）
- 每道题可设置状态栏提示文字
- 录音题可指定录音编号

试卷级操作：
- 设置试卷标题
- 设置评分标准（gradingInfo）
- **保存**（自动保存为草稿状态）
- **预览**（以学生视角播放整张试卷）
- **完成编辑**（标记为已完成，可正式使用）

### 1.4 导入/导出

- 导入：选择试卷文件 → 校验 → 加入列表
- 导出：生成试卷文件，可在其他电脑导入使用

---

## 二、考试（在试卷模块内发起）

### 2.1 考试入场

- 从试卷卡片点击"开始考试"
- 输入姓名和学号
- 麦克风选择和测试

### 2.2 考试过程

- 全屏模式，无侧边栏干扰
- 按题目顺序推进：准备（倒计时）→ 答题（录音）/ 播放（音视频）→ 自动切题
- 录音前后提示音
- 3:2 自适应等比缩放

### 2.3 考试完成

- 显示完成页面
- 作答自动保存在历史中

---

## 三、批改

### 3.1 导入作答

- 从文件导入学生作答包（单个或批量）
- 自动按试卷归类
- 已导入的同学生同试卷作答自动去重

### 3.2 批改列表

按试卷分组显示待批改作答：

```
试卷：2024 高考英语听说模拟
├── 张三  240001  未批改
├── 李四  240002  已批 3/5 题
└── 王五  240003  未批改

试卷：2024 中考英语听说模拟
├── 赵六  240004  未批改
```

勾选要批改的作答 → 点击"开始批改"

### 3.3 批改界面

分屏布局：
- **左侧**：当前题目内容 + 评分标准（可折叠）
- **右侧**：学生录音播放器 + 分数输入 + 评语文本框

操作流：
- 听录音 → 输入分数和评语 → 确认 → 自动跳到下一题
- 当前学生所有题批完后自动切换到下一个学生
- 可随时暂停，已打分自动保存

### 3.4 批改完成与导出

- 全部批完后显示结算摘要（每人得分汇总）
- 一键导出：
  - **CSV 成绩表**（Excel 可打开）
  - **PDF 成绩单**（每人一份 A4 报告）

---

## 四、历史

### 4.1 作答历史

- 列出所有在本机上完成的考试作答记录
- 按姓名、学号、试卷名称搜索
- 每条记录显示：学生姓名、学号、试卷名、考试时间、是否已批改
- 操作：
  - 导出作答文件（用于交到批改端）
  - 查看详情（播放录音）
  - 删除

---

## 模板管理（辅助功能，内嵌于试卷模块）

模板不在侧边栏中作为独立入口，而是作为"新建试卷"流程中的一个环节：

- 模板的导入/导出在试卷页面的设置或工具栏中
- 模板列表在"新建试卷 → 选择模板"时展示
- 这样的好处：用户不需要理解"模板"是什么概念——它就是"新建试卷时可以选择的一个起点"

---

## 对比原设计的改进

| 原设计 | 新设计 |
|--------|--------|
| 侧边栏 6 个入口（试卷、作答、创建试卷、批改、关于、开发者） | 3 个入口（试卷、批改、历史） |
| 模板和草稿是独立页面，用户需要理解三者的关系 | 模板是新建试卷的起点，草稿只是试卷的状态，用户不需要额外学习 |
| 四个自定义文件类型暴露给用户 | 统一为"试卷文件"和"作答文件"，概念减少 |
| 作答管理和批改管理分离 | 历史用于回溯查看，批改是独立工作流，各司其职 |
| 模板列表单独一个 tab | 模板选择器出现在新建试卷流程中，按需出现 |
| 批改列表是扁平的学生列表 | 批改列表按试卷分组，符合教师"改完一张卷子再改下一张"的心智模型 |
