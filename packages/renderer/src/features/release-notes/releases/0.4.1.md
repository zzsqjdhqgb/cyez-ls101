# 曹二听说101 v0.4.1

**Pre-release** · `v0.4.1` · 2026 年 8 月 · 自 `v0.4.0` 以来

0.4.1 是一次聚焦启动体验、内置内容和桌面交互的维护更新。

> **本次更新重点**
>
> - 优化应用启动和打包版本的加载速度
> - 修复上海中考口语对话的语音合成角色配置
> - 改进文本选择以及链接、图片的拖拽行为

## 启动与稳定性

- 更早显示启动窗口，并在后台初始化应用服务，缩短打开应用后的等待感。
- 启动时间较长时展示当前加载阶段，避免界面长时间没有反馈。
- 修复打包版本中后台 Worker 的路径处理，提升本地语音服务和数据处理任务的加载可靠性。

## 内置内容

- 更新上海中考口语题型和内置模板中的对话角色，使用当前语音模型支持的男声、女声音色。
- 避免使用中考口语内置内容生成试卷时，因不受支持的角色配置导致语音合成失败。

## 桌面交互

- 按钮、导航、装饰性文字等界面元素不再被意外选中。
- 报告、代码、文件路径、错误信息以及输入内容仍可正常选择和复制。
- 禁止将应用内的链接和图片意外拖出窗口，同时保留链接的正常点击行为。

## 升级说明

- 本版本没有更改 0.4.x 的数据和文件格式，可以从 0.4.0 直接升级。
- 升级前仍建议备份重要的试卷、模板、题型和作答数据。
