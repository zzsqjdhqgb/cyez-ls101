# 曹二听说101启动图标动效

## Motion brief

- 使用场景：桌面应用首次启动或冷启动，播放一次后停留在静态图标。
- 动效人格：专注、可靠、轻盈。
- 时长：1500 ms，共用单一时间轴。
- 审核页默认播放速度：1.0x；慢速模式为 0.35x。
- 源文件：`/workspace/output.svg`，1254 x 1254，VTracer 自动描摹稿。
- 最终帧：必须与 `logo.svg` 的静态渲染一致。

| `#headphone-arch` | 蓝色耳机弧 | 从左至右描画，建立“听” |

## Geometry decision

采用复杂度阶梯第 3 级：少量解析曲线与基本图元。`output.svg` 含 102 条 VTracer 路径，其中绝大多数是边缘抗锯齿和色差形成的碎片；最终稿只保留其主比例、旋流关系和扁平配色，并重拟合为圆角矩形、椭圆弧、圆角耳罩、麦克风曲线、三层少节点旋流和双层叶形。白色间隙使用真实负空间，不用细碎补色路径伪造。

曲线拟合没有追逐 VTracer 的像素级抖动。第一轮清理稿的 `IoU` 为 0.8987；根据覆盖差异仅收紧右侧耳机弧、麦克风弧和红色旋流右腹，第二轮提升到 0.9111 后停止。该版本在主要中心、端点、宽度和负空间上与源 SVG 对齐，同时保留可编辑、可分层动画的结构。

## Timeline

| 时间 | 阶段 | 画面 |
| --- | --- | --- |
| 0–300 ms | Anticipation 20% | 底板由轻微下沉、缩小和虚化状态进入；主图标保持预备姿态 |
| 210–900 ms | Action 50% | 耳机弧描画；金、橙、红三层旋流依次收拢；左右耳罩错峰吸附 |
| 660–1140 ms | Secondary action | 麦克风连杆描画，端头展开；叶形沿短弧进入 |
| 1050–1500 ms | Follow-through 30% | 主体小幅过冲、反向修正，最终精确落回静态 SVG |

## Principles

- Staging：先建立耳机和旋流主体，最后出现叶形点睛。
- Slow in / slow out：所有有限段使用显式 `cubic-bezier`，避免浏览器退回线性。
- Timing：1500 ms 启动段；大部件先动、细节后动。
- Follow through：左右耳罩、双旋流和叶形分别错开停止时间。
- Anticipation：底板和整体在前 20% 保持轻微下沉、缩小状态。
- Arcs：耳机与麦克风使用真实曲线路径，叶形用短弧位移。
- Appeal：动作取自图标自身的“听力 + 旋流”结构，不增加无关装饰。

## Easing tokens

- Enter：`cubic-bezier(0.16, 1, 0.3, 1)`
- Narrative：`cubic-bezier(0.34, 0, 0.14, 1)`
- Settle：`cubic-bezier(0.22, 1, 0.36, 1)`

这些 token 用于动画声明和文档；`@keyframes` 内使用对应的字面量，以确保 Chromium 实际应用分段缓动。

## Atomic studies

- Hover：整枚图标短距离抬升。
- Pulse：低幅度呼吸缩放。
- Arc：图标沿小弧偏转后归位。
- Press：快速按压并回弹。

## QA notes

- 几何验收优先级：平滑轮廓、语义结构、主要比例、像素差异。
- VTracer 生成的色边、微小补丁和像素级轮廓抖动不作为路径拟合目标。
- 动效不包含循环，启动完成后保持最终静态状态。
- 当前产物是独立审核稿，尚未接入 Electron renderer、preload 或 main process。

## QA results

| 项目 | 结果 |
| --- | --- |
| 第 1 轮，主轮廓清理 | IoU 0.8987；右耳机弧、麦克风弧和红色右腹偏宽，继续收紧 |
| 第 2 轮，局部收紧 | IoU 0.9111；宏观轮廓更接近，曲线平滑，接受 |
| SVG path audit | 金/橙/红/叶形分别为 11/10/9/5 个三次曲线段，0 个短碎段；角度警告均为旋流尖端、叶尖或有意转折 |
| 580–1000 ms 连续性 | 20 ms 步进中无冻结区间 |
| 最终帧契约 | `?static=1` 与 `?t=1500` 同管线像素差为 0 |

剩余差异来自主动平滑 VTracer 边缘、移除色边碎片，以及用独立动画部件替代单条超长复合路径；这些残差不通过增加节点追逐。
