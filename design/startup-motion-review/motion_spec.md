# 曹二听说101启动图标动效

## Motion brief

- 使用场景：桌面应用首次启动或冷启动，播放一次后停留在静态图标。
- 动效人格：专注、可靠、轻盈。
- 时长：1500 ms，共用单一时间轴。
- 审核页默认播放速度：1.0x；慢速模式为 0.35x。
- 源文件：`/workspace/icon1.png`，1254 x 1254 RGBA 图标。
- 最终帧：必须与 `logo.svg` 的静态渲染一致。

## Geometry decision

采用复杂度阶梯第 4 级：平滑轮廓路径。程序直接读取 `icon1.png` 的 HSV 色相，把图像分成蓝、黄、橙、红、绿五个最大连通色区；忽略原图明暗渐变，在 40% 测量尺度上用 Lanczos 抑制像素噪声，再由 Potrace 拟合三次贝塞尔。最终仅保留 5 条综合色路径，叶脉保留为绿色路径内部的真实白色负空间。

共比较 10 组 25%–75% 测量尺度和曲线参数。75% 版本整体 IoU 更高，但需要 209 个曲线段，并产生 27 个短段警告；最终选择 40% 版本，其整体 IoU 为 `0.985971`、五色平均 IoU 为 `0.977339`，共 105 个三次曲线段且没有切线角警告。这个选择牺牲约 0.004 的 IoU，换取明显更简洁、连续、适合动画的边缘。

蓝色耳麦在静态稿和最终帧中始终是一条统一路径。动效只拆分遮罩，不拆分蓝色填充：左右耳罩使用从连接点展开的椭圆遮罩，耳弧、麦杆和端头分别使用贴合真实中心线及实际宽度的描边遮罩。描边采用 `pathLength="1"` 和安全的 `1 1.2` dash 周期；圆头出现点藏在已揭示的耳罩或连接区域内。整个遮罩天然透明，不含背景矩形、渐变、扇形裁剪或跨轮廓的直线切口。

## Timeline

| 时间 | 阶段 | 画面 |
| --- | --- | --- |
| 0–300 ms | Anticipation 20% | 底板由轻微下沉、缩小和虚化状态进入；主图标保持预备姿态 |
| 60–780 ms | Action 50% | 左耳罩从最左端建立，耳弧沿中心线顺时针绘制；金、橙、红三层旋流依次收拢 |
| 690–1110 ms | Secondary action | 右耳罩从连接点展开，麦杆和话筒端头继续沿顺时针路径完成；叶形沿短弧进入 |
| 1050–1500 ms | Follow-through 30% | 主体小幅过冲、反向修正，最终精确落回静态 SVG |

## Principles

- Staging：先建立耳机和旋流主体，最后出现叶形点睛。
- Slow in / slow out：所有有限段使用显式 `cubic-bezier`，避免浏览器退回线性。
- Timing：1500 ms 启动段；大部件先动、细节后动。
- Follow through：耳麦揭示、三层旋流和叶形分别错开停止时间。
- Anticipation：底板和整体在前 20% 保持轻微下沉、缩小状态。
- Arcs：耳弧和麦杆的遮罩骨架直接跟随图标自身曲线，叶形用短弧位移。
- Appeal：动作取自图标自身的“听力 + 旋流”结构，不增加无关装饰。

## Easing tokens

- Enter：`cubic-bezier(0.16, 1, 0.3, 1)`
- Narrative：`cubic-bezier(0.34, 0, 0.14, 1)`
- Settle：`cubic-bezier(0.22, 1, 0.36, 1)`

这些 token 用于动画声明和文档；`@keyframes` 内使用对应的字面量，以确保 Chromium 实际应用分段缓动。

## Atomic studies

- Hover：整枚图标短距离抬升。
- Pulse：低幅度呼吸缩放。
- Arc：图标沿小弧偏转后归位。
- Press：快速按压并回弹。

## QA notes

- 几何验收优先级：平滑轮廓、语义结构、主要比例、像素差异。
- 原图渐变、抗锯齿色边和叶片绿色纹理不作为路径拟合目标。
- 动效不包含循环，启动完成后保持最终静态状态。
- 当前产物是独立审核稿，尚未接入 Electron renderer、preload 或 main process。

## QA results

| 项目 | 结果 |
| --- | --- |
| 第 1 轮，25% 测量尺度 | 整体 IoU 0.9796；叶片和内侧紧曲线损失较多，拒绝 |
| 第 2 轮，40% 测量尺度 | 整体轮廓 IoU 0.9866；语义分色 IoU 0.985971，接受 |
| 分色 IoU | 蓝 0.989477；黄 0.982289；橙 0.984328；红 0.982133；绿 0.948470 |
| SVG path audit | 蓝/黄/橙/红/绿分别为 40/21/18/16/10 个三次曲线段；0 个切线角警告；7 个短段都位于真实尖端或耳麦连接处 |
| 动画接缝检查 | 蓝色耳麦保持单一连续填充；五段语义遮罩沿真实结构顺时针交接，无渐变、扇形硬切或矩形拼缝 |
| 0–1160 ms 连续性 | 隔离蓝色通道后以 10 ms 步进扫描，显露面积单调增长，无 stall+pop 或倒退 |
| 最终帧契约 | `?static=1` 与 `?t=1500` 同管线像素差为 0 |

剩余差异主要来自扁平化原图渐变、忽略叶片绿色纹理、平滑抗锯齿边缘，以及对叶片小面积轮廓的简化；这些残差不通过增加节点追逐。
