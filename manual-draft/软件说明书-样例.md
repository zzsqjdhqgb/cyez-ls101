# 第 1 章 概述

## 1.1 编写目的

本说明书面向使用曹二听说101（以下简称「本软件」）的教师与教学管理人员，说明本软件的运行环境、安装方法、界面构成与各项功能的操作方法。

本说明书依据 V0.4.1 版本编写。界面文字、按钮名称与操作结果均以该版本实际运行结果为准。

## 1.2 软件简介

本软件是一款运行于桌面环境的英语听说考试工具，覆盖一次英语听说考试从内容准备到成绩产出的完整过程：编写评分标准与题型内容、制作试卷模板、生成可运行的试卷、组织考试并采集考生作答、导入作答进行评分，以及按批次结算并导出结果。

本软件把上述过程拆分为若干相互独立又彼此引用的功能模块，各模块的对象关系如下：

1. **评分单元**：定义答案结构、评分输入、分值与评分标准，是评分的依据。
2. **题型**：定义一类听说题目的字段构成与生成要求；一个题型下可以有多个**题组**，题组是题型的具体内容。
3. **试卷模板**：把题型、题组、评分单元、页面内容与时间线组织为可重复使用的制卷规则。
4. **试卷**：由试卷模板生成的、不可编辑的运行快照，用于组织考试。
5. **作答包与作答记录**：一次考试产生的原始作答数据，导入后成为作答记录。
6. **评分结果与结算批次**：对作答记录评分产生的结果，以及结果归组结算的单位。

本软件的全部业务数据保存在本机，并放在可配置的数据目录中，不依赖服务端系统。

## 1.3 主要功能

| 序号 | 功能模块   | 功能说明                                                                 |
| ---- | ---------- | ------------------------------------------------------------------------ |
| 1    | 工作台     | 汇总当前工作状态，提供制卷、考试与评分的快捷入口                         |
| 2    | 评分单元   | 新建、复制、编辑、导出评分单元，管理评分标准与分值                       |
| 3    | 题型库     | 编辑题型草稿并发布，维护题型下的题组，导入与导出题型                     |
| 4    | 试卷模板   | 编辑试卷模板与函数库，查看内置模板，按模板生成试卷                       |
| 5    | 试卷库     | 导入、查看、运行、导出与删除试卷                                         |
| 6    | 考试运行   | 登记考生身份，播放听力与口语题目，采集录音，生成并导出作答包             |
| 7    | 作答记录   | 查看与管理作答记录，进行人工评分或 AI 评分，处理评分抽查                 |
| 8    | 评分结算   | 按批次结算评分结果，查看评分报告，导出结算结果                           |
| 9    | 语音能力   | 内置语音合成；可选用语音合成、语音识别与发音评测扩展                     |
| 10   | AI 能力    | 可配置文本、图像、语音合成、语音识别与发音评测服务商，用于内容生成与评分 |
| 11   | 设置       | 存储位置、外观、许可、AI 服务商与应用信息                                |

# 第 2 章 运行环境

## 2.1 硬件环境

本软件在本地完成语音合成、语音识别与发音评测，对处理器、内存与磁盘有一定要求。

| 项目       | 最低配置             | 建议配置                     |
| ---------- | -------------------- | ---------------------------- |
| 处理器     | 64 位双核            | 64 位四核及以上              |
| 内存       | 4 GB                 | 8 GB 及以上                  |
| 硬盘空间   | 5 GB 可用空间        | 10 GB 以上可用空间           |
| 显示分辨率 | 1280 × 720           | 1440 × 900 及以上            |
| 音频设备   | 扬声器或耳机、麦克风 | 耳机（含麦克风）或独立麦克风 |

上表两列数值为按本地语音模型规模给出的估计值〔待确认：需按实机测量后填写〕。

说明：

1. 语音合成、语音识别与发音评测模型合计约占 4 GB 磁盘空间；业务数据、作答录音与结算结果的占用随考试规模增长。
2. 考试运行需要可用的麦克风。正式考试前应使用本软件提供的麦克风检测功能确认录音与回放正常。
3. 听力播放建议使用耳机，避免考场内扬声器串音。

## 2.2 软件环境

| 项目     | 要求                                                         |
| -------- | ------------------------------------------------------------ |
| 操作系统 | Windows 10 及以上 64 位系统〔待确认：是否声明 macOS / Linux〕 |
| 运行库   | 无需单独安装，安装包已包含全部运行库                         |
| 显示环境 | 系统默认显示设置；支持高分辨率屏幕缩放                       |

说明：

1. 本软件为桌面应用，安装包内含运行所需的全部组件，不要求用户另行安装浏览器、数据库或运行时。
2. 界面语言为简体中文。

## 2.3 网络环境

本软件的核心功能在完全离线的环境下可用。

| 功能                                 | 是否需要网络                                   |
| ------------------------------------ | ---------------------------------------------- |
| 评分单元、题型、模板、试卷、考试运行 | 不需要                                         |
| 内置语音合成                         | 不需要                                         |
| 语音识别、发音评测扩展               | 不需要（模型安装完成后本地运行）               |
| AI 内容生成与 AI 评分                | 需要，且需要在「设置 → AI 引擎」中配置可用服务商 |
| 激活方式意见征集页面                 | 需要                                           |

# 第 3 章 安装、启动与卸载

## 3.1 安装

本软件以安装向导方式安装。

1. 取得本软件的安装程序（文件名形如 `cyez-ls101-0.4.1-setup.exe`）〔待确认：实际发行文件名〕。
2. 双击安装程序，进入安装向导。
3. 按向导提示选择安装位置。默认安装位置为系统程序目录下的本软件目录，可改为其他位置。
4. 按向导提示确认是否创建桌面快捷方式，随后开始安装。
5. 安装完成后，向导提供运行选项，可直接启动本软件。

注意事项：

1. 安装过程不需要网络连接。
2. 安装位置建议使用本地磁盘，不要选择网络驱动器。
3. 覆盖安装新版本前，建议先备份业务数据，备份方法见第 14 章。

## 3.2 首次启动与激活

本软件需要激活后使用。

1. 启动本软件。未激活时，界面显示「激活曹二听说101」，见图 3-1。
2. 在「邀请码」输入框中填写邀请码，单击「激活并进入」。
3. 邀请码不正确时，界面提示「邀请码不正确，请检查后重试。」，可重新填写。
4. 激活成功后进入工作台。本机随后保存激活信息，再次启动不需要重新输入邀请码。
5. 如需了解其他激活方式，可在激活界面单击「参与激活方式意见征集」，在打开的页面中查看候选方案。

界面下方显示当前许可的有效期，格式为「临时许可有效期至 YYYY年M月D日 HH:MM（北京时间）」。

![图 3-1 激活界面](../tests/manual/baselines/FIG-ACTIVATION/default.png)

说明：

1. 激活信息保存在本机。软件许可存在有效期，到期后启动界面显示「使用权限已到期」，此时需要重新获取邀请码。
2. 如需在本机清除激活信息，可在「设置 → 许可」中单击「取消激活」，确认后本软件将删除本机激活信息并重新启动；其他业务数据不受影响。

## 3.3 启动过程

1. 启动本软件后，首先显示启动窗口，并在后台完成应用服务初始化。
2. 启动过程较长时，启动窗口显示当前加载阶段与进度。
3. 初始化完成后进入工作台。
4. 首次启动或版本更新后，界面显示「版本说明」对话框，说明本版本的更新内容与升级注意事项，见图 3-2。单击「关闭版本说明」关闭对话框后即可正常使用。

![图 3-2 版本说明对话框](../tests/manual/baselines/FIG-RELEASE-NOTES/default.png)

说明：版本说明对话框只能通过「关闭版本说明」按钮关闭，按 Esc 键或单击对话框外部不会关闭。

## 3.4 旧版本数据提示

在曾使用旧版本的数据目录中启动本软件时，本软件会对旧版本数据进行归档处理，见图 3-3。

1. 启动后界面显示「旧数据已归档」，并列出归档的旧数据目录数、文件数与数据量。
2. 可选择「导出旧数据」把归档文件保存到指定位置，或选择稍后处理。
3. 确认不再需要旧数据时，单击「清理并继续」，本软件删除已归档的旧数据目录并继续启动。

![图 3-3 旧数据归档提示](../tests/manual/baselines/FIG-LEGACY-ARCHIVE/default.png)

说明：

1. 归档文件保存在用户数据目录中，不随旧数据目录一起删除。
2. 归档与清理在确认后进行，未确认前不会删除任何旧数据。

## 3.5 卸载

1. 打开系统「设置 → 应用 → 已安装的应用」（Windows 10 为「控制面板 → 程序和功能」）。
2. 在列表中选择「曹二听说101」，选择卸载。
3. 按提示完成卸载。

说明：

1. 卸载只移除程序文件，不删除业务数据目录。如需一并清理，请在卸载前按第 14 章的方法找到数据目录并自行备份或删除。
2. 卸载不会删除已经导出的试卷包、作答包与结算结果文件。

# 第 5 章 工作台

## 5.1 功能说明

工作台是本软件启动后默认显示的页面，用于汇总当前工作状态并提供常用入口。工作台不修改任何数据，只读取并展示试卷、作答记录、题型、题组草稿、试卷模板与评分单元的当前情况。

## 5.2 界面组成

工作台自上而下分为四个区域，见图 5-1。

1. **产品区**：显示产品标识与一句英语摘句（含中文译文与作者），右侧为装饰性图形，不承载信息。
2. **快捷操作区**：三张快捷卡片。

| 卡片         | 副标题               | 单击后       |
| ------------ | -------------------- | ------------ |
| 制作试卷     | 基于模板生成听说试卷 | 进入试卷模板 |
| 进入试卷库   | N 份试卷可以运行     | 进入试卷库   |
| 处理作答记录 | N 份作答等待评分     | 进入作答记录 |

3. **当前状态区**：显示「试卷」「待评分」「题型」「试卷模板」「评分单元」五项统计数量。
4. **内容区**：左右两栏。
   - 左栏「最近工作」：列出最近处理的对象，最多 4 条，副标题为「继续上次未完成的内容」。条目显示对象名称与状态，试卷显示「可运行」，作答显示「已结算」「可结算」或「待评分」，模板显示「模板」。
   - 右栏「待处理」：显示作答评分进度，副标题为「作答评分进度」，包含待评分数量、「全部作答」数量、「已完成」百分比与「查看作答记录」按钮；下方列出「未完成题型」。

![图 5-1 工作台（首次启动，尚无最近工作）](../tests/manual/baselines/FIG-WORKBENCH/empty.png)

## 5.3 操作说明

### 5.3.1 查看当前工作状态

1. 启动本软件，或在侧边导航中选择「工作台」。
2. 在「当前状态」区查看试卷、待评分、题型、试卷模板与评分单元的数量。
3. 在「待处理」区查看评分进度与未完成题型。

结果：界面显示各项统计数量与评分完成百分比，用于判断当前应处理的工作。

### 5.3.2 从快捷操作进入功能模块

1. 在工作台「快捷操作」区选择需要的卡片。
2. 单击「制作试卷」，界面进入试卷模板；单击「进入试卷库」，界面进入试卷库；单击「处理作答记录」，界面进入作答记录。

结果：界面打开对应模块页面，可继续该阶段的操作。

### 5.3.3 继续最近的工作

1. 在工作台左栏「最近工作」中找到需要继续的对象。
2. 单击该条目。

结果：界面打开该对象对应的页面。例如单击一份试卷条目进入试卷库，单击一条作答条目进入该作答记录的评分界面。

### 5.3.4 查看并处理待评分作答

1. 在工作台右栏「待处理」区查看待评分数量与完成百分比。
2. 单击「查看作答记录」。

结果：界面进入作答记录页面，可以开始评分。

## 5.4 状态说明

| 状态         | 界面表现                                                                               |
| ------------ | -------------------------------------------------------------------------------------- |
| 加载中       | 快捷卡片副标题显示「正在汇总」，统计值显示「–」，「最近工作」显示「正在汇总最近工作...」 |

2. 工作台不提供页内重试入口，数据读取失败后可离开并重新进入该页面。
