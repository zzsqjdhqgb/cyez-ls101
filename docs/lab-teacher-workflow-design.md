# 机房教师端操作流程设计

状态：待审核，尚未实现。页面范围来自[功能设计](./lab-deployment-design.md)，字段和错误参见 [API 设计](./lab-server-api-design.md)及 [OpenAPI](./lab-server.openapi.yaml)。

## 1. 页面结构与连接隔离

激活通过后每次启动显示连接页。连接后固定导航为试卷、作答、设备、维护、服务设置；页头持续显示目标服务名称、地址、版本和模式。列表以紧凑表格、筛选栏、分页和选中操作为主；详情使用独立页或侧栏。页面不展示内部文件路径、token 或原始请求内容。

本机服务控制始终带本机标识，连接远程时也不能混淆本机和远程设置。首次信任先核对公钥，再发密码；失败展示实际原因。连接本机免密使用宿主认证证明，远程登录使用密码。

切换服务先取消读取与未发送操作，清除列表缓存、选择项和草稿，再建立新连接 epoch。正在进行的下载可提示用户完成或取消；已经发送的写操作可能成功，取消不等于撤销。写操作保留原 server ID、幂等键和目标，结果只更新原服务记录；不得以新服务凭证重试。原连接失败且结果不明时，重连原服务查询后再确定结果。

## 2. 各页面读取来源

| 页面/编辑操作 | 初次读取                                                                | 写操作与冲突恢复                                                |
| ------------- | ----------------------------------------------------------------------- | --------------------------------------------------------------- |
| 服务模式      | `GET /teacher/service` 的 modeRevision                                  | PUT mode 使用 expectedRevision；409 后刷新并展示阻塞原因        |
| 设备属性      | devices 列表或详情的 revision、number、room、seat、displayName、enabled | PATCH；冲突保留用户草稿并显示当前值，由教师再次决定，不自动覆盖 |
| 试卷上下架    | exams 列表或详情的 revision                                             | PATCH published；已删除则移除编辑入口                           |
| 服务设置      | settings 的 revision 和有效 limits                                      | PATCH；监听端口/目录等跳转本机能力，不走远程 PATCH              |
| 管理密码      | `GET /teacher/security` 的 revision                                     | PUT password；成功清除内存密码与会话，回到原服务登录页          |
| 清理确认      | cleanup 详情的 revision 与各设备 selectionDigest                        | POST confirm 提交固定选择；409 后重新预览当前状态               |
| 测试人工确认  | test-run 详情每设备 confirmation.revision（未确认初始 1）               | PUT confirmation；刷新版本后由教师重做决定                      |

数据读取区分初次加载、空结果、读取失败、已有数据刷新失败；失败不将统计清零。教师约每 5 秒刷新设备与维护汇总，后台页降低频率。选择集合只包含显式 ID，分页“全选”只选当前页；跨页选择保留数量，删除确认列出固定范围。

## 3. 入网与设备核对

1. 在维护页读取服务与开放批次。点击开启入网时选择有效期（默认 10 分钟），说明会进入维护；生成并先保存幂等键。
2. 原子创建批次与维护成功后展示到期时间、注册数和下载入口。下载同一文件不刷新有效期，过期或撤销后禁用下载。
3. 设备表按机房、版本、在线状态筛选；显示编号、计算机名、机房座位、激活观测、版本、练习阶段、三项作答统计、最后心跳时间。
4. 教师编辑编号或座位，成功后显示新 revision；学生下次心跳或查询同步。现场核对以学生最近同步时间和画面信息为准，不能把已注册但失联设备算作部署成功。
5. 关闭入网后继续维护；需要新增设备时创建新批次，不能复活过期秘密。

禁用确认说明将停止后续远程业务但本地活动作答保留；重置绑定单独确认设备编号与身份，提示需要重新入网、凭证撤销及任务失效。不能把重置绑定当作清空作答或更换设备归属。

## 4. 练习资料和作答

试卷上传显示传输与校验两个阶段，成功默认上架。同 package ID 同摘要提示已存在；不同摘要冲突不提供覆盖按钮。下架只影响新准入；删除确认说明已收作答和既有练习准入保留。

作答列表按试卷、姓名学号、设备、接收时机房及时间筛选，详情同时展示原设备标签快照与当前标签。单项下载保留原包；批量导出选择最多 500 个 ID，由宿主暂存并确认流完整后发布 ZIP。中断时显示失败，不把部分文件命名为最终成功文件。

批量删除确认列出所选数量与接收时间范围，使用固定 ID 和幂等键。结果逐项展示成功、已删除、失败；重试只针对失败或结果不明的原操作，不能重新拿实时筛选条件扩展范围。磁盘回收可能稍后完成，存储页区分逻辑删除与等待回收空间。

## 5. 维护、测试与退出检查

进入维护后禁止新的练习与正式收卷，在途作答结果仍需按回执协议确认。维护页展示活动练习、在线/离线设备、等待首次上传、结果未确认和异常数量及时间；三个数量分别展示，不相加。离线显示最后已知值，未知显示未知。

测试先选择设备和内置套件/用例，创建固定批次后显示逐设备逐项状态：待执行、运行、通过、失败、取消、超时、离线和待人工确认。声音实际可听与麦克风位置由人工确认，不能自动标记通过。重试失败项创建新批次，retryOf 指向原批次，原报告保留。

取消运行任务后显示“停止中”，直到收到停止结果或租约到期才结束阻塞。断线设备租约过期前不能认为已经停止；报告 late 不改变原取消或到期事实。

退出维护必须读取最新服务状态，并提交当前 modeRevision。仍开放的入网批次、未终结测试/清理、有效执行租约及备份处理中（`pending`/`running`）均为硬阻塞；按 [API 阻塞项](./lab-server-api-design.md#122-备份)定位详情。备份进入加密阶段后普通写入恢复，但仍需等待备份结束才能退出维护。离线设备、待上传和异常记录是检查信息，不自动清空，也不作为无条件禁止退出维护的理由。普通退出维护不等待所有本地练习结束；计划升级必须等待活动练习可靠保存后再安装。退出成功不触发自动开场。

## 6. 历史清理

创建页按机房过滤并显式选择设备、固定 submittedBefore 和 expiresAt。服务端生成预览任务，学生只读检查自己的全部历史，包括换绑前已成功提交的记录。详情按设备显示候选数量、字节数、快照摘要、更新时间和是否可确认。

未返回预览的设备不能纳入本次执行。教师可等待或明确排除，确认时发送计划 revision、所选 device ID 及各自 selectionDigest。确认后范围冻结；新产生历史不自动加入，不能通过更改日期扩大原任务。

执行结果展示 deleted、alreadyAbsent、skipped、failed 和实际字节数。部分失败不是全部成功；处理剩余项需要新计划、新预览及确认。取消只停止未来删除，已删除文件不能回滚；从确认页起明确展示此事实。

## 7. 设置、密码、备份和升级

服务名称、对外地址和传输限制可按 settings revision 热更新；改变对外地址仅影响新签发入网文件，不宣称已有学生自动迁移地址。监听端口、数据目录和自启动设置属于本机控制，远程连接时只说明需在服务机操作。

修改密码先读取独立安全 revision，提交后撤销所有教师会话。请求超时可能密码已生效，提示重新登录核实，不自动拿旧 revision 再改一次。重新登录不能把其他未完成写操作复制到当前页面再次执行。

创建备份要求维护且任务停止。密码输入仅在内存保存，创建请求发出后清空 UI；操作持久化幂等键。详情轮询 `pending`/`running`/`ready`/`failed`，`ready` 才可下载；备份处理中不能退出维护或领取冲突维护任务。失败展示原因，重新创建使用新键并重新输入密码。备份页展示快照时间及范围，说明恢复可能缺少快照之后的收卷数据。

升级检查流程：维护、关闭入网、停止任务、等待活动练习完成、检查异常与离线、完成备份，再在服务机停服务并运行安装器。恢复仅在本机停止/隔离服务时进行，先校验备份，确认将替换活动数据目录；不提供远程恢复接口，不要求学生历史自动补传。

## 8. 页面验收

每个编辑控件都有可读取的初始 revision；切换服务后旧响应不能污染新页面；空列表与失败明确区分；批量操作范围固定；维护退出阻塞可定位；人工测试确认不覆盖自动结果；清理不能包含没有成功回执的记录；回执结果不明不会显示收卷失败或自动新增提交。UI 自动化覆盖这些行为，现场补验远距离维护画面识别、声音与操作系统对话框。
