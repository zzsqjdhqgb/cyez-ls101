# 未保存的草稿修改受到保护

**所属内容：** 题型库 / 题型草稿编辑

## 什么时候使用

草稿编辑器不能因为返回列表或切换页面而静默丢弃用户正在编辑的题型定义。

## 前置条件

- 题型库中已有一个保存完成的题型草稿。

## 操作步骤

1. 打开已保存草稿，修改题型说明但不保存，然后返回草稿列表。

   完成后：应用提示离开会丢失未保存修改。

2. 在提示中选择“取消”。

   完成后：应用留在编辑器中，刚才的未保存说明仍然存在。

3. 再次返回并选择“放弃修改”，重新打开草稿。

   完成后：草稿恢复到上次保存的说明，未保存内容没有写入。

## 完成后

- 离开包含未保存修改的草稿前必须确认。
- 取消离开会保留编辑状态和未保存内容。
- 明确放弃后重新打开草稿只显示上次保存的内容。
