# 评分单元

评分单元是“一个题目如何收集答案、如何计算分数”的稳定契约。它不是某一份试卷里的临时评分备注，也不是评分结果本身。

## 它定义什么

- 题目类型：客观题、固定朗读、录音回答等；
- 学生答案结构：文本、录音以及系统自动捕获的答案索引；
- 题目输入：题干、参考文本、分析材料等模板变量；
- 满分、答案说明和评分标准；
- 可选的额外评分提示。

试卷模板引用评分单元。模板只保存引用和题目输入，实际评分单元的结构和评分约束来自保存时的版本。

## 生命周期

```text
新建评分单元 -> 编辑结构和说明 -> 保存（校验并立即生效）
评分单元 -> 被模板引用 / 被作答包记录 -> 评分与结算
```

- 新建或复制时直接填写完整内容，不再维护独立草稿库；
- 第一次保存时同时校验名称、答案结构、输入字段、分值和评分标准；
- 第一次保存后结构固定，后续只允许修改描述、分值和评分说明等数据；
- 内置评分单元完全只读，需要调整时复制并保存为“我的评分单元”；
- 删除评分单元前必须检查模板引用。删除不会改写历史作答中已经保存的评分单元快照。

## 用户操作顺序

1. 在“评分单元”新建并命名评分单元。
2. 选择题目类型和答案形式，添加必需输入与答案说明。
3. 填写满分、评分标准和可选的额外提示，保存即可使用。
4. 在题型模板编辑时选择评分单元，不在模板中临时改评分规则。

## 结果与边界

保存成功的评分单元可以被模板引用，也会被作答包以快照形式记录。评分单元页面不负责给某个学生打分；给分、评语和报告属于作答记录模块。
