# 试卷库

试卷库用于保存和管理已经生成、可以直接运行的试卷，是生成产物的仓库，不是试卷编辑器。

## 能力边界

试卷库只提供以下管理能力：

- 添加试卷；
- 删除试卷；
- 导出试卷。

试卷库不提供名称、题目、流程或其他试卷内容的修改能力。需要调整内容时，用户应回到对应的试卷模板完成修改，并重新生成试卷。

## 添加试卷

试卷支持通过以下两种方式加入试卷库：

- 在试卷模板生成流程完成后，执行“加入试卷库”；
- 从本地导入已有的试卷文件。

## 删除试卷

删除试卷是不可逆操作。用户执行删除时，必须经过二次确认后才能从试卷库移除试卷。

删除只移除试卷库中的试卷，不删除由该试卷产生的既有作答记录。作答记录作为历史结果独立保留。

## 导出试卷

导出试卷会生成一个完整、自包含的试卷文件。该文件可以再次导入试卷库，无需依赖原试卷模板或应用中的其他本地数据。

同一试卷可以重复导出。导出操作不改变试卷库内试卷的内容或状态。

## 运行入口

试卷库不设置试卷详情页。每份试卷在列表中直接提供“开始考试”主操作，并从该入口进入独立的考试流程。

“导出试卷”和“删除试卷”作为次要管理操作，不与“开始考试”争夺主操作层级。

开始考试后的行为由独立的[运行试卷并保存作答包](../../flows/take-exam/README.md)流程定义。
