# 运行试卷并保存作答包

本文档记录从试卷库开始运行试卷，直至把作答包保存到本地的已确认产品行为。作答记录是后续评分工作区中的管理对象，需要在“作答记录”模块单独导入这个作答包。

## 进入流程

用户通过试卷库中每份试卷的“开始考试”主操作进入独立的考试流程，不经过试卷详情页。

## 作答人信息

开始作答前，用户需要填写作答人信息：

- 姓名必填；
- 考生号必填。

系统为每次作答生成独立的唯一编号。考生号用于在作答记录和导出文件中识别本次作答，练习场景也应填写一个稳定的练习编号。

## 麦克风检查

麦克风检查是否出现由试卷内容决定：

- 试卷包含录音作答任务时，填写作答人信息后进入麦克风检查；
- 试卷完全不包含录音作答任务时，跳过麦克风检查并直接开始正式作答。

包含录音任务时，麦克风检查不可跳过。用户必须完成试录并确认回放声音正常，才能开始正式作答，以避免在作答结束后才发现录音不可用。

## 退出流程

退出行为以正式作答是否已经开始为界：

- 在填写作答人信息或进行麦克风检查时，退出会直接返回试卷库，不显示丢弃进度确认；
- 正式作答开始后，退出必须经过二次确认，并明确告知本次进度不会保存，也不会生成作答记录；
- 用户取消退出时，保留当前进度并继续作答；
- 用户确认退出时，丢弃本次进度并返回试卷库。

## 完成作答

试卷运行完毕后，系统生成完整作答包并打开系统保存对话框。用户必须选择保存位置并成功写入文件，才能进入考试完成页；取消保存或保存失败会停留在错误页，可以重试。

完成页只提供“完成”操作，结束本次播放器流程并返回试卷库。作答包文件是后续处理的输入，可以在“作答记录”中导入、导出、评分和结算。播放器不会替用户自动把文件导入作答记录，也不会在完成页隐式创建评分记录。

用户在完成页执行“关闭”后返回试卷库。

## 播放器模块边界

`ExamPlayer` 是独立的试卷播放器模块，不感知应用路由、试卷库、作答记录或本地文件对话框。它只负责：

- 加载并验证试卷；
- 收集作答人信息和完成必要的设备检查；
- 执行试卷时间线并收集答案；
- 生成完整作答包；
- 通过回调报告完成或退出。

应用宿主负责从试卷库加载试卷，并通过播放器现有的完成和退出回调处理：

- 通过保存回调把作答包写入用户选择的本地文件；
- 关闭流程并返回试卷库；
- 管理播放器所在的沉浸式路由。

播放器模块不得依赖应用路由、试卷库仓储或作答记录仓储。应用层保存方式和路由规则的变化不应侵入播放器核心运行逻辑。

## 正式作答

正式作答开始后，播放器严格按照试卷模板生成的时间线自动运行：

- 不提供暂停；
- 不提供返回上一步；
- 不提供跳过当前步骤；
- 用户只能完成当前步骤要求的作答，或通过确认后退出整场考试。

## 运行错误

音频播放或录音失败时，播放器立即暂停在当前时间线步骤：

- 保留此前完成的选择答案和录音；
- 显示具体错误原因；
- 提供“重试”和“退出”操作；
- 重试时重新执行当前步骤，不从试卷开头重新运行；
- 不允许静默跳过失败的播放或录音步骤。

加载和资源完整性错误在进入考试前处理，按完整预检流程重新加载，不属于时间线步骤重试。

时间线结束后的提交失败处理沿用播放器既有规则：等待宿主完成保存期间显示提交状态；保存失败时停留在错误页，并允许重试提交。
