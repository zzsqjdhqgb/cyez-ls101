# 题型库交互设计方向

> 状态：已确认，待实现。本文记录题型库仓储、题型编辑器、题组编辑器和题型文件交换的产品交互原则。实现和产品说明测试都必须以本文为依据。

## 题型与草稿

- 已发布题型提供“复制为草稿”入口；复制出的草稿与原题型没有运行时关联，后续修改和发布都不会改变原题型。
- 草稿和已发布题型继续保持当前两个独立视图，不把草稿强行改造成题型版本层级。
- 草稿可以保存不完整内容；发布前集中校验名称、生成要求和字段契约。
- 已发布题型不能直接编辑。需要修改时，先复制为草稿，再由用户决定是否发布新的稳定题型。
- 草稿可以确认后删除；删除草稿不影响已经发布的题型。

## 题组归属与内置迁移

- 题组属于创建它时使用的已发布题型。
- 非内置题型的题组不提供跨题型迁移。不同题型之间即使字段看起来相同，也不能静默搬迁题组。
- 内置题型使用稳定的 `builtinKey` 识别同一个产品题型。内置题型升级时，按照已设计的变量契约和资源迁移规则迁移题组；契约不兼容时必须进入内置升级处理流程。
- 题型文件导入不能把不认识的内置题型伪装成普通用户题型。接收设备不认识 `builtinKey` 或无法完成兼容迁移时，必须拒绝导入并说明原因。

## 题组身份与判重

题组 UUID 是题组身份，不是内容摘要。导入时遵守以下规则：

- UUID 不同，即使内容完全相同，也视为两个独立题组，可以同时存在；
- UUID 相同且题组名称、字段值、图片提示词、资源文件名和资源内容全部一致，视为已经存在，跳过写入；
- UUID 相同但任意内容不同，视为身份冲突，禁止导入和覆盖；
- UUID 已经属于另一题型时，不允许跨题型迁移，即使内容完全相同也必须拒绝；
- 判重不能使用更新时间解决冲突，也不能让用户选择“用文件覆盖本地”。同一个 UUID 的分叉必须保留为需要审查的数据冲突。

文件自身存在重复 UUID、题型内容摘要不匹配、资源缺失或资源损坏时，整个文件无效，不能进入选择导入页面。预览通过后到最终提交前必须再次执行判重；提交期间任何冲突都必须整体回滚。

## 全屏导出

导出题型时先进入全屏导出工作页，不直接弹出保存对话框：

- 页面显示题型名称、描述、是否为内置题型、`builtinKey` 和题组总数；
- 列出该题型下的全部题组，用户逐项勾选需要导出的题组；
- 每个题组的全部资源作为一个整体导出，不允许只导出题组文本而遗漏图片资源；
- 内置题型包必须携带 `builtinKey`、导出时的题型内容 ID、完整定义和所选题组；
- 用户确认后才打开保存位置并写出 `.lsinterface` 文件；取消不会产生文件。

## 全屏导入

导入题型时先选择文件，再在全屏导入工作页审查文件内容：

- 页面列出文件内的题型身份、内置标识、题型定义和全部题组资源摘要；
- 题组按“可导入”“已存在”“身份冲突”分组；可导入项默认勾选，已存在项显示完成状态且不可重复勾选，冲突项不可勾选并说明原因；
- 同 UUID 同内容显示为已存在并跳过，不把跳过误报为新导入；同 UUID 不同内容必须显示具体冲突原因；
- 不认识的 `builtinKey`、不兼容的内置变量契约、跨题型占用或损坏文件必须阻止对应导入；
- 用户确认后才提交选中的题组，提交成功后返回题型库并显示导入结果；取消不写入任何内容。

导入导出工作页是完整的用户任务，不是围绕文件对话框的技术包装。产品说明测试需要验证用户如何查看内容、作出选择、理解冲突和确认结果。
