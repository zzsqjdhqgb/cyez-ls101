# 从零准备题型内容

这条用户旅程验证用户不依赖预置业务数据，通过界面完成“题型草稿 -> 稳定题型 -> 可复用题组”的连续内容准备工作。

## 旅程边界

- 从全新的应用数据目录开始，不预先写入用户题型、题型草稿或题组；
- 所有核心业务对象都通过用户可见界面创建；
- 刚发布的稳定题型必须被后续题组创建步骤真实使用；
- 保存后的题组需要从题型详情重新进入，以验证它已经持久化；
- 发布后保留原草稿，方便后续继续演进题型定义。

这条旅程不覆盖 AI Provider 配置、AI 生成题组、JSON 覆盖和异常恢复。这些替代路径或局部规则由独立产品行为验证。
