# 模块文档迁移核验记录

把 `docs/product/modules/**` 的旧设计约束迁移到 [`../ui/modules/`](../ui/modules/README.md) 时，逐条对照 v0.4.1 代码核验。
下表记录**旧产品文档中在当前版本不成立的说法**。旧层已弃用，不再修改；其结论以本表和 `docs/ui/modules/**` 为准。

| 主题 | 旧说法 | v0.4.1 实际 | 新文档处置 |
| --- | --- | --- | --- |
| 试卷库 | 提供导出试卷 | 试卷库界面只有开始考试与删除；仓储的 `exportArchive` 仅供内部运行已保存试卷；自包含文件导出在试卷模板生成流程 | `ui/modules/exam-library.md` 按实际描述 |
| 作答记录 | 批次是成绩表和报告的导出单位 | 没有批次级导出；批次只是分组容器，报告是单条模态，导出是单条归档 | `ui/modules/submission-records.md` 按实际描述 |
| 作答记录 | 首版语音识别只提供内置 Qwen3 ASR | 同时支持在线 `openai-compatible` 与本地 `qwen3-asr` | 同上；`engineering/features/ai-router.md` 已修正 |
| 作答记录 | 语音纠错当前是测试占位结果，不进行真实发音分析 | 应用流程使用真实 AIRouter 发音评测（Wav2Vec2 音素 CTC）；`grading-engine` 中的占位实现存在但未被应用使用 | 同上；`engineering/features/ai-grading.md` 已描述真实流程 |
| 作答记录 | 抽查规则使用可扩展注册结构 | 固定两条规则（整场总题数、按 `schemaId`），没有扩展注册点 | 同上 |
| 设置 | 关于页包含运行环境信息 | 只显示名称、版本、发布说明、团队与许可 | `ui/modules/settings.md` 按实际描述 |
| 设置 | 设置分区为外观、AI 引擎、关于 | 实际注册存储、许可、AI 引擎、外观、关于 | 同上 |
| 设置 | 生成或评分任务使用任务启动时确定的模型 | 仅 AI 评分会话已验证；生成侧无证据 | 模块文档把结论限定为评分会话 |
| 设置 | 手动图片 Provider 是无 API 配置时的后备入口 | 仅作为一种可选 Provider 类型与一个导入对话框，未按"无 API 后备"约束 | 按实际描述 |
| 题型库 | 不兼容的内置变量契约必须阻止导入 | 导入只校验未知 `builtinKey`、跨题型占用与包结构，没有变量契约兼容校验 | 模块文档按实际描述 |
| 题型库 | 导入审查页展示题型定义 | 只展示名称、内置身份、数量与逐个题组的资源摘要，不展示描述与字段结构 | 同上 |
| 题型库 | 提交成功后显示导入结果 | 只有通用成功提示，导入与跳过明细未展示 | 同上 |
| 题型库 | 题组 UUID 在"复制"中保留 | 不存在题组复制或派生操作 | 同上 |
| 评分单元 | 删除前必须检查模板引用 | 删除不做引用检查，仅确认文案提示引用该评分单元的模板将校验失败 | 同上 |
| 评分单元 | 不再维护独立草稿库 | 草稿库路由与页面仍注册且可用，仅用于读取历史数据；主流程不再创建 | 同上 |

## 遗留措辞

- `docs/engineering/features/ai-grading.md` 中 "`free-speech` 只使用通用转写和占位纠错流程" 的表述可以更精确：
  `free-speech` 走同一个真实评测接口，只是没有参考文本、不执行逐音素对齐。
- 旧 `docs/archive/design/interface-editor.md` 等设计稿中的实例 JSON 字段与当前实现存在差异，属预期（档案层）。
