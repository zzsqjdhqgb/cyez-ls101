# 试卷模板

试卷模板是可编辑的制卷规则，负责把页面、时间线、题型题组、评分单元和资源组织成一份考试结构。它不是一次运行的试卷。

## 模板与试卷的区别

| 对象       | 是否可编辑 | 内容                                                  | 用途               |
| ---------- | ---------- | ----------------------------------------------------- | ------------------ |
| 试卷模板   | 是         | 页面结构、题型/题组引用、评分单元引用、时间线、函数库 | 反复制卷和维护规则 |
| 可运行试卷 | 否         | 模板在某次生成时解析后的题目、资源和评分上下文        | 启动考试           |

生成完成后，试卷是自包含快照。后续修改模板不会改变试卷库中已经生成的试卷。

## 模板编辑顺序

1. 在模板库新建模板并填写名称和说明。
2. 在结构树中创建页面和页面顺序。
3. 为页面添加文字、图片、选择题视图或题型调用。
4. 为题型调用绑定已发布题型和题组，为题目输入绑定评分单元所需变量。
5. 为页面配置播放、倒计时、录音等时间线动作。
6. 使用结构视图、页面视图和预览检查内容与播放顺序。
7. 明确保存。离开有未保存修改的编辑器时必须选择继续编辑或放弃修改。
8. 从保存后的模板进入“生成试卷”，在生成设置中确认题组和语音配置。

## 引用与校验

- 模板只允许引用已发布、结构契约匹配的题型和评分单元；
- 被删除或结构不兼容的引用会使模板不可生成，错误必须指出具体节点；
- 生成前系统保存模板当前修改，生成依据只能是最后一次成功保存的版本；
- 内置模板不可直接编辑或删除，需要复制为本地模板后维护。

## 生成结果的保存

生成结果页提供两个互不替代的后续动作：加入试卷库，或导出自包含 `.lsexam` 文件。至少完成其中一个保存动作后才能无确认关闭结果页；未保存结果离开时必须确认丢弃。

## 待补充的自动证据

模板创建、题组和评分单元引用、预览保存、缺失引用校验需要独立的 Playwright 产品文档行为覆盖。
