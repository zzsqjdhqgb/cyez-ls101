# 评分单元

评分单元是“一个题目如何收集答案、如何计算分数”的稳定契约。它不是某一份试卷里的临时评分备注，也不是评分结果本身。

## 它定义什么

- 题目类型：客观题、固定朗读、录音回答等；
- 学生答案结构：文本、录音以及系统自动捕获的答案索引；
- 题目输入：题干、参考文本、分析材料等模板变量；
- 满分、答案说明和评分标准；
- 可选的额外评分提示。

试卷模板引用已发布的评分单元。模板只保存引用和题目输入，实际评分单元的结构和评分约束来自发布时的稳定版本。

## 生命周期

```text
新建草稿 -> 编辑结构和说明 -> 保存草稿 -> 校验发布 -> 稳定评分单元
                                      \-> 校验失败：留在草稿
稳定评分单元 -> 被模板引用 / 被作答包记录 -> 评分与结算
```

- 草稿可以保存不完整内容，便于分阶段设计；
- 发布前必须同时校验名称、答案结构、输入字段、分值和评分标准；
- 发布会创建新的稳定评分单元 ID，原草稿保留；
- 已发布评分单元不能直接改变结构。需要调整时复制为新草稿，再发布新版本；
- 删除评分单元前必须检查模板引用。删除不会改写历史作答中已经保存的评分单元快照。

## 用户操作顺序

1. 在“评分单元”进入“草稿”，新建并命名草稿。
2. 选择题目类型和答案形式，添加必需输入与答案说明。
3. 填写满分、评分标准和可选的额外提示，保存草稿。
4. 执行“发布”，阅读发布后得到稳定契约且草稿保留的说明。
5. 在题型模板编辑时选择已发布评分单元，不在模板中临时改评分规则。

## 结果与边界

发布成功的评分单元可以被模板引用，也会被作答包以快照形式记录。评分单元页面不负责给某个学生打分；给分、评语和报告属于作答记录模块。

## 待补充的自动证据

评分单元创建、校验、发布、复制草稿和引用保护需要单独的 Playwright 产品文档行为覆盖。
