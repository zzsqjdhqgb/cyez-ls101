# 从结构草稿填写评分资料并发布稳定评分单元

**所属内容：** 评分单元 / 评分单元发布

## 什么时候使用

评分单元先以可保存的结构草稿存在，发布时补齐面向用户的名称、说明和答案解释，生成稳定契约并保留原草稿。

## 前置条件

- 评分单元库为空，用户需要创建第一个评分单元。

## 操作步骤

1. 进入“评分单元”，新建并命名一个草稿库，然后在其中新建结构。

   完成后：应用打开一个可以继续编辑的未命名结构草稿。

2. 为结构草稿命名，确认题型，并选择“保存”。

   完成后：页面提示结构草稿已经保存。

3. 选择“发布正式版”，填写正式名称、描述和答案说明，然后确认发布。

   完成后：发布前会说明结构将被冻结；确认后页面提示正式评分单元已经发布。

   ![发布前补齐名称、描述和答案槽位说明](./assets/GS-01/publish-data.png)

   _作出选择时：发布前补齐名称、描述和答案槽位说明_

4. 返回评分单元列表，再进入原草稿库。

   完成后：正式评分单元可以使用，原结构草稿也仍然保留。

   ![正式评分单元发布后，结构草稿仍可在草稿库中找到](./assets/GS-01/published-and-draft.png)

   _完成后：正式评分单元发布后，结构草稿仍可在草稿库中找到_

## 完成后

- 创建草稿库和结构草稿不会直接产生正式评分单元。
- 发布对话框要求补齐正式名称、描述和答案槽位说明。
- 发布成功后正式评分单元和结构草稿都保留，可以分别进入。
