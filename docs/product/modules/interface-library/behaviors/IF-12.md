# 删除非空字段组前需要确认

**所属内容：** 题型库 / 题型草稿编辑

## 什么时候使用

删除字段组会同时删除其子字段，属于需要明确确认的破坏性编辑操作。

## 前置条件

- 草稿编辑器中已有一个包含字段的字段组。

## 操作步骤

1. 新建草稿，添加字段组“lesson”，再在组内添加字段“question”。

   完成后：字段树显示一个包含子字段的字段组。

2. 选中“lesson”并选择删除节点。

   完成后：应用提示字段组及其所有子字段将一并删除。

3. 取消删除确认。

   完成后：字段组和子字段仍然存在。

4. 再次选择删除节点并确认删除字段组。

   完成后：字段组和其中的“question”同时从字段树消失。

## 完成后

- 删除非空字段组时明确说明子字段也会被删除。
- 取消确认不会改变字段树。
- 确认后字段组及其子字段一起从当前草稿移除。
