# 未保存的题组修改受到保护

**所属内容：** 题型库 / 题组编辑

## 什么时候使用

手工修改不会静默保存；离开编辑器前可以继续编辑或明确放弃本次修改。

## 前置条件

- 已经创建一个尚未填写内容的题组。

## 操作步骤

1. 修改题组内容但不保存，然后选择返回题型详情。

   完成后：应用提示离开将放弃未保存的修改。

   ![离开前明确提示未保存修改会被放弃](./assets/IF-03/unsaved-confirmation.png)

   _作出选择时：离开前明确提示未保存修改会被放弃_

2. 在提示中选择“取消”。

   完成后：应用返回编辑页面，并保留刚才尚未保存的内容。

3. 再次返回，并明确选择“放弃修改”，然后重新打开该题组。

   完成后：题组只显示上次保存的内容，不包含已经放弃的修改。

## 完成后

- 离开包含未保存修改的题组前必须确认。
- 取消离开保留编辑状态，放弃修改不会写入题组。
