# 发布前定位草稿字段校验错误

**所属内容：** 题型库 / 题型草稿编辑

## 什么时候使用

草稿可以先保存不完整内容，但发布必须明确指出具体字段需要修正的位置。

## 前置条件

- 题型库中没有需要继续编辑的本地草稿。

## 操作步骤

1. 新建草稿，填写名称、说明、生成要求和字段标识，但故意不填写变量名。

   完成后：草稿可以保存，编辑器保留这个尚未完成的字段。

2. 选择“发布”并确认发布题型。

   完成后：页面显示“变量名不能为空”，并标明错误字段路径；题型不会被发布。

3. 从校验错误进入字段，填写变量名后再次发布并确认。

   完成后：题型发布成功，进入稳定题型详情。

## 完成后

- 发布校验失败时，草稿内容不会被发布或静默修正。
- 错误消息关联到具体字段，用户可以直接回到该字段修正。
- 修正字段后可以再次发布，得到稳定题型。
