# IF-05 从草稿发布稳定题型并保留草稿

**归属：** 题型库 / 题型发布

## 行为意图

题型草稿可以不完整地保存；发布前说明稳定契约，发布成功后已发布题型和原草稿同时保留。

## 前置条件

- 用户从题型库的“草稿”视图开始创建题型。

## 用户路径

1. 在题型库切换到草稿视图并新建题型
2. 填写题型基本信息、生成要求和字段契约
3. 发布前明确说明将生成稳定题型并保留当前草稿

   ![发布前说明稳定题型与原草稿的关系](./assets/IF-05/publish-confirmation.png)

   _决策证据：发布前说明稳定题型与原草稿的关系_

4. 发布成功后可以查看稳定题型，并能在草稿视图找到原草稿

   ![发布后原题型草稿仍保留在草稿视图](./assets/IF-05/retained-draft.png)

   _结果证据：发布后原题型草稿仍保留在草稿视图_

## 行为保证

- 发布前明确说明将创建稳定题型，并保留当前草稿。
- 发布成功后，稳定题型和原草稿可以分别找到。
