# 题型库

本文档记录题型库已经确认的产品定位、对象关系和用户可见行为。

## 模块定位

题型库是试卷内容的生产与复用中心。它管理两类对象：

- **题型**：规定一类内容需要哪些字段，以及 AI 应如何生成这些内容；
- **题组**：按照某个题型填写的一套具体内容，可以在生成试卷时复用。

题型定义属于低频维护，创建、检查和调整题组是日常主线。试卷模板只引用已经发布题型的稳定字段契约，并在生成试卷时从对应题型的题组中选择内容。

## 对象生命周期

题型草稿允许保存不完整内容。用户发布草稿时，系统先保存草稿，再校验名称、生成要求和字段结构；校验通过后生成不可直接修改的稳定题型。

- 发布不会删除草稿；
- 已发布题型不能直接修改；
- 修改已发布题型时，需要先复制为新草稿；
- 题组始终属于创建它时所使用的已发布题型；
- 删除草稿不会影响已经发布的题型；
- 内置题型与用户发布的题型使用相同的题组工作流。

## 题型库首页

题型库首页使用“题型”和“草稿”两个视图：

- “题型”是默认视图，展示题型名称、题组数量、描述和内置来源；
- “草稿”展示尚未发布或继续维护的题型草稿；
- 用户可以直接从草稿视图新建题型草稿；
- 导入题型属于题型视图的次要操作；
- 每个列表项使用一个明确的主要进入方式，不重复提供标题链接和“进入”按钮。

## 题型详情

题型详情使用“题组”和“题型定义”两个视图。

### 题组

“题组”是默认视图，负责题组的创建、进入和删除。用户点击“新建题组”后先完成创建设置：

1. 填写必填的题组名称；
2. 选择“手工填写”或“AI 生成”；
3. 确认后系统才正式创建题组并进入编辑器；
4. 取消创建不会留下空题组；
5. 选择“AI 生成”时，编辑器直接打开整组生成任务，但不会自动发起 AI 请求。

### 题型定义

“题型定义”展示题型描述、生成要求和字段结构。复制为草稿、导出题型、复制提示词和复制 JSON 结构等低频维护操作只在该视图提供，不与题组日常操作竞争。

## 题组编辑

题组编辑器以手工编辑为基础，同时提供整组 AI 生成、JSON 覆盖和图片生成能力。

- 手工修改需要用户明确保存；
- 有未保存修改时，所有离开页面的方式都需要提示；
- 题组包含图片字段时，图片提示词和图片必须同时存在才能保存；
- 单个图片字段可以选择文件、读取剪贴板或调用 AI 生成；
- 批量 AI 生图只处理已经填写图片提示词的字段；
- AI 整组生成和 JSON 导入都会原子覆盖整组内容并立即保存；
- 对已有内容执行整组覆盖前，系统必须明确说明覆盖范围并再次确认；
- AI 或 JSON 校验失败、任务失败或用户取消时，原有题组内容保持不变。

界面使用“AI 生成并覆盖”和“从 JSON 覆盖”表达上述语义，不使用可能被理解为追加内容的模糊文案。

### 辅助操作的界面语义

题组表单是页面中唯一持续存在的编辑工作区。AI 整组生成、JSON 覆盖和批量生图都是一次性任务，使用模态对话框，不作为会挤压或与主表单并行编辑的侧边栏。

AI 整组生成的生命周期为：

1. 选择文本模型和必要的图像 Provider；
2. 已有内容时再次确认覆盖范围；
3. 运行期间锁定底层编辑，可以显式取消任务；
4. 生成、校验和保存全部成功后才替换题组；
5. 结果态可以返回题组或重新生成；
6. AI 返回无效内容时，可进入 JSON 对话框检查原始结果。

JSON 覆盖的生命周期为：

1. 打开对话框后粘贴完整 JSON；
2. 校验失败时保留对话框、输入和字段错误，题组保持不变；
3. 取消时丢弃本次临时 JSON 和校验错误；
4. 校验通过并确认覆盖后，整组替换、保存并自动返回题组。

## 题型草稿编辑

草稿编辑器分别维护题型基本信息、生成要求和字段结构。

- 字段树中的字段组可以展开和折叠；
- 添加字段或字段组时，界面明确显示内容将被添加到哪个层级；
- 字段标识无效或冲突时就地显示原因，不静默恢复；
- 删除包含子节点的字段组前需要确认；
- 发布校验结果需要关联到具体表单或字段节点；
- 发布操作明确说明发布后得到稳定题型，且当前草稿仍然保留；
- 有未保存修改时，所有离开页面的方式都需要提示。
