# 工作台与导航

工作台是应用首页和产品封面，负责汇总当前工作状态并提供常用操作入口。

## 能力边界

工作台提供：

- 产品各项能力的快捷入口；
- 最近状态和重要信息的汇总；
- 最近工作和待处理事项的承载区域。

工作台不拥有独占业务能力。工作台中出现的每个操作，都必须能够从对应一级模块独立进入和完成。

工作台不是教师或学生角色的门户，也不改变其他模块的权限或可见性。

## 一级导航

一级导航持续提供工作台、试卷库、作答记录、题型库、试卷模板、评分单元和设置的独立入口。快捷入口不能替代一级导航，也不能成为某项业务能力的唯一入口。
