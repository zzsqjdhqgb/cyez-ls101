# 运行考试并移交作答

本旅程说明用户已有一份可运行试卷时，如何完成作答人登记、运行考试、保存作答包，并把同一份作答交给作答记录继续处理。

## 起点

- 用户已经取得一份可以导入 LS101 的试卷包。
- 试卷运行不需要在开始前检查麦克风。

## 终点

- 作答人完成试卷，作答包成功保存到本地。
- 本次运行产生的作答包已经通过界面导入作答记录。
- 作答记录保留本次考试的试卷名称、作答人姓名和考生号，可以继续评分和结算。

## 边界

- 本旅程从已经存在的可运行试卷开始，不说明试卷如何制作和生成。
- 本旅程验证作答包从考试运行到作答记录的真实移交，不用预置作答包替代中间产物。
- 录音设备检查、包含录音的完整考试、异常退出恢复和后续评分结算不属于本旅程。
