# 文本选择交互规则

> 状态：已确认并实现。本文是 renderer、exam-player 和 page-renderer 中文本选择行为的统一依据。

## 目标

鼠标拖动是桌面应用中的常见误操作来源。应用的导航、按钮、标签页、卡片入口、拖动控件和纯展示状态不应在点击或拖动时产生蓝色选区；用户输入、复制和审查所需的正文必须保留选择能力。

## 默认规则

以下元素默认不可选中：

- 所有 `button`；
- `role="button"`、`role="tab"` 和 `role="option"` 元素；
- 原生 `summary` 展开标题；
- 图片及图片占位内容，且图片不允许被浏览器拖拽；
- 所有应用内链接禁止原生拖拽到窗口外；链接文字仍可选择和复制；
- 侧边栏导航、标题栏、启动界面和考试播放器外壳；
- 模板编辑器中的节点、页面画布、缩放/调整尺寸控件和预览胶片；
- 选择题选项、评分方式卡片、设置入口、列表行和批次折叠标题；
- 分栏拖动手柄及其他通过指针操作的控件；
- 纯状态内容：进度、倒计时、状态徽章、步骤指示、空状态和装饰性标题；这些区域由所属页面样式按交互需要局部禁选，不通过应用根节点全局禁选。

通用控件优先通过基础样式实现，不要求每个按钮重复添加类名。非语义交互元素必须使用现有交互类或显式添加 `user-select: none`。

## 必须保持可选

以下内容必须允许用户选择和复制：

- `input`、`textarea`、`select` 的用户输入和选项文本；
- JSON、JSON Schema、提示词、代码、字段 ID、节点 ID 和其他 `code`/`pre` 内容；
- 文件系统路径、错误详情、任务日志和诊断信息；
- 评分材料、学生答案、语音识别文本、评分标准和 Markdown 报告；
- 题干、说明、描述等非交互正文；
- 外部链接或报告中的链接文字。

表单控件位于不可选中的标签或面板内时，控件本身仍需显式恢复 `user-select: text`。新增需要复制的展示区域时，应优先使用现有正文/代码样式，必要时在局部样式中写 `user-select: text`，不得依赖父元素的默认值。

## 三个样式域

### 主渲染层

`packages/renderer/src/styles/global.css` 负责通用语义控件和图片的默认规则。页面专属 CSS 负责非语义卡片、拖拽手柄和侧边栏等区域。主渲染层不在应用根节点全局禁选；普通正文、错误提示、路径和报告保留选择能力。

### 考试播放器

`packages/exam-player/src/ExamPlayer.module.css` 负责考生登录、设备检查、考试状态栏和播放器操作；播放器根节点默认不可选，姓名/考生号输入恢复可选。

### 页面渲染器

`packages/page-renderer/src/PageRenderer.module.css` 和 `packages/exam-player/src/ExamPageView.css` 的页面舞台是视觉渲染区域，默认不可选。页面中的单选输入仍可交互；编辑器画布的选择、移动和缩放由模板编辑器样式单独控制。

## 明确不采用的规则

- 不在 `body` 或应用内容根节点上全局设置 `user-select: none`；
- 不通过禁用右键或覆盖浏览器选择行为来实现；
- 不禁止报告、错误、日志、路径和 JSON 的复制；
- 不把可编辑输入字段改成不可选文本。

## 新增页面检查清单

1. 新增按钮、页签、菜单、卡片入口或拖动控件时，确认它落在通用语义选择器或交互类中。
2. 新增正文、错误、路径、日志或代码时，确认它没有继承不可选规则，并补充 `user-select: text`（如有必要）。
3. 新增图片时设置 `draggable={false}`；全局图片规则会阻止选择和拖动。
4. 新增链接时保留文字选择能力，但必须阻止原生拖拽（全局 CSS 或 `draggable={false}`）。
5. 修改考试播放器或页面渲染器后，运行对应的集成测试和 `xvfb-run -a yarn test:smoke`。
