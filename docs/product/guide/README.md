## 阅读方法

- 第一次使用时按章节顺序阅读，先理解对象关系，再进入具体操作。
- 只处理某个阶段时，直接进入对应章节；每条旅程和行为都链接到保证、截图和可执行测试。
- 完整旅程不通过仓储预置核心业务对象；产品行为可以声明并构造自己的前置状态。
