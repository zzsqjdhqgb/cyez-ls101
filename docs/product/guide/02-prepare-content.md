# 2. 准备评分标准与题型内容

[上一章：认识 LS101 与完整工作流](./01-understand-ls101.md) · [返回指南](./README.md) · [下一章：制作模板并生成试卷](./03-build-generate-exam.md)

## 这一阶段要完成什么

先建立稳定的评分单元和题型契约，再准备可被试卷模板复用的具体题组。

## 为什么需要这一步

评分单元决定收集什么答案以及如何给分，题型决定内容字段，题组则提供每次制卷所用的实际材料。

## 开始前准备

- 考试的题目类型、答案形式、满分和评分标准。
- 用于出题的文字、图片和参考答案。

## 已验证用户旅程

### 1. 从题型草稿发布稳定题型并创建可复用题组

从全新的应用数据目录开始，通过界面定义并发布题型，再用刚发布的题型创建、保存和重新打开一套具体题组。

**开始前：**

- 没有预先创建的用户题型、题型草稿或题组。

**操作顺序：**

1. 从题型库草稿视图新建题型
2. 填写题型说明、生成要求和字段契约并保存草稿
3. 确认发布稳定题型并进入题组工作区
4. 使用刚发布的题型命名创建手工填写题组
5. 填写题组内容，保存后从题型详情重新进入
6. 返回题型库确认发布后的原草稿仍然保留

**完成标准：**

- 题型草稿、稳定题型和题组都由同一条用户界面路径依次产生。
- 后续题组使用本次旅程刚发布的题型，不以测试夹具替换中间产物。
- 题组内容保存后可以重新进入，发布题型后原草稿仍然保留。

## 已验证产品行为

### 1. 从结构草稿填写评分资料并发布稳定评分单元

评分单元先以可保存的结构草稿存在，发布时补齐面向用户的名称、说明和答案解释，生成稳定契约并保留原草稿。

**开始前：**

- 评分单元库为空，用户需要创建第一个评分单元。

**操作顺序：**

1. 进入评分单元并新建结构草稿库
2. 命名结构草稿并明确评分管道
3. 补齐正式资料并确认发布冻结结构
4. 发布后查看正式评分单元并保留结构草稿

**完成标准：**

- 创建草稿库和结构草稿不会直接产生正式评分单元。
- 发布对话框要求补齐正式名称、描述和答案槽位说明。
- 发布成功后正式评分单元和结构草稿都保留，可以分别进入。

[查看 GS-01 的截图、异常分支与可执行规格](../modules/grading-units/behaviors/GS-01.md)

### 2. 从草稿发布稳定题型并保留草稿

题型草稿可以不完整地保存；发布前说明稳定契约，发布成功后已发布题型和原草稿同时保留。

**开始前：**

- 用户从题型库的“草稿”视图开始创建题型。

**操作顺序：**

1. 在题型库切换到草稿视图并新建题型
2. 填写题型基本信息、生成要求和字段契约
3. 发布前明确说明将生成稳定题型并保留当前草稿
4. 发布成功后可以查看稳定题型，并能在草稿视图找到原草稿

**完成标准：**

- 发布前明确说明将创建稳定题型，并保留当前草稿。
- 发布成功后，稳定题型和原草稿可以分别找到。

[查看 IF-05 的截图、异常分支与可执行规格](../modules/interface-library/behaviors/IF-05.md)

### 3. 从题型库命名创建并保存题组

题型详情以题组为默认工作区；用户先命名题组并选择进入方式，再填写和保存具体内容。

**开始前：**

- 题型库中已有“英语问答练习”题型。

**操作顺序：**

1. 从题型库进入题型，默认看到题组工作区
2. 填写题组名称并选择手工填写后才正式创建
3. 填写题组内容并明确保存

**完成标准：**

- 题组只有在确认名称和进入方式后才正式创建。
- 手工填写内容需要明确保存，并能从题型详情重新进入。

[查看 IF-01 的截图、异常分支与可执行规格](../modules/interface-library/behaviors/IF-01.md)

### 4. 取消创建不会留下空题组

打开新建题组设置不会立即写入空记录；只有确认名称和进入方式后才创建题组。

**开始前：**

- 当前题型还没有任何题组。

**操作顺序：**

1. 打开新建题组设置并填写名称
2. 取消后题组列表和本地记录都保持为空

**完成标准：**

- 取消新建题组后，列表和本地存储都不会出现空记录。

[查看 IF-02 的截图、异常分支与可执行规格](../modules/interface-library/behaviors/IF-02.md)

### 5. 未保存的题组修改受到保护

手工修改不会静默保存；离开编辑器前可以继续编辑或明确放弃本次修改。

**开始前：**

- 已经创建一个尚未填写内容的题组。

**操作顺序：**

1. 修改字段后离开会提示未保存风险
2. 取消离开会保留当前编辑状态
3. 明确放弃后返回题组列表，重新进入时不包含未保存内容

**完成标准：**

- 离开包含未保存修改的题组前必须确认。
- 取消离开保留编辑状态，放弃修改不会写入题组。

[查看 IF-03 的截图、异常分支与可执行规格](../modules/interface-library/behaviors/IF-03.md)

### 6. AI 整组生成明确覆盖并原子保存

AI 整组生成使用明确的覆盖语义；已有内容时再次确认，成功后整组结果一次保存。

**开始前：**

- 题组已有手工保存的内容，并配置了可用的 AI 文本模型。

**操作顺序：**

1. 打开 AI 生成任务并选择模型
2. 对已有内容执行生成前明确提示会覆盖并立即保存
3. AI 成功后整组内容被替换并已经保存

**完成标准：**

- 已有内容时，生成前明确确认覆盖范围和立即保存语义。
- 只有生成、校验和保存全部成功后，才替换当前题组。

[查看 IF-04 的截图、异常分支与可执行规格](../modules/interface-library/behaviors/IF-04.md)

### 7. JSON 作为临时导入对话框完成覆盖

JSON 是一次性导入命令；校验失败时保留临时输入，取消时清空，校验成功后原子保存并返回题组。

**开始前：**

- 题组已有手工保存的内容。

**操作顺序：**

1. 打开临时导入对话框，明确覆盖和立即保存语义
2. JSON 校验失败时保留输入和错误，原题组内容保持不变
3. 取消会丢弃本次临时输入和校验错误
4. 合法 JSON 经确认后原子保存，关闭对话框并返回题组

**完成标准：**

- 校验失败时保留临时输入和错误，原题组保持不变。
- 取消导入会清空临时状态。
- 合法 JSON 经确认后原子保存并关闭对话框。

[查看 IF-06 的截图、异常分支与可执行规格](../modules/interface-library/behaviors/IF-06.md)
