# 3. 制作模板并生成试卷

[上一章：准备评分标准与题型内容](./02-prepare-content.md) · [返回指南](./README.md) · [下一章：运行试卷并保存作答包](./04-run-exam.md)

## 这一阶段要完成什么

把题型、题组、评分单元、页面内容和时间线组织为可复用模板，并生成不可编辑的运行试卷。

## 为什么需要这一步

模板是可维护的生产规则，试卷是某次运行所需的完整快照。两者分离后，既能重复制卷，也能保证已经运行的试卷不被后续编辑改变。

## 开始前准备

- 已发布的题型与题组。
- 已发布的评分单元。
- 页面、时间线和语音合成配置。

## 已验证操作

### 1. 创建、编辑并保存可复用的试卷模板

试卷模板先保存为可继续维护的制卷规则，用户明确填写名称和说明后保存，之后才能进入生成试卷流程。

**开始前：**

- 试卷模板库中没有需要继续编辑的本地模板。

**操作顺序：**

1. 从模板库新建模板并填写基本信息
2. 明确保存模板并确认版本状态
3. 返回模板库并重新进入时保留名称和说明

**完成标准：**

- 新模板从默认名称开始，但只有明确保存后才成为可复用版本。
- 模板名称和说明保存后从模板列表重新加载仍然存在。
- 模板编辑器同时提供保存和生成入口，生成依据最后一次成功保存的内容。

[查看 TP-01 的截图、异常分支与可执行规格](../modules/template-library/behaviors/TP-01.md)

### 2. 从试卷模板生成试卷并决定如何保存结果

生成试卷使用独立的全屏三阶段流程。语音逐条执行并自动重试，生成完成后由用户选择加入试卷库或导出文件。

**开始前：**

- 已有一份包含三条语音的试卷模板，并配置三个可独立选择的语音提供商。

**操作顺序：**

1. 从试卷模板编辑器进入不带一级导航的生成设置页
2. 填写试卷名称并为三种音色分别选择提供商、模型和音色
3. 生成进行中离开页面需要确认，继续生成会保留当前任务
4. 单条语音自动尝试四次仍失败时立即中断
5. 从失败语音继续生成，不重新合成已完成任务
6. 未保存结果时关闭会提示丢失风险
7. 加入试卷库和导出文件是独立操作，完成后页面仍保持打开
8. 主动关闭流程后可以在试卷库找到生成结果

**完成标准：**

- 生成设置、生成过程和生成结果在独立全屏流程中依次呈现。
- 语音失败会在有限重试后中断，并可从中断位置继续。
- 加入试卷库和导出文件互相独立，未保存结果受到离开保护。
