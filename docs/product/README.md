# LS101 产品定义

本文档记录产品梳理过程中已经确认的产品事实和用户可见设计。它是后续界面设计、交互实现和 Playwright 集成测试的产品依据。

`design/`、`refactor/` 和旧版 README 中与本文档冲突的内容均视为历史草案，不作为当前产品行为的依据。

## 梳理原则

- 核心业务能力已经稳定，本轮以重新确认产品定位、用户流程和交互逻辑为主；
- `ExamPlayer` 的现有前端经过专门设计，应作为播放器体验基线，仅修改产品梳理中明确确认的差异；
- 其他模块的现有界面只代表当前实现和能力范围，不默认视为合理的产品设计；
- 其他模块需要根据已确认的产品逻辑重新检查信息结构、操作层级、反馈和常见用户习惯。

## 产品定位

LS101 是一套覆盖英语听说考试完整工作流的全能桌面工具。

产品不划分教师端和学生端，也不根据身份限制功能。用户可以在同一个应用中制作题型、设计评分单元和试卷模板、运行试卷、管理作答记录并完成评分。

## 工作台

工作台是应用首页，负责提供：

- 产品各项能力的快捷入口；
- 最近状态和重要信息的汇总。

工作台不拥有独占业务能力。工作台中出现的每个操作入口，都必须能够从对应功能模块独立进入和完成。

工作台不是教师或学生角色的门户，也不改变其他模块的权限或可见性。

## 一级模块

已确认的一级模块名称如下：

| 名称     | 定位                                           |
| -------- | ---------------------------------------------- |
| 工作台   | 应用首页、最近状态和快捷入口                   |
| 试卷库   | 管理已经生成并可以直接运行的试卷               |
| 作答记录 | 管理作答包、评分状态和结果报告                 |
| 题型库   | 管理可复用的题型定义及其题组内容               |
| 试卷模板 | 组织试卷结构、页面、题型、时间线和评分单元     |
| 评分单元 | 定义可复用的答案结构、评分输入、分值和评分标准 |
| 设置     | 管理应用配置、AI 能力和应用信息                |

已确认的一级导航顺序为：

1. 工作台
2. 试卷库
3. 作答记录
4. 题型库
5. 试卷模板
6. 评分单元
7. 设置

## 用户可见术语

- 用户界面统一使用“评分单元”，不向普通用户暴露 `Schema`。
- 用户界面统一使用“试卷模板”，与最终可运行的“试卷”区分。
- 用户界面使用“作答记录”，不使用带有特定角色倾向的“收卷”。
- `Interface`、`Schema`、`Template` 等名称可以继续作为代码和文件格式中的内部术语。
