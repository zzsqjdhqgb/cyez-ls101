# 试卷模板生成试卷

本文档记录从试卷模板创建可运行试卷的已确认产品行为。

## 页面定位

“生成试卷”使用独立的全屏页面承载，不使用普通弹窗。生成页延续试卷模板编辑器的沉浸式工作区，占据整个窗口内容且不显示应用一级导航；用户只通过流程自身提供的返回或关闭操作离开。

生成流程在同一个全屏页面内依次呈现三个阶段：

1. **生成设置**：确认模板、题组、语音及其他生成参数；
2. **生成过程**：展示总体生成阶段和逐条音频合成任务；
3. **生成结果**：展示最终结果和后续操作。

进入页面不会自动开始任务。只有用户在“生成设置”阶段明确执行“开始生成”，流程才进入“生成过程”。

## 进入流程

用户从试卷模板编辑器进入生成流程时，如果模板存在未保存修改，系统先自动保存当前内容：

- 保存成功后进入全屏生成页；
- 保存失败时停留在模板编辑器并展示失败原因；
- 本次生成始终以完成保存的模板内容为依据。

## 生成设置

生成设置包含必填的“试卷名称”：

- 默认使用当前试卷模板名称；
- 用户可以在开始生成前修改；
- 生成后的试卷库条目名称使用该值；
- 导出文件的默认文件名使用该值。

### 题组选择

模板内容选择统一使用“题型”和“题组”表达：

- `Interface` 在用户界面中称为“题型”；
- `Interface Instance` 在用户界面中称为“题组”；
- 选择区域命名为“题组选择”；
- 每一项展示模板所需的题型名称，并从该题型已有的题组中选择本次内容；
- 不向用户显示 `Interface` 或“实例”等内部术语。

### 语音设置

语音设置按用途分为“默认音色”“男声音色”和“女声音色”三组。三组均为必选，不提供回退或跟随默认音色的选项。每组分别提供以下三级联动选择：

1. 提供商；
2. 模型；
3. 音色。

不同用途可以分别选择不同的提供商、模型和音色；不要求三组使用同一个语音引擎。

如果模板完全不包含语音合成动作，生成设置不显示上述语音选择，也不要求配置语音。页面需要明确提示“此模板无需合成语音”，语音配置不得阻塞这类模板的生成。

## 生成过程

生成过程固定展示以下总体阶段：

1. **准备试卷内容**：校验模板并读取所选题组；
2. **合成语音**：展示每条音频合成任务；
3. **整理试卷资源**：收集图片、已有音频等资源；
4. **打包试卷**：生成最终可运行的试卷包。

不包含语音合成动作的模板仍显示“合成语音”阶段，并将其标记为“无需处理”，以保持不同试卷生成过程的结构一致。

逐条语音合成进度复用产品现有的 `TaskProgress` 交互和状态模型：

- 每一条语音对应一个独立任务；
- 任务按实际合成顺序排列；
- 等待、执行、完成和错误信息由任务项自身呈现；
- 自动重试次数及最终失败原因记录在对应任务中；
- 不再为语音合成另外设计一套进度条或任务列表。

### 失败和重试

音频合成任务按生成顺序执行。单条音频首次合成失败后，系统自动额外重试三次，即每条音频最多请求四次。达到上限仍未成功时：

- 立即中断整个生成流程，不再继续后续任务；
- 在当前进度和失败项目处展示错误；
- 提供手动重试操作；
- 保留本次任务中已经成功合成的音频；
- 手动重试时复用已完成结果，从失败项目继续，不从第一条音频重新合成。

### 离开页面

首版生成任务仅在当前页面前台运行，不进入后台。生成过程中，用户执行返回或关闭操作时，页面必须先明确提示离开将取消本次生成：

- 用户确认离开时，取消当前生成任务并返回试卷模板编辑页；
- 用户选择继续生成时，保留当前任务和进度并停留在生成页面；
- 不允许导航操作无提示地中断生成。

用户主动关闭生成流程后，可以释放临时任务进度和音频结果。

## 生成结果

生成完成后停留在结果页面，不自动导出文件，也不自动关闭。只有用户主动执行关闭操作时，才结束生成流程。

结果页中的操作规则如下：

- “加入试卷库”是主操作，“导出文件”是次要操作，“关闭”是普通操作；
- “加入试卷库”和“导出文件”是相互独立的后续操作；
- “加入试卷库”成功后，按钮变为“已加入试卷库”并禁用，防止重复加入；
- “导出文件”可以重复执行，以便将文件导出到不同位置；
- 任一操作成功后都继续停留在结果页；
- 用户最终执行“关闭”后返回试卷模板编辑页。

如果结果既没有加入试卷库，也没有成功导出过文件，用户执行关闭时必须再次确认本次结果将被丢弃。只要已经成功完成任意一种保存操作，关闭时不再显示该提示。
