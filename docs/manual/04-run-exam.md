# 4. 运行试卷并保存作答包

[上一章：制作模板并生成试卷](./03-build-generate-exam.md) · [返回说明书](./README.md) · [下一章：评分、结算与查看结果](./05-grade-settle.md)

## 这一阶段要完成什么

从试卷库启动考试，完成身份登记、播放、作答采集和作答包保存。

## 为什么需要这一步

试卷运行负责按模板确定的顺序采集事实数据；评分发生在运行完成之后，不应反向修改原始作答。

## 开始前准备

- 一份可以导入或已经位于试卷库中的可运行试卷。
- 作答人姓名和考生号。
- 可用的扬声器和麦克风。

## 完整任务

### 1. 运行一份试卷并把作答交给评分环节

已有可运行试卷时，从试卷库启动考试、登记作答人并保存作答包，再把本次产生的作答导入作答记录。

**开始前：**

- 本地有一份无需录音检查的可运行试卷包。

**操作步骤：**

1. 进入“试卷库”，选择“导入试卷包”，再选择要运行的试卷文件。

   完成后：导入的试卷出现在试卷库中。

2. 选择“开始考试”，填写作答人姓名和考生号。

   完成后：开始作答前，页面显示本次试卷并保留作答人身份信息。

3. 选择“继续”进入播放器，并完成试卷。

   完成后：完成页确认作答包已经保存，并提供结束考试的“完成”按钮。

4. 在完成页选择“完成”。

   完成后：播放器关闭并返回试卷库，原试卷仍可再次使用。

5. 进入“作答记录”，选择“导入作答包”，再选择本次考试刚刚保存的文件。

   完成后：作答出现在“未结算”列表中，并显示刚才登记的姓名和试卷名称。

**完成后：**

- 开始考试前必须填写姓名和考生号。
- 作答完成后必须成功保存作答包才能结束考试。
- 本次考试产生的作答包可以立即导入作答记录，并保留试卷和作答人信息。

## 相关操作

### 1. 重复导入同一份试卷并取消导入

试卷库用试卷包编号和内容判断重复导入；用户取消文件选择时，列表和提示都不发生变化。

**开始前：**

- 本地有一份已经导入试卷库的试卷和同一份试卷包文件。

**操作步骤：**

1. 进入“试卷库”，选择“导入试卷包”，选中一份可运行的试卷文件。

   完成后：试卷出现在试卷库列表中。

2. 再次选择“导入试卷包”，选中同一个试卷文件。

   完成后：页面提示“该试卷包已经在考试库中”，列表不新增试卷。

3. 再次选择“导入试卷包”，在文件选择框中取消。

   完成后：列表保持不变，也不显示错误提示。

**完成后：**

- 重复导入同一份试卷包不会新增列表记录，并提示该试卷包已经在考试库中。
- 取消文件选择不会改动列表，也不会显示错误提示。

### 2. 导入损坏的试卷包并在提示后重试

导入失败只显示原因并保留列表中已有内容，用户可以修正文件后重新导入，不需要重新进入页面。

**开始前：**

- 本地试卷库为空，另有一份损坏的试卷包文件和一份正常试卷包文件。

**操作步骤：**

1. 在没有任何试卷时进入“试卷库”。

   完成后：内容区显示“暂无试卷”。

2. 选择“导入试卷包”，选中一个损坏的试卷文件。

   完成后：页头下方显示“无法导入试卷包”的错误条，列表仍为空。

3. 再次选择“导入试卷包”，选中一份正常的试卷文件。

   完成后：试卷成功导入并出现在列表中。

**完成后：**

- 空试卷库显示“暂无试卷”，不提供页内快捷导入入口。
- 导入损坏文件时页头下方显示带告警图标的错误条，列表保持为空。
- 重新导入正常文件后试卷进入列表。

### 3. 查看空试卷库并识别查询失败提示

没有试卷时展示空状态；本地数据损坏导致查询失败时，页头下方显示错误条且不渲染试卷表格，重新进入页面会再次查询。

**开始前：**

- 本地试卷库为空，之后本地保存的试卷库数据会被破坏。

**操作步骤：**

1. 在没有任何试卷时进入“试卷库”。

   完成后：内容区显示“暂无试卷”。

2. 在本地试卷库数据损坏后重新进入“试卷库”。

   完成后：页头下方显示带告警图标的“考试库数据损坏”错误条，试卷表格不渲染。

**完成后：**

- 空试卷库显示“暂无试卷”。
- 数据损坏时页头下方显示“考试库数据损坏”的错误条，试卷表格不渲染。

### 4. 确认后删除试卷并保留取消分支

删除试卷会同时移除本地保存的原始试卷包，属于不可逆操作，必须经过二次确认；取消后试卷保持不变。

**开始前：**

- 试卷库中有一份可以删除的试卷。

**操作步骤：**

1. 进入“试卷库”，选择“导入试卷包”，选中一份可运行的试卷文件。

   完成后：试卷出现在试卷库列表中。

2. 选择这份试卷的“删除试卷”，阅读确认说明后选择“取消”。

   完成后：确认对话框关闭，试卷仍在列表中。

3. 再次选择“删除试卷”，并选择“删除”。

   完成后：提示删除成功，列表刷新为空状态。

**完成后：**

- 删除前必须经过确认对话框，取消后试卷仍在列表中。
- 确认删除后试卷从列表消失，试卷库回到空状态。

### 5. 退出考试前确认并放弃本次进度

考试运行中退出不会生成作答包，因此必须先经过退出确认；选择继续考试会保持当前进度，确认退出才返回试卷库。

**开始前：**

- 试卷库中有一份需要较长时间作答的可运行试卷。

**操作步骤：**

1. 进入“试卷库”，选择“导入试卷包”，选中一份需要较长时间作答的试卷文件。

   完成后：试卷出现在试卷库列表中。

2. 选择“开始考试”，填写作答人姓名和考生号，再选择“继续”。

   完成后：播放器进入作答页并显示页码与“退出”按钮。

3. 选择“退出”，在确认对话框中选择“继续考试”。

   完成后：确认对话框关闭，页面停留在当前作答进度。

4. 再次选择“退出”，并选择“确认退出”。

   完成后：应用放弃当前进度并返回试卷库，原试卷仍在列表中。

**完成后：**

- 任何阶段的“退出”都会先打开退出确认对话框。
- 选择“继续考试”关闭对话框并保留当前进度。
- 选择“确认退出”放弃本次进度并返回试卷库，试卷仍可再次使用。

- 包含身份、答案、录音和评分上下文的自包含作答包。
- 作答记录中一条可以继续评分和结算的未结算作答。
