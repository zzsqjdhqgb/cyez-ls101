# 产品说明书（待建立）

本目录将存放**自动生成**的《LS101 产品说明书》，是面向用户与第三方评审的产品承诺文档。

**当前状态：尚未建立。** 现有 `docs/product/` 是上一代产物，已弃用（见 [`../product/README.md`](../product/README.md)）。

## 目标形态

- **说明书是第一产物**：章节、任务、步骤先用人的语言写，测试只负责验证；不为"有没有测试"决定"写不写文档"。
- 允许 `unverified` 步骤存在并计入锚定率，逐步提高，而不是反过来。
- 生成器复用现有确定性设施：canonical Docker 渲染容器、固定字号/时钟/UUID、等价截图保留旧字节。
- 不再生成逐操作的行为页；界面语义由 [`../ui/screens/`](../ui/README.md) 承担。

## 章节（按工作顺序）

1. 认识 LS101 与完整工作流
2. 准备评分标准与题型内容
3. 制作模板并生成试卷
4. 运行试卷并保存作答包
5. 评分、结算与查看结果

章节顺序与每章的"目标 / 为什么 / 输入 / 产出 / 下一步"由手写大纲定义，正文由说明书规格生成。

## 写作约束

- 只写用户动作与用户可见结果；测试编号、内部数据结构、源码入口不得进入正文叙事。
- 前置条件必须是用户能准备的真实材料或产品对象，不得由测试夹具替代主线中间产物。
- 与 `../ui/` 冲突时以 `../ui/` 为准。
