# 曹二听说101 使用说明书

曹二听说101 是一套英语听说模拟考试软件，用来完成出卷、考试、批改三件事。软件装在本机，数据保存在本机，除 AI 功能外不需要联网。

本说明书对应 V0.4.1 版本，按实际使用的先后顺序编写。

| 文档版本 | 日期    | 修订内容                   | 修订人 |
| -------- | ------- | -------------------------- | ------ |
| V1.0     | 2026-09 | 依据 V0.4.1 界面与功能编写 | 应昊廷 |

## 1. 运行环境与安装

### 1.1 运行环境

软件运行在 Windows 10 或 Windows 11（64 位）上，安装包已包含运行所需的全部组件。

语音合成和语音识别在本机运行，模型文件约占 4 GB 硬盘空间；加上试卷、作答录音和评分结果，硬盘占用会持续增长，安装前和考试前都要留出余量。

考试需要耳机或音箱播放听力、麦克风录制口语。考场建议让考生使用耳机，避免相互干扰；正式考试前用软件提供的麦克风检测功能试录一次，确认能录能放。

出题、组卷、考试和评分都能离线完成，需要联网的只有两处：使用 AI 生成内容或 AI 评分时访问「设置 → AI 引擎」中配置的服务商，以及打开「激活方式意见征集」页面。

### 1.2 安装

1. 双击安装程序，打开安装向导。
2. 按提示选择安装位置。默认装在系统程序目录，也可以改；建议装在本地硬盘，不要装到网络驱动器或移动存储设备上。
3. 按提示决定是否创建桌面快捷方式。
4. 安装完成后，向导提供运行选项，可以直接启动软件。

覆盖安装新版本前先备份数据，方法见 1.5 节。

### 1.3 首次启动与激活

1. 启动软件，第一次打开时界面显示「激活曹二听说101」。
2. 在「邀请码」输入框中输入邀请码，单击「激活并进入」。

   ![图 1 激活界面](../../tests/manual/baselines/FIG-ACTIVATION/default.png)

3. 邀请码不正确时，界面提示「邀请码不正确，请检查后重试。」，重新输入即可。
4. 激活成功后进入工作台。激活信息保存在本机，以后打开不用再输入。

激活界面下方显示许可的有效期。许可到期后启动软件，界面显示「使用权限已到期」，此时需要获取新的邀请码。

如需在本机清除激活信息，打开「设置 → 许可」，单击「取消激活」并确认。软件会删除本机的激活信息并重新启动，试卷、题型、作答记录等业务数据不受影响。

### 1.4 启动过程与旧版本数据

软件启动后先显示启动窗口，同时在后台加载数据；加载时间较长时，窗口里会显示当前进行到哪一步。第一次打开或者更新版本后，界面会弹出「版本说明」，列出这一版改了什么。

![图 2 版本说明](../../tests/manual/baselines/FIG-RELEASE-NOTES/default.png)

「版本说明」只能用「关闭版本说明」按钮关闭，按 Esc 键或单击对话框外部都不会关闭。

在装过旧版本的电脑上启动时，软件会先把旧数据打包归档，并显示「旧数据已归档」，列出归档的目录数、文件数和数据量。

![图 3 旧数据已归档](../../tests/manual/baselines/FIG-LEGACY-ARCHIVE/default.png)

需要保留时单击「导出旧数据」把归档文件保存到指定位置；暂时不处理可以关闭提示；确认不再需要时单击「清理并继续」，软件删除已归档的旧数据目录后继续启动。归档文件保存在软件数据目录中，不会跟着旧数据一起删除，没有确认清理之前旧数据不会被删除。

### 1.5 数据存储位置

软件数据默认保存在：

```text
%APPDATA%\cyez-ls101\data
```

其中 `%APPDATA%` 一般为 `C:\Users\<用户名>\AppData\Roaming`。实际位置和占用大小可在「设置 → 存储」中查看，该页面提供三项操作：

- 「更改位置」：把数据复制到一个空目录，或者改用另一个已有的数据目录。
- 「恢复默认位置」：改回默认目录。
- 「删除旧数据」：删除更换位置后留下的旧目录。

复制完成之前不会切换目录，原数据也不会删除。迁移完成后，原目录保留为「旧数据目录」，确认不再需要时再删除。旧数据目录尚未删除，或者旧版本数据的归档尚未清理时，都不能更改数据位置。

### 1.6 卸载

打开 Windows 的「设置 → 应用 → 已安装的应用」（Windows 10 为「控制面板 → 程序和功能」），找到「曹二听说101」并卸载。卸载只删除程序文件，不删除数据目录；如需一并清理，先按 1.5 节找到数据目录自行备份或删除。已经导出的试卷包、作答包和成绩文件不受影响。

## 4. 评分单元

### 4.1 评分单元是什么

评分单元是一道题的判分依据，同时规定三件事：这道题怎么作答、答案怎么采集、分数怎么给。考试时学生看到什么、评分时阅卷人看到什么、报告里展示什么，都由评分单元决定。

评分标准、题目内容、卷面编排在软件里分开维护。试卷模板只引用评分单元，并把评分单元绑定到具体题目；生成试卷时，评分单元的定义会完整写进试卷，成为这份试卷自带的判分依据。因此同一套标准可以用在多份试卷上，一份试卷也可以换一套标准重新评分，而评分单元后来怎么改，都不会动摇已经生成的试卷和已经完成的评分。

一份评分单元从建立到使用的完整去向：

1. 建立：新建或从内置评分单元复制，填好内容后保存。
2. 引用：在试卷模板中绑定到某道题或多个题目。
3. 固化：生成试卷时，评分单元的定义随试卷一起保存。
4. 采集：考试时按评分管道与答案槽位决定学生怎么答、录几段音。
5. 判分：评分时，评分材料、满分上限与评分标准出现在评分界面。
6. 归档：结算后，分数与评分标准一起进入评分报告。

### 4.2 一项评分单元要定下来的事

新建或复制评分单元时，页面左侧编辑内容，右侧实时显示评分结构摘要；要定下来的内容分四组，依次是作答方式、答案槽位、模板输入和评分依据。

![图 7 新建评分单元（左侧编辑，右侧结构摘要）](../../tests/manual/baselines/FIG-GS-EDITOR/default.png)

**这道题怎么作答——评分管道**

评分管道在三者中选一，决定学生怎么答、答案怎么采、由谁判分：

| 评分管道 | 学生怎么答     | 答案形态       | 谁来判分                           |
| -------- | -------------- | -------------- | ---------------------------------- |
| 客观题   | 在页面上选择   | 一段文本       | 系统自动判定，不需要人工或 AI 评分 |
| 固定朗读 | 按给定文本朗读 | 一条或多条录音 | 人工评分或 AI 评分                 |
| 自由口语 | 自由作答       | 一条或多条录音 | 人工评分或 AI 评分                 |

客观题在评分会话开始时由系统判完，计入总评分单元数，但不出现在人工或 AI 的待评列表里。切换评分管道会重置答案槽位的类型，需要重新添加槽位。

**答案怎么采——答案槽位**

一个答案槽位就是一份要采集的答案。客观题固定一个文本槽位；固定朗读和自由口语可以添加多个语音槽位，例如短文分句朗读、一问一答各一条，槽位顺序可以调整。

每个槽位有稳定编号和说明。编号用于记录与引用，说明会显示在评分界面上，告诉阅卷人这段文本或录音是什么。评分时，文本答案直接显示内容，没有作答时显示「未作答」；录音答案显示时长，可以回放确认。

**模板里能填什么——试卷模板输入**

试卷模板输入是留给试卷模板填写的文字项，例如朗读原文、参考文本、题目描述。每项有编号、类型（目前是文本）和是否必填；标为必填的输入，生成试卷时不能为空。

评分时，这些输入按名称逐个显示在评分界面的「评分材料」一侧，和题目一起构成判分依据。

**怎么给分——满分、评分标准与 AI 补充提示词**

- **满分**：评分界面的分数上限，填写分数时必须在 0 到满分之间；结算时按满分汇总总分，报告里同时给出总分与满分。
- **评分标准**：分档说明，用 Markdown 编写。人工评分时显示在「评分材料」里，AI 评分时作为判分依据；结算后随评分报告一起归档，便于复核。
- **AI 补充提示词**：可选，只在 AI 评分时生效，用来补充机器不容易从评分标准里读出的要求。

**名称、描述与版本**

名称在列表、模板绑定处和评分界面上显示；描述用一句话说明这道题考什么。每次保存递增一个版本号，界面显示为「版本 N」。

### 4.3 做一个评分单元

![图 8 评分单元库](../../tests/manual/baselines/FIG-GS-LIBRARY/default.png)

1. 进入「评分单元」。软件自带 14 项内置评分单元（上海高考的朗读句子、情景提问、看图说话等），先在内置列表里找最接近的一项，单击「复制并修改」，软件会带着原结构生成一份可编辑的副本。
2. 填写名称和描述。
3. 选择评分管道。改管道会重置答案槽位类型，需要重新添加槽位。
4. 按题目需要增减答案槽位，填写每个槽位的稳定编号和说明；朗读、口语题可以为一题添加多个槽位并调整顺序。
5. 如果模板要往这套标准里填文字（例如朗读原文），添加试卷模板输入，写明编号和是否必填。
6. 填写满分和评分标准，需要时补上 AI 补充提示词。
7. 单击「添加到我的评分单元」。软件先校验结构再校验数据，不通过时在页面上逐条列出要修正的内容，已经填好的内容不会丢失。
8. 保存后停留在编辑态，可以继续修改数据并保存，每次保存产生一个新版本。

### 4.4 使用与维护

- **结构在第一次保存后固定**：评分管道、答案槽位及其顺序、试卷模板输入都不能再改，之后只能修改名称、满分、说明、评分标准和 AI 补充提示词。需要改结构时，重新从内置评分单元复制，或者新建一个。已经生成的试卷因此始终对得上当初的判分依据。
- **内置评分单元只读**：内置项不能编辑和删除，需要调整时复制成「我的评分单元」再改。
- **导出**：已保存且没有未保存修改时，「导出」把当前定义写成 `.lsschema` 文件，用于备份或复制到其他电脑；有未保存修改时导出不可用。
- **删除**：需要二次确认，确认框会说明删除后引用该评分单元的模板将无法通过校验。已经生成的试卷和已经完成的评分不受影响。
- **在模板中引用**：模板只保存引用和题目输入，实际判分规则以生成试卷时读取的正式版本为准；同一个评分单元可以在模板中被多个题目引用。

## 5. 题型库

### 5.1 题型与题组

**题型**规定一类题目由哪些字段组成以及 AI 应当按什么要求生成内容。例如「朗读句子」需要一段原文文本、一张提示图片和一条参考音频，这些就是题型的字段结构。

**题组**是按题型的字段填好的一套具体内容。一个题组就是一套完整的题，可以在生成多份试卷时反复选用。

试卷模板只引用题型的字段结构，生成试卷时才选定用哪个题组。因此同一批题目可以供不同试卷使用，调整卷面编排也不必改动题目定义。已发布的题型不能直接修改，需要调整时从复制新草稿开始，修改和重新发布不会影响已经生成的试卷。

### 5.2 题型库与题型详情

导航栏进入「题型库」，页面分「题型」和「草稿」两个视图：题型视图列出已经发布的题型，显示名称、题组数量和描述；草稿视图存放还没发布或者还在继续修改的草稿，新建草稿的入口也在草稿视图。

![图 9 题型库](../../tests/manual/baselines/FIG-IF-LIBRARY/default.png)

打开一个题型进入详情页，详情页分「题组」和「题型定义」两个视图：「题组」是默认视图，用于新建、进入和删除该题型下的题组；「题型定义」查看描述、生成要求和字段结构，也是复制为新草稿、复制提示词和复制结构化输出的地方。导出题型固定在详情页，单击后先进入全屏选择页，勾选要交付的题组后再导出。

![图 10 题型详情（题组视图）](../../tests/manual/baselines/FIG-IF-DETAILS/default.png)

### 5.3 题型由哪些内容组成

| 内容     | 说明                                                                                                                                                                         |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 名称     | 题型的名字，在列表、模板绑定和题组页面显示                                                                                                                                   |
| 描述     | 一句话说明这类题目考什么                                                                                                                                                     |
| 生成要求 | 写给 AI 的提示词，说明这类内容应当怎么生成                                                                                                                                   |
| 字段结构 | 题型需要哪些内容。字段可以分组；每个字段包含字段标识（同层唯一的名字）、类型（文本或图片）、变量名（供试卷模板引用）、描述（告诉 AI 这个字段是什么）、示例（给 AI 的示例值） |
| 内置来源 | 显示题型是否随软件提供                                                                                                                                                       |
| 题组     | 该题型下的具体题目，每套题组有名称和生成时间                                                                                                                                 |

文本字段在试卷模板中以 `[@变量名]` 引用；图片字段分两份资源，图片提示词为 `[@变量名.inst]`，图片本身为 `[@变量名.img]`，模板里可以分别使用。

### 5.4 草稿与发布

题型有两个状态，对应题型库页面的两个视图：

- **草稿**：编制中的题型。允许保存不完整的内容，可以分次填写。
- **已发布题型**：发布后的稳定题型，字段结构不再变化，供试卷模板引用。

发布时集中校验名称、生成要求、字段结构（至少一个字段、字段组不能为空、变量名不能重复等），校验结果可以定位到具体字段。发布成功后草稿仍然保留，可以继续修改并再次发布，也可以删除；删除草稿不影响已经发布的题型。

### 5.5 编一个题型

1. 进入「题型库」，切到「草稿」视图，新建题型草稿。
2. 在「基本信息」里填写名称和描述，在「提示词」里填写生成要求。
3. 在「字段结构」中添加字段组和字段：文本字段用于文字内容，图片字段用于配图。
4. 逐个字段填写变量名、描述和示例。变量名会出现在试卷模板里，描述和示例会随生成要求一起交给 AI。

   ![图 11 题型草稿编辑器（左侧基本信息与生成要求，右侧字段结构）](../../tests/manual/baselines/FIG-IF-DRAFT/default.png)

5. 保存草稿。字段标识不合法或同层重名时会就地提示，不会自动改名。
6. 单击「发布」，在确认框中确认。发布生成稳定题型并进入题型详情。

### 5.6 做一套题组

![图 12 题组编辑器（按题型字段填写一套内容）](../../tests/manual/baselines/FIG-IF-INSTANCE/default.png)

在题型详情的「题组」视图中单击「新建题组」：

1. 填写题组名称，例如「校园生活第一套」，然后选择进入方式。
2. **手工填写**进入空白表单，按题型字段逐个填写；**AI 生成**进入编辑器后打开整组生成任务，但不会自动发起请求，需要确认后才开始。
3. 表单里的文本字段直接填写；图片字段必须同时有图片提示词和图片，才能保存。
4. 保存时整组一起提交，不提供单字段保存。

题组内容的三种生产方式：

- **整组 AI 生成**：按题型的生成要求一次性生成全部字段。成功时整组内容被原子替换并立即保存；如果题组里已有内容，开始前会说明覆盖范围并再次确认，生成失败或取消时原内容不变。
- **JSON 覆盖**：把外部整理好的内容一次性写入题组，规则与整组生成相同；AI 返回内容不合法时，可以转到 JSON 对话框检查原始结果。
- **图片生成**：单个图片字段可以选取本地文件、读取剪贴板，或调用图像生成服务；批量生图按字段顺序逐个进行，要求所有图片字段都已填写提示词，全部成功后一次保存。

删除题组会连同内容和图片资源一起删除，不可恢复。

### 5.7 交换题型文件

题型文件用于在两台电脑之间传递题目。在题型详情中单击「导出题型」，进入全屏选择页逐项勾选要交付的题组，再导出为 `.lsinterface` 文件；每个题组的全部资源随题组一起交付。

导入时先选择文件，再在全屏审查页看到三类题组：

- **可导入**：本机没有的题组，默认勾选。
- **已存在**：本机已有完全相同的题组，显示完成状态，不能重复勾选。
- **冲突**：标识相同但内容不同的题组，不能勾选，页面会说明原因。这种情况不能用文件直接覆盖，需要人工确认后另行处理。

取消导入不会写入任何内容。

### 5.8 内置题型

内置题型随软件提供，当前版本包含上海高考英语听力、上海高考英语口语和上海中考英语口语，不能直接修改。

内置版本升级时按变化程度分别处理：兼容性更新自动应用；字段结构有变化时，由使用者选择迁移现有题组还是保留旧版；如果变量契约不兼容，则不会自动更新，当前版本继续保留并明确提示。

## 6. 试卷模板

### 6.1 模板、函数库与试卷

**试卷模板**是可编辑的制卷规则，把页面、内容、题型题组、评分单元和资源组织成一份完整的考试结构。**试卷**是模板生成出来的自包含快照：生成之后再修改甚至删除模板，都不会改变已经生成的试卷。考过的卷子必须固定、可复查，因此软件把「规则」和「成品」分成两个对象。

**函数库**存放模板可以复用的函数，例如按规则计算分值或拼接文本。本地函数库独立维护；函数插入模板后成为模板内部的一份副本，源函数库之后的变化不再影响这份模板。

### 6.2 模板由哪些内容组成

| 内容         | 说明                                                                     |
| ------------ | ------------------------------------------------------------------------ |
| 结构         | 页面与框架的层级，决定整份试卷的页面顺序                                 |
| 页面内容     | 页面上显示的内容块，包括文本块、图片块和选择题块                         |
| 时间线       | 每个页面上按时间播放或采集的步骤，决定先播什么、播放几遍、留多少作答时间 |
| 题型与题组   | 模板声明需要哪些题型；生成试卷时从题型的题组中选择具体内容               |
| 评分单元绑定 | 把题目的答案与评分标准对应起来                                           |
| 资源         | 试卷使用的图片、音频等文件                                               |
| 函数         | 模板内可复用的计算与文本处理                                             |
| 版本         | 每次成功保存递增，用于判定新旧                                           |

模板不区分草稿和发布：保存只是记录工作进度，不做严格校验；预览和生成试卷时才要求内容完整合法。模板只允许引用可用且结构匹配的题型与评分单元；生成只能依据最后一次成功保存的内容，从编辑器进入生成前会先保存当前修改。

### 6.3 模板库

![图 13 试卷模板库](../../tests/manual/baselines/FIG-TP-LIBRARY/default.png)

导航栏进入「试卷模板」，页面分「内置模板」「我的模板」「函数库」三个视图，内置模板默认显示，两类模板都可以按标签筛选。每条内置模板显示版本号。

- **内置模板**：随软件提供，包含上海高考口语标准题型、上海高考英语听力标准题型，以及朗读句子、快速应答、短对话、短文、长对话专项训练等。内置模板只读，可以查看、创建副本或直接生成试卷；缺少依赖题型的模板会标记为不可用，不能生成。
- **我的模板**：提供编辑、生成试卷、导出和删除。导入模板时如果遇到同标识但内容不同的模板，可以选择覆盖本地、以新标识导入为副本，或者取消。
- **函数库**：见 6.5 节。

### 6.4 编辑模板

模板编辑器提供三个视图：

- **结构视图**：以节点树展示整份试卷，可以新增框架、页面和选择题，调整同级顺序，复制子树，删除节点。
- **页面视图**：在设计面上编辑页面内容块，支持选中、拖动、缩放、复制和删除。
- **预览视图**：按编译后的展开顺序，把每个页面的每个时间线步骤显示为一个画面，用于检查学生实际看到的顺序和选择题交互；切换画面或重新进入预览会清空答案。

![图 14 内置模板查看（左侧函数库与组件库，中间节点树，右侧属性）](../../tests/manual/baselines/FIG-TP-EDITOR/default.png)

编辑以整份文档为单位维护撤销与重做，最近一次成功保存是干净基线。保存期间可以继续编辑，不会覆盖新修改。有未保存修改时离开页面会先确认。保存失败时会提示数据已在其他窗口更新，此时需要刷新后重试。

### 6.5 函数库

本地函数库是带版本号的独立工作文档，库里的函数统一读取、保存和删除，可以在库之间导入导出。函数调用要求填写完整输入，并把每个手动输出映射到调用方的变量名。

从本地、导入或内置函数库中插入函数时，软件会在一次保存中复制该函数的完整依赖，随目标模板保存；源函数库之后的修改、删除或停用都不影响已经插入的模板。

### 6.6 生成试卷

在模板编辑器或内置模板上单击「生成试卷」，页面依次经过三个阶段。

**生成设置**：

1. 填写试卷名称，该名称同时用于试卷库条目和导出文件名。
2. 为模板中声明的每个题型选择题组。此段只在模板声明了题型要求时出现。
3. 如果模板含语音播放，为默认音色、男声、女声分别选择服务商、模型和音色；不含语音的模板显示「此模板无需合成语音」。

![图 15 生成设置（试卷信息、题组选择与三组音色）](../../tests/manual/baselines/FIG-TP-GENERATE/default.png)

**生成过程**：单击「开始生成」后，任务按列表顺序执行：准备试卷内容、逐条合成语音、整理资源、打包试卷。中途失败会显示「生成已中断」，可以从中断位置重试，已完成的语音继续复用。

**生成结果**：完成后显示页面数、资源数和试卷包大小，并提供两种互相不能替代的保存方式：

- **加入试卷库**：试卷直接进入本机试卷库，可以开始考试。
- **导出文件**：导出为 `.lsexam` 试卷包，用于复制到其他电脑。

两种方式至少要完成一种才能直接离开；都没有保存就离开时，软件会提示本次生成结果将丢失。

## 7. 试卷库

### 7.1 试卷与试卷库

试卷库保存可以直接运行的试卷，内容是试卷模板生成的快照。库里的试卷不能编辑：需要修改内容时，回到对应的试卷模板调整后重新生成。这样库中的卷子与实际考过的卷子始终一致。

导出一份试卷有两种途径：在模板的生成流程中导出 `.lsexam` 文件，或者把已经生成的试卷加入试卷库供本机使用。试卷库内不提供导出。

### 7.2 一条试卷记录包含哪些信息

| 信息       | 说明                                   |
| ---------- | -------------------------------------- |
| 标题       | 生成时填写的试卷名称                   |
| 试卷包编号 | 试卷的标识，导入时用于判断是否重复     |
| 导入时间   | 进入试卷库的时间，列表按这一项倒序排列 |
| 页数       | 试卷包含的页面数量                     |
| 资源数量   | 试卷包中的图片、音频等资源个数         |
| 包大小     | 试卷包文件的大小                       |

导入时软件校验试卷包清单和声明的全部资源：包编号与内容都与库中已有试卷一致时判为重复，不新增记录；包编号相同但内容不同时报冲突，不会覆盖已有试卷；校验失败不产生记录。

### 7.3 管理试卷

- **导入**：选择 `.lsexam` 试卷包，导入后出现在列表顶部。
- **开始考试**：每份试卷的主入口，见 7.4 节。
- **删除**：需要二次确认，只移除试卷库中的这份试卷和本地试卷包，不影响由这份试卷产生的作答记录。

库中没有任何试卷时显示空状态。

![图 16 试卷库（已导入的试卷）](../../tests/manual/baselines/FIG-EL-LIBRARY/default.png)

### 7.4 考试运行

在试卷库中单击某份试卷的「开始考试」进入考试。软件先校验试卷资源，然后依次进行：

1. **考生登录**：填写姓名和考生号，两者都是必填项。
2. **麦克风测试**：含录音作答的试卷会先进行设备检查，步骤为选择录音设备、完成试录、回放确认；确认声音正常后才开始考试。
3. **作答**：试卷页面按时间线依次播放，页面下方状态条显示当前页码、状态和剩余时间。学生按页面内容听题、录音或作答。
4. **生成作答包**：考试结束后，软件把本次作答打包保存。作答包需要交给阅卷的老师，由作答记录模块导入。

![图 17 考试运行（考生登录）](../../tests/manual/baselines/FIG-EL-PLAYER/default.png)

考试过程中可以退出，界面会先确认，退出不会生成作答包。资源缺失、播放或录音失败时考试会暂停并说明原因，可以重试当前步骤或重新生成作答包。

## 8. 作答记录

### 8.1 一条作答记录包含哪些信息

| 信息     | 说明                                         | 是否可修改 |
| -------- | -------------------------------------------- | ---------- |
| 姓名     | 考试时登记的考生姓名                         | 不可修改   |
| 考生号   | 考试时登记的考生号                           | 不可修改   |
| 原始答案 | 选择题选项、录音以及其他原始作答内容         | 不可修改   |
| 评分结果 | 每个评分单元的分数与评语，与原始作答分开保存 | 可重新评分 |
| 结算归属 | 记录所属的结算批次、批次总分与结算时间       | 见 8.4 节  |

原始作答不可修改、评分只产生独立结果，这样重新评分只需要放弃旧的评分结果，学生原始作答不会丢失。

### 8.2 导入与管理

导航栏进入「作答记录」，页面分「未结算」和「已结算」两个标签，未结算是默认视图，已结算按结算批次组织。

- **导入**：选择 `.lssubmission` 作答包，导入后形成作答记录。
- **导出**：把作答记录再导出为作答包文件，用于转交或备份。
- **删除**：不可逆。未结算记录删除后连同原始作答包与暂存评分一起移除；已结算记录删除后，结算归属和报告数据一并移除。

未结算记录有三种进度：未评分、评分中、可结算（全部评分单元都已完成）。

![图 18 作答记录（未结算）](../../tests/manual/baselines/FIG-SR-LIBRARY/default.png)

### 8.3 评分

可以单条开始评分，也可以按列表顺序批量逐条推进；继续评分时从第一个未评分的单元开始，已提交的评分保留。一次评分会话开始时在两种方式中二选一：

- **人工评分**：逐题填写分数与评语。
- **AI 评分**：先选择语音识别模型和文本评分模型，软件再依次处理本场所有未评分的评分单元。

客观题不需要人工介入，在准备评分时由系统自动判定。一次会话只使用一种方式；已经提交的评分单元不能修改。

![图 19 评分工作区（左侧评分材料，右侧填写分数与评语）](../../tests/manual/baselines/FIG-SR-GRADING/default.png)

AI 评分的处理规则：

- 单题失败不会中断其他题目，失败的题目单独列出并可重试；全部成功后才能完成本次评分或进入审查。
- 软件会保留所选模型、录音转写、评分提示词和模型原始响应；中途暂停后重新进入，已成功且模型选择相同的题目不会重复生成。
- AI 返回的分数必须在 0 到满分之间、最多三位小数，不符合要求的题目按失败处理。

全部题目成功后，可以选择直接采用全部结果、逐题审查，或者按规则抽查：可以填写整场抽查总题数，也可以按评分单元分别指定抽查题数。审查时修改过的结果仍然算作 AI 评分结果。

### 8.4 结算与评分报告

一条记录的全部评分单元完成后即为可结算。进入结算页后：

- **本次结算**把本场全部评分完成的记录结算为一个批次，计算总分并记录结算时间；没有可结算记录时该操作不可用。
- **下次结算**保留当前进度并返回未结算列表，已经完成的评分继续保留。

![图 20 评分结算](../../tests/manual/baselines/FIG-SR-SETTLEMENT/default.png)

结算整体成功或失败，不会产生只结算了一部分的批次。结算后的记录进入「已结算」标签，按批次展开；只有已结算的记录可以查看评分报告。报告包含总分与满分、逐题分数与评语、题目、评分标准和学生答案，客观题另含正误与解析。

发现评分有误时，可以对已结算记录重新评分：软件删除该记录的评分、结算结果和报告，保留原始作答，记录回到未结算列表；如果原批次因此为空，空批次会被删除。

## 9. 设置

### 9.1 AI 引擎

「设置 → AI 引擎」分五个区域：文本生成、图像生成、语音合成、语音识别和 AI 语音评测，各自管理服务商、模型与密钥。题组内容生成、试卷语音合成和 AI 评分分别使用对应区域的配置。

![图 21 设置 → AI 引擎（五个区域，以文本生成为例）](../../tests/manual/baselines/FIG-ST-AIROUTER/default.png)

配置一个服务商的步骤：

1. 新建服务商，填写协议与地址，以及该服务商要求的 API 密钥。
2. 用当前填写的内容测试连接；测试通过后保存。
3. 发现该服务商可用的模型，逐个启用需要使用的模型。

已保存的密钥不在列表中明文显示，查看需要显式操作。删除服务商会同时删除对应的加密密钥，但不影响已经保存的题组、试卷和作答记录。

一次评分会话在开始时确定所用的语音识别与文本评分模型，会话进行中不会因为这里的改动而变化。

### 9.2 存储

存储设置显示数据目录的当前位置与占用大小，并提供三个操作：更改位置、恢复默认位置、删除旧数据目录。位置未更改时，位置行标为默认位置；更改过的目录标为自定义位置。

![图 22 存储（当前目录、占用大小与位置操作）](../../tests/manual/baselines/FIG-ST-STORAGE/default.png)

迁移、切换与删除的完整说明和注意事项见 1.5 节。

### 9.3 外观

外观设置分两组：主题用于选择界面主题（浅色、深色或跟随操作系统），交互用于开关减少动态效果。修改后立即生效并保存；保存失败时回滚到上一次的取值，也可以恢复默认设置。
