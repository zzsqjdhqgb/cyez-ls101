本文件记录**当前覆盖到哪、还缺什么、被什么挡住**，是继续扩展说明书的工作清单。

## 1. 当前覆盖

- 生成物：`docs/manual/`（`README.md` + 5 章 + manifest），纯文本、无截图。
- 生成命令：`xvfb-run -a yarn docs:manual:local`（需先 `yarn build:test`；全部用例通过才会覆盖产物）。
- 覆盖单元：**30 项** = 3 条完整任务（`PJ-01`、`EX-01`、`EP-01`）+ 27 项独立操作。
- 旧层只有 20 项。第一批扩表由 `EP-01` 把对象链主线连起来，第二批补齐试卷库维护与作答记录分支（见 §2.1）。

## 2. 已贯通的主线

`EP-01`（[`tests/product-docs/journeys/exam-production/create-content-template-and-generate.spec.ts`](../../../tests/product-docs/journeys/exam-production/create-content-template-and-generate.spec.ts)）
在**同一个数据目录、同一次启动**内用界面依次完成：

评分单元（`UI-GS-01/02`）→ 题型草稿与发布（`UI-IF-01/03`）→ 题组（`UI-IF-02/04`）
→ 试卷模板与绑定（`UI-TP-01/02`）→ 生成试卷（`UI-TP-05`，mock 语音合成）→ 加入试卷库（`UI-EL-01`）。

## 5. 结构性阻塞

1. **AI 与语音资产**：`MockAiServer` 只处理文本、语音合成与图像端点，没有音频转写；
   canonical 产品文档镜像只带轻量 Qwen TTS runtime。AI 评分、审查与抽查因此不可达，
   `UI-SR-02` 与 `UI-ST-06` 的本地 ASR 分支同样不可达。
2. **媒体桩未共享**：麦克风与播放器桩只存在于集成测试，产品文档套件拿不到，`UI-EL-02` 的录音路径不可达。
3. **无 URL 直达**：renderer 用 MemoryRouter，只能靠点击走到目标屏，长链路用例必须一次启动内跑完。
4. **重启与系统对话框**：需要重启应用的状态（存储迁移、外观）与原生目录选择对话框在流程测试里代价高。
5. **手册由声明生成**：正文来自步骤的 `action`/`expected` 文本，不是断言；措辞可能超出真正验证过的行为，
   新增步骤时要按实际断言写 `expected`，不要写成产品愿景。
