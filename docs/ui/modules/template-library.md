# 试卷模板

## 对象定位

试卷模板是可编辑的制卷规则，把页面、时间线、题型题组、评分单元和资源组织成一份考试结构。它不是一次运行的试卷。

- **试卷模板**是可反复编辑和维护规则的工作文档，不区分草稿与发布。
- **可运行试卷**由模板在生成时解析得到，是自包含快照；生成后再修改或删除模板都不改变已经生成的试卷。
- **函数库**是模板可复用的函数集合。本地函数库是独立于模板的工作文档；函数进入模板后成为模板内嵌的不可变快照。

## 能力边界

试卷模板提供：

- 本地模板的新建、编辑、保存、删除、导入与导出；
- 结构、页面与预览三种编辑视图；
- 页面、框架、函数调用和选择题节点的编辑，页面内容块、线性时间线、选择题视图与评分单元绑定的配置；
- 题型题组与评分单元的引用和绑定；
- 本地函数库的创建、函数编辑、导入、导出与删除；
- 以模板生成试卷，并把生成结果写入试卷库或导出为试卷文件；
- 内置模板的浏览、创建副本与生成试卷。

试卷模板不提供：

- 模板的草稿与发布状态；保存工作文档不执行严格语义校验，预览和生成才要求内容完整合法；
- 对内置模板的编辑、删除或工作文档导出；
- 对内置函数库的删除，以及对内置或导入函数库中函数的编辑；
- 在模板内改写评分单元的评分规则；模板只保存引用与题目输入；
- 学生端作答与评分。

**边界约束**：模板只允许引用可用且结构契约匹配的题型与评分单元；生成依据只能是最后一次成功保存的工作文档，从编辑器进入生成前会先保存当前修改。

## 状态与生命周期

- 模板工作文档以稳定标识与递增修订号标识，创建即持久化。保存以修订号判定新旧，过期副本的保存被拒绝，不会覆盖较新数据。
- 模板不区分草稿与发布。保存工作文档不触发严格业务校验；语义校验与编译在预览和生成时执行。
- 内置模板以不可变发布版本维护，同一模板跨版本保持稳定标识与递增版本号。内置模板只读，用户创建副本后得到可编辑的本地模板。
- 本地函数库是带修订号的独立工作文档，库内函数以稳定标识维护并随所属库统一读取、保存和删除。导入函数库和内置函数库是不可变发布版本，内置库不可删除。
- 函数进入模板后成为不可变快照。源函数后续修改、删除或内置版本停用都不改变已经嵌入的模板，也不改变已经生成的试卷。
- 删除本地模板会删除模板及其编辑内容，已经导出的试卷不受影响；删除本地函数库不影响已经嵌入其他模板的函数快照。

## 关键交互语义

- **模板库三视图**：内置模板、我的模板与函数库。内置模板默认展示，普通模板与内置模板都可按标签筛选。内置条目显示版本号，缺少题型或评分单元依赖的版本标记为不可用且不能生成试卷。本地模板提供编辑、生成试卷、导出与删除入口。
- **模板与试卷的差异**：模板保存结构、引用、绑定、时间线与函数；生成后的试卷保存解析后的题目、资源和评分上下文。两者不是同一对象，模板修改不会回流到已生成的试卷。
- **编辑视图**：结构视图展示包含根框架的可折叠节点树，支持选择节点、新增框架/页面/选择题、同级上下移动、子树复制与确认删除；页面视图在固定设计面上编辑内容块，支持单选、拖动、缩放、复制、删除与视图缩放；预览视图按编译展开顺序把每个页面的每个时间线步骤映射为一个画面，复用学生端选择题交互，切换画面或重新进入预览会清空答案与分页状态。
- **变更与保存**：编辑以整份文档快照维护撤销与重做，最近一次成功保存是干净基线。保存期间允许继续编辑，返回的新修订号会重定基到当前历史，既不覆盖新修改，也不让之后的保存使用过期版本。
- **引用与校验**：模板只保存评分单元的稳定标识，校验和编译读取最新正式版本，并把当时的完整定义快照写入试卷。校验错误定位到具体字段路径，由界面呈现给用户。
- **离开保护**：有未保存修改时，页面导航与窗口关闭都需要确认。
- **函数调用**：函数调用必须完整填写输入，并把每个手动出参映射到调用方作用域中的变量名。插入本地、导入或内置函数库中的函数会在一次保存中复制完整依赖闭包并改写内部引用，副本随目标文档保存，源库之后的变化不影响副本。基础组件库的预设节点直接插入节点内容，不生成函数调用。
- **生成设置**：必须为模板中的每个题型别名选择一个题组；模板包含语音时还必须为各音色选择语音配置，生成过程按所选配置合成录音。生成结果提供两个互不替代的保存动作：写入试卷库，或导出为自包含的试卷文件。至少完成其中一个保存动作后才能无确认离开结果页，未保存结果离开时必须确认丢弃。
- **导入冲突**：导入模板时，同标识且内容相同视为已存在；内容冲突时用户可以选择覆盖本地、以新标识导入为副本或取消。覆盖保留当前模板标识并把本地修订号递增，不使用过期修订号。
