# 题型库

## 对象定位

题型库是试卷内容的生产与复用中心，拥有两类对象：

- **题型**：规定一类内容需要哪些字段，以及 AI 应如何生成这些内容。已发布题型是不可直接修改的稳定对象，其身份由内容决定；草稿是它的编制态。
- **题组**：按某个已发布题型填写的一套具体内容，可在模板生成试卷时被复用。

题型定义属于低频维护，创建、检查和调整题组是日常主线。题型库还承载题型文件的导入与导出。试卷模板只引用已发布题型的稳定字段契约，并在生成试卷时从对应题型的题组中选择内容。

## 能力边界

题型库提供：

- 题型草稿的新建、编辑、保存、发布与删除；
- 已发布题型的浏览、完整定义查看、提示词与结构化输出的复制、复制为新草稿；
- 题组的新建、手工填写、整组保存与删除；
- 题组内容的整组 AI 生成、JSON 覆盖、单字段与批量 AI 生图、图片文件选择与剪贴板读取；
- 题型文件的导出与导入，包含全屏的题组勾选与冲突审查；
- 内置题型的版本维护与题组迁移处理。

题型库不提供：

- 已发布题型的直接编辑；修改从复制新草稿开始，是否发布为新的稳定题型由用户决定；
- 题组在不同题型之间的迁移入口；
- 题组的复制或克隆；
- 单字段保存；题组按整组提交；
- 评分执行与评分结果，这些属于作答记录模块。

**边界约束**：题型文件导入不能把接收设备不认识的内置题型降级为普通题型，也不能用文件覆盖本地已存在且内容不同的同标识题组。

## 状态与生命周期

- 题型草稿允许保存不完整内容；保存不触发发布校验。发布时集中校验名称、生成要求与字段结构，校验失败不产生已发布题型。
- 发布语义是先保存草稿再校验写入；相同内容已经存在时不创建重复副本。发布成功后草稿保留。
- 已发布题型不可直接修改；复制出的新草稿与原题型之间没有运行时关联，后续修改和再次发布都不改变原题型。
- 删除草稿不影响已发布题型。删除题组会一并删除题组内容与图片资源，不可恢复。
- 题组从创建时起就是持久化实体。创建时先命名并选择进入方式：手工填写进入空白表单，AI 生成只打开整组生成任务且不自动发起请求；取消创建不留下空题组。
- 内置题型与用户题型共用题组工作流。内置版本升级按变化分类处理：兼容更新自动应用，字段结构变化由用户选择迁移现有题组或保留旧版；变量契约不兼容时不能自动更新，当前版本继续保留并明确告知用户。内置题型从随包来源移除时，用户可以选择删除，或把旧版保留到用户分区。
- 题组标识在导入与内置迁移中保持不变。相同标识但内容不同是必须审查的数据冲突，不能通过更新时间或文件覆盖就地解决。

## 关键交互语义

- **首页双视图**：「题型」是默认视图，展示题型名称、题组数量、描述与内置来源；「草稿」展示尚未发布或继续维护的草稿。新建草稿入口位于草稿视图；导入题型是题型视图的次要操作，不占用主操作位。
- **题型详情双视图**：「题组」是默认视图，负责题组的创建、进入与删除；「题型定义」承载描述、生成要求与字段结构的查看，以及复制新草稿、复制提示词和结构化输出等低频维护操作。导出题型固定在详情页层级，先进入全屏选择页，不直接弹出系统保存对话框。
- **题组编辑**：表单是页面中唯一持续存在的编辑工作区。手工修改需要明确保存；有未保存修改时，页面导航与窗口关闭都需要确认。图片字段必须同时具备图片提示词和图片才能保存。
- **整组覆盖**：整组 AI 生成与 JSON 覆盖都是一次性模态任务，成功时原子替换整组内容并立即保存。对已有内容的覆盖在开始前明确说明覆盖范围并再次确认；生成、校验失败或用户取消时，原题组内容保持不变。AI 返回无效内容时可以转入 JSON 对话框检查原始结果。
- **图片生成**：单个图片字段可以选择文件、读取剪贴板或调用图像生成服务，生成结果在保存前只作为本地预览。批量生图按字段顺序逐个生成，要求全部图片字段都已填写提示词，全部成功后一次保存并覆盖对应旧图片。
- **草稿编辑**：字段组可以展开和折叠；添加字段或字段组时明确显示目标层级；字段标识无效或同层冲突时就地显示原因，不静默修复；删除含子节点的字段组前需要确认；发布校验结果可以定位到具体表单或字段节点。
- **文件交换**：导出列出题型下的全部题组，用户逐项勾选，每个题组的全部资源随题组整体交付。导入先选择文件，再在全屏审查页看到该题型的可导入、已存在与冲突题组：可导入项默认勾选，已存在项显示完成状态且不可重复勾选，冲突项不可勾选并说明原因。取消不写入任何内容。
