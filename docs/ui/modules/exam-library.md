# 试卷库

## 对象定位

试卷库拥有**试卷**对象：由试卷模板生成或从本地导入、可以直接运行的试卷快照，以自包含试卷包保存。
每份试卷记录标题、试卷包编号、导入时间、页数、资源数量与包大小。

试卷在对象链中的位置：试卷模板生成试卷，试卷运行产生作答包，作答包导入后成为作答记录的原始凭据。
试卷库不拥有作答记录，也不编辑试卷模板；它是生成产物的仓库，不是试卷编辑器。

## 能力边界

试卷库提供：

- 列出库中试卷，并按导入时间倒序排列；
- 从本地导入试卷包；
- 从列表直接开始考试；
- 删除试卷，并二次确认。

试卷库不提供：

- 修改试卷名称、题目、流程或任何内容；需要调整内容时回到对应试卷模板重新生成；
- 试卷详情页；
- 在库内导出试卷文件；导出自包含试卷文件由试卷模板的生成流程负责；
- 直接管理由试卷产生的作答记录。

**边界约束**：开始考试只使用库中已保存的试卷包；运行产生的作答包必须另存为文件后，才能由作答记录模块导入。

## 状态与生命周期

- **导入**：校验试卷包清单与声明的全部资源。包编号 与内容都与库中已有试卷一致时判为重复，不新增记录；包编号 相同但内容不同时报冲突且不写入；校验失败不产生记录。
- **在库**：导入成功后试卷持续保存在本地，直到被删除。删除不影响由该试卷产生的既有作答记录。
- **运行**：开始考试时先读取并校验试卷包，再进入考试流程。加载失败进入不可运行的错误状态，可重试或返回列表。
- **删除**：不可逆操作，必须二次确认；删除只移除试卷库中的试卷及其本地试卷包。

## 关键交互语义

- **列表口径**：每份试卷展示标题、试卷包编号、导入时间、页数、资源数量与包大小；同一导入时间按试卷包编号 倒序。
- **主操作层级**：开始考试是每份试卷的主入口；删除作为次要危险操作，不与开始考试争夺主操作层级。
- **重复与冲突**：以试卷包编号 和内容哈希共同判定导入结果，内容不同即拒绝覆盖已有试卷。
- **运行流程**：运行包含加载校验、考生登录（姓名与考生号必填）、按需的麦克风试录与回放确认、按时间线依次播放、倒计时与录音作答、生成作答包并保存；退出考试需要确认，且不生成作答包。
- **运行失败**：资源缺失或播放、录音失败会暂停考试流程，展示原因并允许重试当前步骤或重新生成作答包；加载失败可重新加载。
- **空状态**：库中没有任何试卷时显示空状态。
