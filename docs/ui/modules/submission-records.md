# 作答记录

## 对象定位

作答记录拥有**作答记录**对象：一次完整作答产生的原始凭据，以及与该凭据分开保存的评分状态、评分结果与结算归属。
原始内容——作答人姓名、考生号、选择答案、录音及其他原始答案——不可修改；评分只产生独立结果，不改写原始作答。

对象链：试卷运行产生作答包，作答包导入后成为作答记录；记录经评分得到评分结果，经结算归入结算批次，并据此生成评分报告。
作答记录不拥有试卷与试卷模板；它保存的是试卷在某一时刻运行的结果快照。

## 能力边界

作答记录提供：

- 导入与导出作答包；
- 删除作答记录；
- 单条或批量开始、继续评分；
- 人工评分与 AI 评分，客观题由系统自动判定；
- AI 结果审查；
- 将已完成评分的记录结算为批次；
- 查看已结算记录的评分报告；
- 对已结算记录重新评分。

作答记录不提供：

- 修改原始作答内容；
- 旧的“未批改 / 已批改”上下分区；
- 批次级的成绩表或报告导出；评分报告按单条记录查看；
- 评分历史版本；重新评分会删除旧评分结果与报告。

**边界约束**：AI 评分依赖设置中已配置并启用的模型；没有可用模型时无法开始 AI 评分。

## 状态与生命周期

- **未结算**包含三种进度：未评分、评分中、可结算（全部评分单元完成）。单项评分提交后不可修改；客观题在准备评分时自动完成，不进入人工或 AI 主观评分流程。
- **评分方式**在一次会话开始时二选一：人工评分逐题填写分数与评语；AI 评分先选语音识别模型与文本评分模型，再依次处理本场全部未评分单元。一次会话只使用一种方式。
- **结算**校验参与记录全部可结算，计算总分并记录结算时间与批次。未结算记录可以暂缓结算，已完成的评分继续保留。
- **已结算**记录只在结算后出现，按结算批次组织；只有已结算记录能查看评分报告。
- **删除**：未结算记录删除后移除原始作答包与暂存评分；已结算记录删除后同时移除其结算归属与报告数据。删除不可逆。
- **重新评分**：删除该记录的评分、结算结果与报告，保留原始作答包，作为未评分记录回到未结算列表；从原批次中只移除该记录，批次为空时删除空批次。

## 关键交互语义

- **两个一级标签**：未结算为默认视图，已结算按批次组织；不使用“未批改 / 已批改”分区。
- **批量评分**：按列表顺序逐条作答、逐个评分单元推进；已提交的评分单元保留，继续评分从第一个未评分单元开始。
- **AI 失败处理**：单题失败不中断其他题目；失败题单独列出并可重试。全部题目成功前不能完成本次 AI 评分或进入审查。
- **AI 结果留存**：保存所选模型、录音转写、纠错描述、评分提示词、模型原始响应、结果与失败信息。暂停后重新进入会话时，已成功且模型选择相同的题目不重复生成。
- **AI 审查**：整场成功后可选完成（直接采用全部结果）、全部审查或抽查。抽查提供两种规则：填写整场抽查总题数，或按评分单元分别填写抽查题数；显示名称相同但定义不同的评分单元不合并。
- **分数约束**：AI 返回结果必须是只含 score 与 comment 的严格 JSON，score 在 0 到满分之间且最多三位小数，违规题目判为失败。审查可修改分数与评语，分数约束相同；审查确认后的结果仍标记为 AI 评分结果。
- **结算边界**：结算页列出本次会话全部作答及各自进度；“本次结算”只把全部评分完成的记录结算为一个批次，没有可结算记录时不可用；“下次结算”保留进度并返回未结算列表；结算整体成功或失败，不产生部分批次。结算成功后返回已结算视图并展开本次批次。
- **报告口径**：报告包含总分与满分、逐题分数与评语、题目、评分标准与学生答案；客观题另含正误与解析。
