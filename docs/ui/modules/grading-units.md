# 评分单元

## 对象定位

评分单元是"一个题目如何收集答案、如何计算分数"的稳定契约，不是某一份试卷里的临时评分备注，也不是评分结果本身。

评分单元定义评分管道、答案槽位、模板输入、满分、答案说明、评分标准与可选的 AI 补充提示词。试卷模板引用评分单元，模板只保存引用与题目输入；实际评分约束来自模板校验和生成时读取的正式版本，并随试卷固化为快照。

## 能力边界

评分单元提供：

- 评分单元的新建、复制、编辑与保存；
- 评分管道（客观题、固定朗读、自由口语）与答案槽位（文本、固定语音、自由语音）的定义；
- 模板文本输入的定义与必填性；
- 名称、描述、满分、答案槽位说明、模板输入说明、评分标准与 AI 补充提示词的编辑；
- 内置评分单元的浏览与复制并修改；
- 评分单元定义的导出，以及非内置评分单元的删除。

评分单元不提供：

- 独立草稿库；新建与复制时直接填写完整内容，并在第一次保存时校验生效；
- 第一次保存后的结构修改；评分管道、答案槽位及其顺序、模板输入固定，之后只能修改数据；
- 内置评分单元的修改与删除；
- 具体试卷的临时评分规则调整；
- 给学生打分、评语与报告，这些属于作答记录模块。

**边界约束**：删除评分单元不执行模板引用检查，删除后引用它的模板会在校验时失败。删除也不改写已经生成的试卷中保存的评分单元快照。

## 状态与生命周期

- 新建或复制时产生结构可编辑的编辑阶段，结构、名称、分值与评分标准在同一页面完成。第一次保存同时校验结构与评分数据，校验失败不写入。
- 第一次保存后结构固定。之后的保存只允许修改数据：名称、描述、满分、答案槽位说明、模板输入说明、评分标准、AI 补充提示词。结构不接受变化。
- 每次成功保存递增修订号；读取会拒绝结构与记录不一致的数据。
- 内置评分单元完全只读，需要调整时必须复制并保存为我的评分单元。复制得到的是结构可编辑的新对象。
- 旧版本留下的草稿库数据与对应界面仍然存在，用于读取旧数据；主界面不创建、不展示也不依赖草稿库。
- 删除评分单元立即生效。历史作答中已经保存的评分单元快照不受删除影响。

## 关键交互语义

- **来源双视图**：我的评分单元与内置评分单元，默认显示内置评分单元。列表展示名称、评分管道、满分与描述；内置项只提供复制并修改，我的评分单元提供编辑与删除。
- **结构编辑阶段**：只有新建与复制时结构可编辑。此时可以选择评分管道、增减和排序答案槽位、定义模板文本输入及其必填性。评分管道决定答案槽位类型：客观题固定为单个文本槽位，固定朗读与自由口语可以维护多个语音槽位。系统内置输入不可删除，也不可修改必填性。
- **冻结结构阶段**：第一次保存后进入冻结结构视图，页面只展示评分管道、答案槽位与模板输入的摘要，不再出现结构编辑控件；数据字段继续可编辑。
- **保存语义**：保存同时校验结构与评分数据。校验失败时保留本次编辑内容并就地显示校验信息，不写入；保存成功后以返回结果刷新页面基线。
- **未保存保护**：有未保存的数据修改时，页面导航与窗口关闭都需要确认。
- **导出**：导出提供当前评分单元定义的完整文件；有未保存修改时导出不可用。
- **删除**：删除前需要确认，界面说明引用该评分单元的模板将无法通过校验。删除立即生效，不改写历史试卷中的评分单元快照。
