# 工作台

## 对象定位

工作台是应用首页与产品封面。它**只读汇总**其他模块已经产生的对象：试卷、作答记录、题型、题组草稿、试卷模板、评分单元；
不拥有任何独占业务对象，也不产生新的业务对象。

## 能力边界

工作台提供：

- 当前状态汇总：试卷、待评分、题型、试卷模板、评分单元的数量；
- 快捷入口：制作试卷、进入试卷库、处理作答记录；
- 「最近工作」：按时间汇总最近产生的试卷、作答记录与试卷模板；
- 「待处理」：未结算作答的数量、结算完成比例与未完成题型数。

工作台不提供：

- 任何编辑、删除、评分或结算操作；
- 角色划分或权限控制。工作台不是教师端或学生端门户，不改变其他模块的可见性。

**边界约束**：工作台中出现的每个操作都必须能从对应一级模块独立进入并完成，快捷入口不能成为某项能力唯一入口。

## 状态与生命周期

- 工作台不使用持久化状态；每次进入页面重新查询各仓储，读取失败时进入「部分状态暂不可用」。
- 只读汇总值不影响任何对象的生命周期；页面内的导航会离开工作台并进入目标模块。

## 关键交互语义

- **一级导航常驻**：工作台、试卷库、作答记录、题型库、试卷模板、评分单元固定在主导航，设置固定在底部导航；顺序为工作台、试卷库、作答记录、题型库、试卷模板、评分单元、设置。
- **汇总口径**：试卷数与题型数取已发布对象；「待评分」取未结算作答数；结算完成比例 = 已结算 ÷（未结算 + 已结算）。
- **最近工作**：最多展示 4 条，按试卷、作答记录、试卷模板的顺序合并后截断；作答条目按「已结算 / 可结算 / 待评分」显示状态并导航到对应界面。
- **空状态**：没有任何最近工作时提供进入试卷模板的入口。
