# 函数编辑器 · UI-TP-04

- 路由：`/templates/libraries/:libraryId/functions/:functionId`
- 入口：`UI-TP-02` 模板编辑器左栏「本地」函数库 → 函数卡片「编辑<函数名>」；`/templates` 为无模板上下文时的返回目标
- 对象：本地函数库（版本）、函数（名称、输入/输出签名、函数体、评分单元引用）

## 布局

专注式全屏工作区（`layout: focus`，不显示一级导航），与 `UI-TP-02` 同构：

1. 工具栏：左侧「返回模板编辑」与函数身份（函数名 + `<函数库名> · 版本 <版本号>`，有未保存修改时追加 `· 未保存`），右侧撤销 / 重做 / 保存。
2. 工作区（`ResizableSplit`，`label="调整函数库宽度"`，初始 300、左栏最小 240、右栏最小 720）：
   - 左栏「函数库」素材面板，标题右侧标注「添加到当前选择之后」；来源标签页「内置 / 导入 / 本地」；函数卡片按来源插入。
   - 中右栏（`ResizableSplit`，`label="调整属性栏宽度"`，初始 350、中栏最小 420、右栏最小 300）：
     - 中栏编辑视图标签页（`aria-label="编辑视图"`）：结构 / 页面 / 预览，默认「结构」。
     - 右栏属性面板，或在预览视图下换成「函数预览配置」检查器。
3. 覆盖层：放弃修改确认、删除节点确认。

左栏在「本地」来源下会过滤掉当前正在编辑的函数本身，避免函数递归调用自身；其余本地函数可被调用。函数身份副标题中的版本号是函数所在本地函数库的版本，不是单个函数的版本号。

## 文案

- 身份：函数名缺失时 `未命名函数`；副标题 `<函数库名> · 版本 <版本号>` 或追加 ` · 未保存`；函数库名缺失时 `未命名函数库`；`正在加载`、`无法加载`
- 操作：`返回模板编辑`、`撤销`、`重做`、`保存`、`正在保存`
- 素材面板：`函数库`、`添加到当前选择之后`、`内置`、`导入`、`本地`、`正在加载函数库...`、`暂无可用函数`
- 素材空状态：`暂无内置函数库` / `暂无导入函数库` / `暂无本地函数库`；描述 `当前没有可用的内置组件`、`导入函数库后会显示在这里`、`当前没有其他可调用的本地函数`
- 函数卡片：名称缺失时 `未命名函数`；类型副标题 `框架`、`页面`、`选择题`、`变量`、`函数`；插入操作 `添加<名称>`（组件）或 `调用<名称>`（函数）
- 结构视图：`正在加载函数` / `函数不可用`
- 页面节点：`时间线`、`暂无时间线`、`编辑内容`、`查看内容`、`TTS 播放`、`倒计时`、`录音`
- 属性小节：`函数`、`评分单元`、`节点属性`、`内容块`
- 函数签名：`输入`、`添加输入`、`没有函数输入`、`输出`、`添加输出`、`没有函数输出`；字段标签 `名称`、`类型`、`形状`、`每页题数`、`来源`、`未选择`；形状选项 `单题`、`连续范围`、`完整题组`；类型选项 `文本`、`数字`、`文件`、`录音`、`选择题组`、`选择题答案`
- 预览：`函数预览配置`、`预览范围`、`节点`、`画面`、`刷新预览`、`函数输入`、`完整题组`、`当前时间线`、`类型`、`来源`、`暂无时间线信息`、`预览错误`、`校验结果`
- 确认对话框：`放弃未保存的修改？` / `离开后，本次尚未保存的函数修改会丢失。` / `放弃修改`；`删除节点“<nodeId>”？` / `该节点及其包含的全部子节点都会被删除。` / `删除`
- 加载失败：`本地函数库不存在。`、`本地函数不存在。`

## 状态与恢复

- **加载中**：身份副标题显示「正在加载」，结构视图显示「正在加载函数」，属性输入禁用。
- **加载失败**：函数库或函数不存在时错误为 `本地函数库不存在。` 或 `本地函数不存在。`，显示在属性面板 `role="alert"`；其他失败文案来自 `templateErrorMessage`。
- **编辑错误**：文档操作被拒绝时错误文本为 `<错误码>: <路径>`，写入属性面板 `role="alert"`；成功的编辑会清除错误。
- **素材加载失败**：函数库清单查询失败时错误显示在左栏 `role="alert"`，中栏仍可编辑。
- **保存失败**：错误写入属性面板 `role="alert"`，函数保持未保存状态，可重试。
- **未保存离开**：页内导航由未保存守卫拦截，或由返回按钮触发放弃确认；确认后丢弃本次函数修改，取消则留在编辑器。
- **预览失败**：检查器显示预览错误或校验结果；校验结果点击后定位到函数体内对应节点。
- 编辑历史上限 200 步；保存成功后当前状态成为干净状态。

## 有损操作

- **删除节点**：不可逆。必须二次确认；确认文案说明该节点及其全部子节点都会被删除。
- **放弃未保存修改**：不可逆。离开有未保存修改的函数编辑器必须确认；确认文案说明本次函数修改会丢失。
- 保存会覆盖该函数在本地函数库中的当前内容，并使函数库版本递增；这是显式「保存」动作，不额外确认。已经嵌入模板的函数副本不随之更新。
- 本页不提供删除函数或删除函数库操作；这两个操作在 `UI-TP-02` 的函数库面板中完成。

界面使用「试卷模板」「函数库」「题型」「题组」「评分单元」「时间线」「版本」，与 [`../glossary.md`](../glossary.md) 一致。
本批迁移后的实际文案：

- 属性小节标题为 `评分单元`；评分单元面板为 `暂无正式评分单元`、`评分单元不存在或编号无效`。
- 预览检查器使用 `当前时间线`、`暂无时间线信息`；编译错误说明使用 `题型`、`评分单元`、`采集器`、`时间线` 等用户用词。
- 身份副标题显示 `版本 <版本号>`。

本屏不再出现 `Schema`、`Interface`、`Timeline`、`Collector`、`revision` 等内部术语。

## 产物

- 保存的结果是该函数在本地函数库中的内容更新、函数库版本递增；后续插入该函数的模板会引用新内容，已嵌入的旧副本不回溯更新。
- 「返回模板编辑」回到 `UI-TP-02`（携带 `templateId` 时），否则回到 `UI-TP-01`。
- 本页不产出文件，也不直接生成试卷。

## 锚点

```yaml
anchors:
  visual: unverified
  behavior: electron-app.spec.ts › creates, edits and reloads a persisted template（tests/integration/electron-app.spec.ts）
```

行为锚点：`electron-app.spec.ts › creates, edits and reloads a persisted template` 覆盖新建函数、改名、保存与版本号断言。`TP-01` 与 `TG-01` 都不进入函数编辑器，因此素材插入、结构编辑、函数签名、预览与删除确认仍未覆盖。
