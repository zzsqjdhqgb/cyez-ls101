# 外观设置 · UI-ST-04

- 路由：`/settings/appearance/*`
- 入口：设置总览（`UI-ST-01`）→「外观」
- 对象：外观设置（主题偏好、减少动态效果）

## 布局

1. 加载/不可用状态：整块状态文本，携带错误时额外显示「恢复默认设置」按钮。
2. 正常状态：设置内容区，包含两个设置分组：
   - `主题`：一行「界面主题」下拉选择。
   - `交互`：一行「减少动态效果」开关。
3. 分组上方可选错误提示（`role="alert"`）。

## 控件清单

| 名称 | 类型 | 默认 / 加载 / 禁用 / 错误 | 触发结果 | 快捷键 |
| --- | --- | --- | --- | --- |
| 界面主题 | 下拉选择（`aria-label="界面主题"`） | 保存中禁用；不可用状态下不渲染 | 立即应用并保存主题偏好 | 无 |
| 减少动态效果 | 开关（`role="switch"`，`aria-label="减少动态效果"`） | 保存中禁用；不可用状态下不渲染 | 立即应用并保存动态效果偏好 | 无 |
| 恢复默认设置 | 按钮 | 仅在存在错误且设置不可用时出现；保存中禁用 | 重置外观设置 | 无 |

下拉选项：`跟随系统`（system）、`浅色`（light）、`深色`（dark）。

## 文案

- 加载中：`正在加载外观设置...`
- 不可用且无错误：`外观设置不可用`
- 不可用且存在错误：显示错误文本，并提供 `恢复默认设置`
- 分组标题与描述：`主题`（调整应用的整体显示方式。）、`交互`（控制界面反馈和动态效果。）
- 行标签与描述：`界面主题`（选择浅色、深色或跟随操作系统。）、`减少动态效果`（减少非必要的过渡和动画。）
- 保存失败：设置内容区顶部显示错误文本（`role="alert"`）

## 状态与恢复

- **加载中**：整块显示 `正在加载外观设置...`。
- **不可用**：整块显示 `外观设置不可用`；若同时有错误，显示错误文本与「恢复默认设置」按钮。
- **保存中**：两个控件禁用，防止并发修改。
- **保存失败**：页面顶部显示错误；控件保持可用，可重试。
- 变更是即时生效的：选择或切换后立即应用，不提供单独的「保存」按钮。

## 有损操作

无。外观设置可随时改回；「恢复默认设置」是显式操作，不涉及数据删除。

## 术语

界面使用「外观」「主题」「减少动态效果」，与 [`../glossary.md`](../glossary.md) 一致。
本页不出现内部术语。

## 产物

- 修改后的主题与动态效果偏好被持久化，作用于整个应用界面。
- 本页不产生业务对象。
