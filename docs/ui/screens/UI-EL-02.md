# 考试运行 · UI-EL-02

- 路由：`/exams/player`
- 入口：试卷库列表 → 点击某份试卷的「开始考试」
- 对象：一份试卷、作答人身份、作答包

## 布局

沉浸式全屏界面，不显示一级导航。界面分两层。

**外层装载**（由试卷库交接后进入）：

1. 加载态：整屏居中提示 `正在验证试卷资源...`。
2. 错误态：整屏居中，告警图标、标题「无法开始考试」、失败原因，以及「返回考试列表」和（仅当携带了试卷标识时）「重试」。未携带试卷标识时直接进入错误态，原因为「未指定要开始的试卷。」。

**播放器阶段**（固定 1200×880 设计画布，按窗口宽高取较小比例等比缩放并居中；录制/播放运行时不显示浏览器控件）：

1. 考生登录：居中表单，含 eyebrow「考生登录」、试卷标题、`姓名` 与 `考生号` 两个输入框和操作行。
2. 麦克风测试：仅为含录音作答的试卷显示。含三步骤清单「选择设备 / 完成试录 / 回放确认」、录音设备选择行、试录与回放区域、操作行。
3. 作答页：上下两段。上方 1200×800 内容视口渲染试卷页面（页面内容在样式隔离的阴影容器内呈现，可含文本块、图片块和选择题块）；下方 80 像素状态条分三列：左「第 <当前页> / <总页数> 页」，中「状态文字 + 进度条 + 剩余秒数」，右「退出」。
4. 消息态：加载、装载失败、流程暂停、归档失败、正在生成作答包、考试完成等状态共用同一整屏消息面板结构（标题 + 说明 + 操作按钮）。
5. 退出确认：居中模态对话框，覆盖在任意阶段之上。

## 文案

**外层装载**

- 加载中：`正在验证试卷资源...`
- 错误：标题 `无法开始考试`；未携带试卷标识时原因 `未指定要开始的试卷。`；按钮 `返回考试列表`、`重试`（仅携带试卷标识时）

**考生登录**

- eyebrow：`考生登录`
- 标题：试卷标题
- 字段标签：`姓名`、`考生号`
- 校验错误：`姓名和考生号不能为空`
- 按钮：`退出`（仅允许退出时）、`继续`

**麦克风测试**

- eyebrow：`设备检查`；标题 `麦克风测试`；说明 `考试包含录音作答，请先确认录音和回放声音正常。`
- 步骤清单：`选择设备`、`完成试录`、`回放确认`
- 设备行标签 `录音设备`；下拉占位 `正在检测设备...`、`未检测到麦克风`、`麦克风 <序号>`（设备无名称时）
- 设备图标按钮：`重新检测录音设备`
- 试录进行中：`正在录音`、`请正常说话 · <剩余秒数> 秒`
- 试录完成后：`试录完成`、`请完整播放刚才的录音`、`播放试录`
- 回放完成后：`回放完成`、`确认声音清晰后即可开始考试`、`再听一次`、`声音正常，开始考试`
- 未试录时：`正在检测麦克风`（检测中）或 `准备试录`、`试录时长 3 秒`、`开始试录`
- 按钮：`退出`、`重新试录`
- 错误文案：权限被拒 `无法使用麦克风，请在系统设置中允许麦克风权限后重新检测。`；无设备 `未检测到麦克风，请连接设备后重新检测。`；设备被占用 `麦克风暂时无法使用，请关闭其他占用麦克风的应用后重试。`；回放失败 `试录回放失败，请重新试录。`；无音频数据 `试录没有产生音频数据`

**作答页与阶段消息**

- 状态条：`第 <当前页> / <总页数> 页`；状态文字默认 `正在准备`，播放阶段 `正在播放`，倒计时阶段 `准备作答`，录音阶段 `准备录音` 与 `正在录音`；状态文字右侧显示剩余 `<秒数>s`
- 加载：`正在加载考试` / `正在验证清单和全部考试资源...`
- 装载失败：标题 `考试加载失败`；按钮 `重新加载`、`退出`
- 流程暂停（步骤失败）：标题 `考试流程已暂停`；按钮 `重试`、`退出`
- 归档失败：标题 `作答归档生成失败`；按钮 `重试`、`退出`
- 正在生成作答包：`正在生成作答包` / `正在整理答案、录音和考试附件...`
- 考试完成：`考试完成` / `作答包已成功保存。` / 按钮 `完成`
- 数据错误：标题 `考试数据错误` / `当前页面或时间线动作不存在。`
- 保存作答包的系统对话框：标题 `保存作答包`；默认文件名 `作答-<ISO 时间戳>.lssubmission`（时间戳中的 `:` 替换为 `-` 并去掉毫秒）；文件类型名 `LS101 作答包`（扩展名 `lssubmission`、`zip`）

**退出确认**

- 标题：`退出考试？`；正文：`当前考试进度不会生成作答包。`；按钮 `继续考试`、`确认退出`

## 状态与恢复

- **装载中**：`正在验证试卷资源...`；此时不渲染播放器。
- **装载失败**：进入「无法开始考试」错误态。携带试卷标识时可「重试」，或「返回考试列表」；未携带标识时只能返回。
- **身份校验失败**：停留在考生登录页，显示 `姓名和考生号不能为空`，已填内容保留。
- **麦克风检测失败或无设备**：停留在麦克风测试，错误显示在页内，可「重新检测录音设备」重试。
- **时间线步骤失败**（资源缺失、音频播放失败、录音设备出错、录音无数据）：进入「考试流程已暂停」，显示具体原因，可「重试」当前步骤；重试会重新执行当前步骤并重置计时。
- **归档失败**（保存作答包被取消或写入失败）：进入「作答归档生成失败」，可「重试」重新生成并再次弹出保存对话框。取消保存对应文案 `需要保存作答包才能完成考试。`，即不保存无法结束考试。
- **退出确认**：任何阶段（麦克风测试、作答页、错误态）的「退出」都先弹确认框；「确认退出」丢弃当前进度且不生成作答包，返回试卷库；「继续考试」关闭对话框并保持原状态。
- **刷新或重新进入**：页面以查询参数中的试卷标识重新装载并从头开始，不恢复之前的作答进度。
- **作答录音**：录音按时间线自动开始与停止，用户不手动控制录制；试录与正式录音使用同一个已选设备。

## 有损操作

- **确认退出**：不可逆地放弃本次考试进度，不生成作答包。必须经过退出确认对话框二次确认。
- **提交身份后无法返回修改**：进入麦克风测试或作答后不再提供改回姓名与考生号的入口；退出即放弃进度。
- **提交本题选择**：选择题一经选择即写入本次作答，作答页内没有单独的撤销入口。

## 术语

`试卷`、`试卷库`、`作答包`、`考生号`、`麦克风`，与 [`../glossary.md`](../glossary.md) 一致。界面不出现 `ExamPlayer`、`SubmissionPackage` 等内部术语。

## 产物

- 完成作答并成功保存后产生一个作答包文件（`.lssubmission`），由用户选择保存位置。
- 完成态点击「完成」返回试卷库，原试卷仍可再次使用。
- 本次产生的作答包可在 [`UI-SR-01`](./UI-SR-01.md) 中导入为作答记录。
- 中途退出不产生任何产物。
