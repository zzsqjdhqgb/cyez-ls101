# 题型导入 · UI-IF-06

- 路由：`/interfaces/import`
- 入口：题型库列表（`UI-IF-01`）「题型库操作 → 导入题型」并在系统文件选择中选中 `.lsinterface` 文件后进入
- 对象：待导入题型、文件内题组

## 布局

专注式全屏审查页（`InterfaceTransferPage.module.css`），不显示一级导航：

1. 页头：左侧「题型库 / 导入题型」眉题、标题「审查题型文件」与文件名；右侧「取消导入」。
2. 主体卡片：三格汇总（题型 / 题型身份 / 可导入题组），下方是 `文件内的题组` 区标题与已选计数，再下面是题组勾选列表。
3. 底部粘性操作条：`取消` 与 `导入选中的题组`。

页面依赖从题型库传入的导入会话。直接打开本路由（没有会话）时只显示单卡片空状态「没有待导入的题型文件」与「返回题型库」。

## 文案

- 眉题：`题型库 / 导入题型`
- 标题：`审查题型文件`；副标题为文件名 `<filename>`
- 页头操作：`取消导入`
- 汇总：`题型`、`题型身份`、`可导入题组`；身份取值为 `内置题型 · <builtinKey>` 或 `用户题型`；可导入题组为可导入状态的条数
- 列表区：标题 `文件内的题组`；计数 `已选择 <数量> 个`
- 题组行：名称；资源说明 `包含 <数量> 个资源文件` 或 `不包含图片资源`
- 题组状态：`可以导入`（可导入）；`本地已经存在相同内容`（本地已有完全相同内容）；`同一题组标识对应的内容不同`（身份冲突）；`该题组标识已被另一题型占用`（其他题型占用）；`文件内容不完整`；`接收设备不认识这个内置题型`
- 底部操作：`取消`、`导入选中的题组`（导入中 `正在导入...`）
- 成功提示：`题型已导入`
- 无会话空状态：`没有待导入的题型文件`、按钮 `返回题型库`

## 状态与恢复

- **无导入会话**：直接打开 `/interfaces/import` 或会话失效时不读取文件，只显示空状态与「返回题型库」。
- **导入失败**：错误写入页面错误条，勾选状态保持不变，按钮恢复可点以便重试；不写入任何题组。
- **取消导入**：页头「取消导入」与底部「取消」都结束会话并返回题型库，不写入任何内容。
- **状态判定**：文件内每个题组按本地身份判定为可导入、已存在、身份冲突或其他题型占用；已存在与冲突项不可勾选，导入不会覆盖本地内容。
- **内置题型文件**：内置题型文件只有在接收端认识该内置题型时才可导入；无法识别的内置题型其题组显示冲突原因，不能降级为普通题型导入。
- **题型已存在**：题型身份与本地相同时按身份规则跳过或合并，页面不显示进度；完成后统一提示 `题型已导入`。

## 有损操作

- **导入**：向题型库写入题型与所选题组及其资源。它不覆盖本地题组：本地不存在同标识题组时才写入，内容完全相同则跳过，内容不同或被其他题型占用则禁止勾选。导入结果不回滚已成功写入的条目。

## 术语

界面使用「题型」「题组」「题型库」「导入」「内置题型」「用户题型」，与 [`../glossary.md`](../glossary.md) 一致。
界面不出现 `Interface`、`Instance`、`UUID`、`Package` 等代码术语；冲突原因文案用「题组标识」而非 `UUID`。本页无内部术语泄漏。

## 产物

- 成功导入产生接收方题型库中的题型与题组；返回 `UI-IF-01`，可在其中打开新题型进入 `UI-IF-02`。
- 取消或无会话时不产生任何对象。
