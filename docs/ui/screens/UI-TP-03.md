# 内置模板查看 · UI-TP-03

- 路由：`/templates/builtin/:templateId`
- 入口：模板库列表「内置模板」标签页 → 行内「查看」
- 对象：内置模板（只读）

## 布局

与 `UI-TP-02` 相同的专注式全屏工作区，但以只读模式渲染。不显示一级导航，退出路径只有工具栏「返回模板」「创建副本」与「生成试卷」。

与 `UI-TP-02` 的差异：

1. 工具栏身份副标题固定为「内置模板 · 只读」，不显示 revision；操作组只有「创建副本」，没有撤销、重做、保存、导出模板；最右仍有「生成试卷」。
2. 左栏「函数库」标题右侧显示「只读」，没有「导入函数库」「新建本地函数库」，函数库分组与函数卡片不渲染任何操作按钮。
3. 结构视图节点树不渲染上移、下移、复制、删除节点操作；页面节点行内按钮为「查看内容」且不渲染添加时间线入口。
4. 属性面板的「名称」「描述」「标签」「评分 Schema」「节点属性」「内容块」全部禁用，不能修改模板。
5. 预览视图仍可切换画面、选择题型对应的题组（`Interface 实例` 下拉不禁用）并刷新预览。

## 文案

- 身份：名称缺失时 `未命名模板`；副标题 `内置模板 · 只读`、`正在加载`、`无法加载`
- 操作：`返回模板`、`创建副本`、`正在创建`、`生成试卷`、`查看内容`
- 函数库：`函数库`、`只读`、`内置`、`导入`、`本地`；空状态 `暂无内置函数库` / `暂无导入函数库` / `暂无本地函数库`；函数为空 `暂无函数`
- 结构视图：`正在加载模板` / `模板不可用`
- 页面节点：`时间线`、`暂无时间线`、`TTS 播放`、`倒计时`、`录音`
- 属性小节：`全局属性`、`评分 Schema`、`节点属性`、`内容块`
- 预览：`预览序列`、`预览配置`、`预览范围`、`刷新预览`、`当前 Timeline`、`暂无 Timeline 信息`、`请选择实例`、`未命名实例`；胶片条状态 `预览加载失败`、`正在生成预览...`、`模板未通过校验`、`所选节点不产生页面`
- 复制结果提示：`已创建模板副本“<名称>”`

## 状态与恢复

- **加载中**：身份副标题显示「正在加载」，结构视图显示「正在加载模板」，属性输入禁用。
- **加载失败**：模板不存在或查询失败时身份副标题为「无法加载」，结构视图显示「模板不可用」；文案来自 `templateErrorMessage`，显示在「全局属性」`role="alert"`。页面不提供页内重试，可重新进入或返回模板库。
- **只读边界**：所有写操作被禁用；编辑历史为空，不会产生未保存状态，因此离开本页不需要确认。
- **预览失败**：预览检查器显示「预览加载失败」或「模板未通过校验」，校验结果列出说明与路径，点击可定位到节点。
- 本页不修改内置模板，也不产生模板新版本。

## 有损操作

无。内置模板查看不提供删除、覆盖、重置或保存操作；「创建副本」只新增本地模板，不改变内置模板；「生成试卷」跳到独立流程，不修改当前对象。

## 术语

界面主体使用「试卷模板」「内置模板」「题型」「题组」「函数库」，与 [`../glossary.md`](../glossary.md) 一致。只读面板沿用 `UI-TP-02` 的同一套控件，因此同样出现内部术语泄漏：`Interface 配置`、`Interface 实例`、`选择 Interface`、`评分 Schema`、`Schema 不存在或 ID 无效`，以及编译错误文案中的 `Interface`、`Schema`、`Timeline`、`Collector`。这些与 [`../open-questions.md`](../open-questions.md) 第 1 条同类，本规格按 v0.4.1 实际文案记录。

## 产物

- 「创建副本」产出一个本地模板并进入 `UI-TP-02`。
- 「生成试卷」进入 `UI-TP-05` 的内置模板分支。
- 本页自身不产生业务对象，也不改变内置模板。
