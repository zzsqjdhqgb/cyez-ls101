# 许可激活 · UI-OV-01

- 触发：运行时（非路由）。应用启动时若本机许可状态不是「已激活」，本屏替代主应用渲染。
- 入口：应用启动
- 对象：本机许可（邀请码、激活状态、截止时间）

## 布局

本屏是一个覆盖层界面，不占用业务路由，也不显示一级导航：

1. 顶部是应用标题栏，只显示应用图标与名称，不显示侧边导航；窗口的最小化、最大化、关闭控件仍然可用。
2. 主体是居中面板：产品标识（应用名 `曹二听说101` 与副标题 `英语听说考试系统`），随后是状态区，底部是意见征集入口。
3. 状态区有两种形态：
   - **激活态**（许可未激活）：盾牌图标、标题 `激活曹二听说101`、说明文字、邀请码表单、截止时间。
   - **到期态**（许可已过期）：盾牌叉号图标、标题 `使用权限已到期`、说明文字、截止时间；不显示邀请码表单。
4. 意见征集入口在两种形态下都显示，其错误提示出现在按钮下方。

触发与关闭：

- 触发条件：启动流程确认许可状态不是「已激活」时进入本屏；激活截止时间已过时直接进入到期态。
- 本屏没有取消、跳过或返回入口，用户无法在应用内绕过许可进入工作台。
- 本屏不是模态对话框，可以用窗口关闭控件退出应用；关闭应用不会改变许可状态。

## 文案

- 产品标识：`曹二听说101`、`英语听说考试系统`
- 激活态：标题 `激活曹二听说101`，说明 `请输入项目方提供的邀请码以继续使用。`
- 邀请码标签：`邀请码`
- 提交按钮：`激活并进入`，提交中 `正在激活`
- 激活态截止时间：`临时许可有效至` + `<日期>（北京时间）`
- 到期态：标题 `使用权限已到期`，说明 `本阶段的临时许可已经结束，请联系项目负责人获取后续授权。`
- 到期态截止时间：`许可截止时间` + `<日期>（北京时间）`
- 截止时间格式：按北京时间显示为 `<年>年<月>月<日>日 <时>:<分>（北京时间）`
- 意见征集按钮：`参与激活方式意见征集`
- 错误提示（均为 `role="alert"`）：
  - `许可证服务不可用，请重新启动应用。`
  - `邀请码不正确，请检查后重试。`
  - `暂时无法验证邀请码，请稍后重试。`
  - `意见征集页面暂时无法打开，请重新启动应用。`
  - `意见征集页面暂时无法打开，请稍后重试。`

## 状态与恢复

- **空闲**：邀请码自动聚焦，可输入；为空时无法提交。
- **提交中**：邀请码输入与提交按钮禁用；按钮显示 `正在激活`。提交期间意见征集按钮仍可用。
- **激活失败**：输入恢复可用，页面显示 `邀请码不正确，请检查后重试。`，已输入的邀请码保留，可直接重试。
- **校验服务异常**：显示 `暂时无法验证邀请码，请稍后重试。`，可重试。
- **许可服务缺失**：提交时显示 `许可证服务不可用，请重新启动应用。`；该错误不改变输入可用性，但无法完成激活。
- **激活结果已到期**：不显示错误，页面切换为到期态。
- **启动即到期**：直接进入到期态，邀请码输入不渲染。
- **意见征集失败**：错误显示在按钮下方；再次点击会先清除旧错误再重试。
- 邀请码输入最长 256 个字符、关闭拼写检查，并声明按字符自动大写；去除首尾空白后为空时无法提交。

## 有损操作

无。本屏只读取本机许可状态并提交邀请码；激活成功写入本机激活凭证，不修改题组、试卷、作答记录等业务数据，也不删除任何文件。

## 术语

界面使用「许可」「激活」「邀请码」「意见征集」，与 [`../glossary.md`](../glossary.md) 一致。
本页不出现内部术语。

## 产物

- **激活成功**：本机保存激活凭证，随后进入应用；若同时检测到旧版本数据，先进入旧数据迁移（[`UI-OV-02`](./UI-OV-02.md)），再初始化工作台。
- **激活失败**：停留在本屏，可继续重试。
- **许可到期**：停留在本屏，无法进入工作台；可打开意见征集窗口。
- **意见征集**：打开独立的意见征集窗口，关闭该窗口后回到本屏，许可状态不变。
- 本屏不产生业务对象。
