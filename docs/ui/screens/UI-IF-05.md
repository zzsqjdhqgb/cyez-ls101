# 题型导出 · UI-IF-05

- 路由：`/interfaces/:interfaceId/export`
- 入口：题型详情（`UI-IF-02`）页头「导出题型」
- 对象：题型、题组

## 布局

专注式全屏工作页（`InterfaceTransferPage.module.css`），不显示一级导航：

1. 页头：左侧「题型库 / 导出题型」眉题、标题「选择要交付的题组」与题型描述；右侧「返回」。
2. 主体卡片：三格汇总（题型 / 题组总数 / 题型身份），下方是 `题组` 区标题与已选计数，再下面是题组勾选列表。
3. 底部粘性操作条：`取消` 与 `导出题型`。

返回路径为页头「返回」或底部「取消」，两者都按历史返回；从题型详情进入时回到 `UI-IF-02`。

## 控件清单

| 名称 | 类型 | 默认 / 加载 / 禁用 / 错误 | 触发结果 | 快捷键 |
| --- | --- | --- | --- | --- |
| 返回 | 按钮 | 始终可用 | 返回上一页 | 无 |
| 题组勾选框 | 复选框 | 默认全部选中 | 勾选/取消该题组是否随题型导出 | 无 |
| 取消 | 按钮 | 始终可用 | 放弃导出并返回上一页 | 无 |
| 导出题型 | 主按钮 | 导出中显示「正在导出...」并禁用；已选 0 个时禁用 | 打开系统保存对话框，写出 `.lsinterface` 文件 | 无 |

## 文案

- 眉题：`题型库 / 导出题型`
- 标题：`选择要交付的题组`
- 描述：`<题型描述>`；未填写时为 `没有填写题型描述。`
- 页头操作：`返回`
- 汇总：`题型`、`题组总数`、`题型身份`；身份取值为 `内置题型 · <builtinKey>` 或 `用户题型`
- 列表区：标题 `题组`；计数 `已选择 <数量> 个`
- 列表空状态：`当前题型没有题组。`
- 题组行：名称、`生成于 <本地化日期时间>`、`包含全部题组资源`
- 底部操作：`取消`、`导出题型`（导出中 `正在导出...`）
- 成功提示：`题型已导出`
- 加载中：`正在准备导出内容...`

## 状态与恢复

- **加载中**：题型与题组并行查询完成前只显示 `正在准备导出内容...`。
- **加载失败**：错误写入页面卡片上方的错误条；列表不渲染。题型不存在时错误文案为 `题型不存在`。页面不提供页内重试。
- **题组为空**：列表显示 `当前题型没有题组。`，「导出题型」因已选 0 个保持禁用，仍可「取消」返回。
- **保存被取消**：系统保存对话框取消时不写入文件、不提示成功、不导航，停留在本页。
- **导出失败**：错误写入页面错误条，已勾选状态与页面保持不变，可重试。
- **勾选状态**：查询完成后按题型当时已有的全部题组默认全选；不持久化，重新进入页面时重置。

## 有损操作

- **导出并保存文件**：写出的 `.lsinterface` 文件包含题型、所选题组及其全部资源。若目标位置已存在同名文件，覆盖由系统保存对话框确认；本页不再单独确认，也不修改本地题型与题组。

## 术语

界面使用「题型」「题组」「内置题型」「用户题型」「交付」，与 [`../glossary.md`](../glossary.md) 一致。
界面不出现 `Interface`、`Instance`、`Package` 等代码术语。本页无内部术语泄漏。

## 产物

- 成功导出产生一个 `.lsinterface` 题型文件，并返回 `UI-IF-02`（题型详情）。
- 该文件可在另一套 LS101 由 `UI-IF-06`（题型导入）审查后导入。
