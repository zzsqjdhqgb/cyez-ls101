# 题型详情 · UI-IF-02

- 路由：`/interfaces/:interfaceId`
- 入口：题型库列表（`UI-IF-01`）点击题型行
- 对象：题型、题组

## 布局

单页标准布局（`Page` / `PageHeader`，`InterfaceShared.module.css`、`InterfaceDetailsPage.module.css`）：

1. 页头：标题为题型名称（取不到时为「题型不存在」），右侧固定为「导出题型」与「返回题型」。
2. 描述行：题型描述（未填写时「暂无描述」）；内置来源显示徽标「内置题型」。
3. 标签页（`role="tablist"`，`aria-label="题型详情内容"`）：题组 / 题型定义，默认选中「题组」。
4. 「题组」视图：带副标题的区域标题 «题组 + 为试卷模板准备可复用的具体内容» 与「新建题组」按钮，下面是空状态或题组列表。
5. 「题型定义」视图：`aria-label="题型定义"`，自右向左依次是「复制为草稿」按钮、「生成要求」提示词代码块、带复制按钮组的「字段结构」表。

加载未完成时不渲染页头，只显示居中加载提示。

## 文案

- 页头标题：`<题型名称>`；取不到题型时为 `题型不存在`
- 页头操作：`导出题型`、`返回题型`
- 描述行：`<题型描述>`；未填写时为 `暂无描述`；内置题型徽标 `内置题型`
- 标签页：`题组`、`题型定义`
- 题组区：标题 `题组`；副标题 `为试卷模板准备可复用的具体内容`；按钮 `新建题组`
- 题组空状态：`暂无题组`
- 题组行：名称、生成时间（本地化日期时间）
- 题组操作菜单：`题组操作：<名称>`、菜单项 `删除题组`
- 删除题组确认对话框：标题 `删除题组“<名称>”？`；正文 `删除后无法恢复，题组中的内容和资源也会一并删除。`；确认按钮 `删除`
- 删除成功提示：`已删除题组“<名称>”`
- 新建题组对话框：标题 `新建题组`；说明 `先命名题组并选择进入编辑器后的起始方式。`；名称标签 `题组名称`；占位 `例如：校园生活第一套`；分组标题 `进入方式`；选项 `手工填写` / `进入空白字段表单`、`AI 生成` / `进入后配置模型并生成整组内容`；按钮 `取消`、`创建题组`；创建中为 `正在创建...`
- 名称为空错误：`请输入题组名称。`
- 题型定义：按钮 `复制为草稿`；小节标题 `生成要求`、`字段结构`；按钮 `复制完整提示词`、`复制单独提示词`、`复制 JSON Schema`、`复制 JSON Example`
- 字段结构行：类型标签 `组` / `text` / `image`、字段标识、文本字段 `[@<变量名>]`、图片字段 `[@<变量名>.inst] / [@<变量名>.img]`、字段描述（字段组不显示描述）
- 加载中：`正在加载题型...`

## 状态与恢复

- **加载中**：题型、题组、提示词三项并行查询完成前只显示 `正在加载题型...`。
- **加载失败**：页面保留 `role="alert"` 错误提示，题型数据保持为空，因此同时显示「题型不存在」空状态；错误提示按仓储错误消息渲染。页面不提供页内重试。
- **题型不存在**：`interfaceId` 无对应题型时不渲染描述行、标签页与对话框，只显示空状态「题型不存在」和「返回题型」。
- **删除题组失败**：错误写入 `role="alert"`，确认对话框关闭，题组列表保持不变。
- **复制失败**：剪贴板不可用或写入失败时用错误提示条提示 `当前环境无法访问剪贴板。`，不修改页面状态。
- **创建取消**：对话框内选择「取消」或按 Esc 关闭，不产生题组；未确认前不会写入空题组。

## 有损操作

- **删除题组**：不可逆，必须经过 `ConfirmModal` 二次确认。确认文案明确题组中的内容和资源会一并删除。删除成功后重新查询题组列表；已导出的题型文件、其他题组与题型定义不受影响。
- **复制为草稿**：不改动原题型，生成一个与原题型无关联的新草稿。

## 术语

界面使用「题型」「题组」「草稿」「生成要求」「字段」「变量名」，与 [`../glossary.md`](../glossary.md) 一致。
内部术语泄漏：复制按钮文案 `复制 JSON Schema`、`复制 JSON Example` 中出现代码术语 `Schema`（此处指 JSON Schema 数据格式），与术语表右列同名。
该冲突已登记在 [`../open-questions.md`](../open-questions.md) 第 1 条，本规格按 v0.4.1 实际文案记录，不擅自改写。

## 产物

- 「新建题组」产生一个题组并进入 `UI-IF-04`（题组编辑器）。
- 复制为草稿产生一个新草稿并进入 `UI-IF-03`（题型草稿编辑器）。
- 「导出题型」进入 `UI-IF-05`（题型导出）。
- 删除题组的产物是该题组从题组列表消失。
