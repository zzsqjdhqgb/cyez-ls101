# 题组编辑器 · UI-IF-04

- 路由：`/interfaces/:interfaceId/instances/:instanceId`
- 入口：题型详情（`UI-IF-02`）题组列表点击题组行，或新建题组后自动进入；直接选择「AI 生成」进入方式时自动打开「AI 生成并覆盖」对话框
- 对象：题组、所属题型的字段定义

## 布局

专注式编辑器（`InterfaceInstanceEditorPage.module.css`），不显示一级导航；顶部工具栏 62px，下方是居中的单列表单（最大宽度 980px，可滚动）：

1. 工具栏：左侧返回按钮 + 题组名称与状态；右侧「AI 生成并覆盖」「批量生图」（仅存在已填写提示词的图片字段时显示）、「高级操作」「保存」。
2. 题组名称：单行输入。
3. `内容字段` 区：标题右侧显示变量总数；下方按题型字段顺序排列每个内容字段。
4. 每个字段：标题行（字段标识、暴露变量写法、所属路径）、字段描述、然后是文本多行输入或图片输入区。
5. 图片输入区：`提示词` 多行输入、图片预览（空态显示「尚未选择图片」）、图像 Provider 选择、状态文字与「选择文件」「生成图片」「从剪贴板读取」「移除图片」。

「AI 生成并覆盖」「AI 生图」「从 JSON 覆盖题组」均以模态对话框呈现，不挤压主表单。运行中的 AI 任务会锁定底层表单与离开操作。

## 文案

- 工具栏：题组名（为空时 `未命名题组`）；状态 `<题型名> · 有未保存修改` 或 `<题型名> · 编辑`；按钮 `AI 生成并覆盖`（运行中 `生成中`）、`批量生图`（运行中 `生图中`）、`高级操作`、`保存`
- 表单：`题组名称`；`内容字段`；`<变量数> 个变量`
- 字段标题：字段标识；文本字段 `[@<变量名>]`；图片字段 `[@<变量名>.inst] / [@<变量名>.img]`；所属路径（根级为空）
- 图片输入：`提示词`；`图片`；空预览 `尚未选择图片`；文件说明为待选文件名、`已保存图片` 或 `PNG、JPEG、GIF 或 WebP`
- JSON 对话框：标题 `从 JSON 覆盖题组`；说明 `粘贴完整 JSON。校验通过后将覆盖整组内容并立即保存。`；标签 `JSON 内容`；按钮 `取消`、`校验并覆盖`
- JSON 校验错误：`<字段路径或 $>：<错误说明>`
- AI 生成对话框：标题 `AI 生成并覆盖`；说明按状态为 `选择生成模型。覆盖前会再次确认，成功后立即保存。`、`正在生成并校验，当前题组在任务成功前保持不变。`、`生成任务已结束，可以查看结果或重新生成。`、`生成已中断，可以保留已完成步骤并从失败位置继续。`；字段 `生成模型`、`图像 Provider`；启动中 `正在启动生成任务` / `正在读取模型配置并准备提示词...`；进度区标签 `AI 生成进度`
- AI 生成结果：`生成完成` / `生成内容已通过校验并保存到当前题组。`；`生成内容未通过校验` / `发现 <数量> 个字段错误，可检查原始 JSON 并修正后覆盖题组。`；`生成失败` / `<失败原因>`（续跑启动失败时追加 `；续跑启动失败：<原因>`）；`生成已取消` / `任务已停止，当前题组内容没有被生成结果覆盖。`；`生成任务启动失败` / `<启动错误>` 或 `无法启动生成任务`
- AI 生图对话框：标题 `AI 生图`；说明 `将为 <数量> 个已填写提示词的字段生成图片，成功后立即保存。`、运行中 `正在生成 <数量> 张图片`、结束 `生图任务已结束，可以查看结果或重新生成。`；字段 `图像 Provider`；进度区标签 `AI 生图进度`（步骤 `生成图片：<字段标识>`、`保存图片`）；按钮 `取消`、`开始生图`、`取消生图`、`重新生成`、`返回题组`
- AI 生图结果：`生图完成` / `所有图片已生成并保存到当前题组。`；`生图已取消` / `任务已停止，当前题组中的图片没有被覆盖。`；`生图失败` / `<失败原因>` 或 `图片生成服务暂时不可用`
- 覆盖确认框：标题 `覆盖当前题组内容？`；AI 路径正文 `AI 生成成功后会替换当前题组的全部文本、图片提示词和图片，并立即保存。`，确认按钮 `生成并覆盖`；JSON 路径正文 `JSON 校验通过后会替换当前题组的全部内容，并立即保存。`，确认按钮 `校验并覆盖`
- 未保存离开确认框：标题 `放弃未保存的修改？`；正文 `离开后，本次尚未保存的修改会丢失。`；确认按钮 `放弃修改`
- 提示：`题组已保存`、`AI 生成内容已保存`、`已取消 AI 生成`、`AI 生图结果已保存`、`已取消 AI 生图`、`图片已生成，请保存题组`、`已从 JSON 更新题组`、`剪贴板中没有图片`、`请先填写图片提示词`、`请先选择图像 Provider`
- 加载中：`正在加载题组...`；数据缺失：`题组不存在`

## 状态与恢复

- **加载中**：题型定义与题组实例并行查询完成前只显示 `正在加载题组...`。
- **加载失败 / 数据缺失**：错误写入 `role="alert"`；题型或题组为空时主区显示 `题组不存在`，所有提交按钮保持禁用。
- **未保存保护**：名称、字段取值、图片提示词或图片发生变化即标记未保存；此时返回、导航与关闭窗口都会先弹「放弃未保存的修改？」确认。「取消」留在编辑器并保留修改，「放弃修改」放弃修改后继续导航。AI 生成/生图运行中禁用返回按钮，成功后自动清除未保存标记。
- **保存校验**：每个图片字段必须同时有提示词与图片（待保存或已保存）才允许保存；不满足时「保存」禁用并给出提示，字段与提示词保持不变。
- **Provider 不可用**：图像 Provider 列表加载中或失败时不能选择；单字段生成按钮禁用，批量生图与 JSON 覆盖入口相应禁用，失败信息就地显示。
- **AI 生成生命周期**：选择模型（含图片字段时选择 Provider）→ 有已保存内容时二次确认覆盖 → 运行期间锁定表单并可取消 → 生成、校验、保存全部成功后才替换题组；失败或取消时原题组保持不变。无效返回进入 JSON 对话框检查并修正。
- **JSON 覆盖生命周期**：打开时清空临时输入与错误；校验失败时保留对话框、输入与字段错误，题组不变；取消时丢弃临时输入和错误；校验通过并确认后整组替换、保存并关闭对话框。
- **批量生图生命周期**：只处理已填写提示词的图片字段，逐个生成后统一保存；运行中可取消，取消或失败时本地图片不被覆盖；部分步骤失败时保留已完成步骤的日志。
- **放弃修改**：放弃后重新打开题组只显示上次保存的内容。

## 有损操作

- **AI 生成并覆盖**：整组替换文本、图片提示词与图片并立即保存。已有内容时不可省略覆盖确认，确认文案明确替换范围与立即保存语义；任务失败、校验失败或取消时原内容保留。
- **从 JSON 覆盖**：整组替换内容并立即保存。校验失败不改变题组；确认后才执行替换。
- **批量生图**：用生成结果覆盖图片字段并立即保存；取消或失败时不覆盖。
- **移除图片**：清除该字段的图片（待保存图片或已保存图片引用），保存后不可通过本页恢复。
- **删除题组**：不在本页；在题型详情 `UI-IF-02` 执行。

## 术语

界面使用「题型」「题组」「字段」「变量」「提示词」「保存」「覆盖」，与 [`../glossary.md`](../glossary.md) 一致。
内部术语泄漏：图片生成选择器标签 `<字段名>图像 Provider` 与 `图像 Provider` 暴露英文代码术语 `Provider`，术语表没有对应条目。本规格按 v0.4.1 实际文案记录；同类界面用词冲突的登记与处置方式见 [`../open-questions.md`](../open-questions.md)。

## 产物

- 「保存」写回题组；AI 整组生成、JSON 覆盖与批量生图成功后同样立即写回题组并清除未保存标记。
- 「返回题型详情」回到 `UI-IF-02`，保存后的题组出现在题组列表；放弃未保存修改则该次修改不写入。
