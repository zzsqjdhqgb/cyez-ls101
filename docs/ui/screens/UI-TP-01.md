# 模板库列表 · UI-TP-01

- 路由：`/templates`
- 入口：一级导航「试卷模板」；工作台快捷卡片「制作试卷」
- 对象：试卷模板（本地模板）、内置模板、函数库（只读清单）

## 布局

单页标准布局（`Page` / `PageHeader`），自上而下：

1. 页头：标题「试卷模板」，右侧两个操作「导入模板」「新建模板」。
2. 错误条：查询、新建、导入、复制、导出或删除失败时显示 `role="alert"` 条；无错误时不占位。
3. 加载文本：查询未完成时只显示「正在加载模板...」，此时不渲染标签页与列表。
4. 分类标签页（`role="tablist"`，`aria-label="试卷模板分类"`）：内置模板 / 我的模板 / 函数库，默认选中「内置模板」。
5. 标签页内容：
   - 内置模板：标签筛选 + 列表行。每行是名称与 `v<version>`、标签、描述，右侧三个操作「查看」「创建副本」「生成试卷」。
   - 我的模板：标签筛选 + 列表行。每行是名称按钮、标签、描述，右侧「编辑」「生成试卷」与图标按钮「导出模板“<名称>”」「删除模板“<名称>”」。
   - 函数库：只读列表，每行只显示名称，行内没有操作。
6. 覆盖层：导入冲突确认对话框、删除确认对话框。

标签筛选在存在标签时出现（`aria-label="按标签筛选"`），每个标签是一个 `aria-pressed` 切换按钮。三个分类在挂载时并行查询一次；切换标签只改显示，不重新查询。

## 文案

- 页头标题：`试卷模板`
- 操作：`导入模板`、`新建模板`、`正在导入`、`正在新建`
- 加载中：`正在加载模板...`
- 标签页：`内置模板`、`我的模板`、`函数库`
- 空状态：`暂无内置模板`（内置）、`暂无本地模板`（我的）、`暂无函数库`（函数库）
- 行文本：名称缺失时显示 `未命名模板`；内置行徽标 `v<version>`；描述缺失时显示 `暂无描述`；内置模板不可用时描述替换为 `缺少所需的题型或数据结构，当前版本暂不可用`
- 行操作：`查看`、`创建副本`、`正在创建`、`编辑`、`生成试卷`；图标按钮 `导出模板“<名称>”`、`删除模板“<名称>”`
- 删除确认：标题 `删除模板“<名称>”？`；正文 `模板及其编辑内容会从本地删除，已经导出的试卷不受影响。`；确认 `删除`
- 导入冲突确认：标题 `模板“<名称>”已存在`；正文 `本地 revision <本地修订> 与文件 revision <文件修订> 的内容不同。覆盖会保留当前模板 ID 并递增本地 revision。`；确认 `覆盖本地模板`；次按钮 `导入为副本`
- 导入结果提示：`模板“<名称>”已存在`（内容完全相同，不导入）、`已导入模板“<名称>”`、`已覆盖模板“<名称>”`、`已将模板“<名称>”导入为副本`
- 导出结果提示：`模板已导出`
- 复制结果提示：`已创建模板副本“<名称>”`

## 状态与恢复

- **加载中**：`Promise.all` 未完成时只显示「正在加载模板...」；其余区域不渲染。
- **查询失败**：错误写入页头下方 `role="alert"`，列表不渲染；页面不提供页内重试入口，重新进入页面会重新查询。
- **空状态**：当前分类没有条目时显示对应空状态标题；空状态不提供快捷创建按钮（新建入口始终在页头）。
- **标签筛选**：筛选只作用于已加载列表，选中多个标签时取交集；清空选中即恢复全部。
- **导入冲突**：内容相同直接提示 `模板“<名称>”已存在` 并结束；内容不同时打开确认对话框，必须选择「覆盖本地模板」或「导入为副本」。
- **删除失败**：错误写入页头 `role="alert"`，对话框保持打开，可重试或取消。
- **删除成功**：不显示提示，直接从列表移除；不做二次查询。

## 有损操作

- **删除模板**：不可逆。必须经过 `ConfirmModal` 二次确认；确认文案说明模板及其编辑内容从本地删除，已经导出的试卷不受影响。
- **覆盖导入**：不可逆。确认文案说明覆盖保留当前模板 ID 并递增本地 revision；覆盖前的本地内容不再保留，列表行随之更新。
- 导出模板、创建副本不修改已有对象。

## 术语

界面主体使用「试卷模板」「内置模板」「函数库」「标签」，与 [`../glossary.md`](../glossary.md) 一致。
两处内部术语泄漏：

- 导入冲突对话框正文直接显示代码字段名 `revision`。
- 内置行「生成试卷」按钮在模板不可用时，通过 `title` 属性暴露内部错误代码列表。

这两处属于界面用词与内部术语的冲突，与 [`../open-questions.md`](../open-questions.md) 第 1 条同类；本规格按 v0.4.1 实际文案记录，不擅自改写。

## 产物

- 「新建模板」「编辑」「模板名称」进入 `UI-TP-02`（模板编辑器）。
- 「查看」进入 `UI-TP-03`（内置模板查看）。
- 「生成试卷」进入 `UI-TP-05`（生成试卷）。
- 函数库只在「函数库」标签页列出名称，本页不提供进入 `UI-TP-04` 的入口；`UI-TP-04` 由模板编辑器左栏进入。
- 删除的结果是该模板从「我的模板」列表消失；导入、覆盖、创建副本的结果是列表新增或更新一行。
