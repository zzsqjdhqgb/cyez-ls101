# 旧数据迁移 · UI-OV-02

- 触发：运行时（非路由）。应用启动时（或许可激活后）检测到旧版本数据需要整理，本屏替代主应用渲染。
- 入口：应用启动 / 许可激活成功（[`UI-OV-01`](./UI-OV-01.md)）后
- 对象：旧版本遗留的数据、归档、清理

## 布局

本屏是一个覆盖层界面，不占用业务路由，也不显示一级导航：

1. 顶部是应用标题栏，只显示应用图标与名称，不显示侧边导航；窗口的关闭控件被禁用（悬停提示 `旧数据整理完成后可关闭`），最小化与最大化仍可用。
2. 主体是居中面板：状态图标、标题、状态说明，随后按状态显示归档摘要、错误、导出成功提示与操作区。
3. 三种形态：
   - **整理中**：加载图标、标题 `正在整理旧数据`、说明文字，以及进度提示；没有操作按钮。
   - **已归档**：归档图标、标题 `旧数据已归档`、说明文字、归档摘要（旧数据目录数量、文件数量、数据量），以及「导出旧数据」和「清理并继续」。
   - **失败**：警告图标、标题 `旧数据整理失败`、说明文字、错误文本，以及「重试」。

触发与关闭：

- 触发条件：启动流程检测到旧数据整理状态既不是「无」也不是「已清理」时进入本屏；许可未激活时先经过许可激活，激活成功后再检测。
- 本屏没有取消或跳过入口；窗口关闭按钮被禁用，用户无法在整理完成前退出。
- 当状态在进入后变为「无」或「已清理」时，本屏自动完成并离开。

| --- | --- | --- | --- | --- |
| 导出旧数据 | 次按钮 | 仅已归档时出现；操作进行中禁用 | 选择保存位置并导出归档；成功后显示 `归档已导出到你选择的位置。` | 无 |
| 清理并继续 | 危险按钮 | 仅已归档时出现；操作进行中禁用，按钮显示 `正在清理` 并带加载图标 | 永久删除旧文件并继续启动 | 无 |
| 重试 | 主按钮 | 仅失败时出现；操作进行中或整理服务不可用时禁用，按钮显示 `正在重试` 并带加载图标 | 重新尝试整理旧数据 | 无 |

## 文案

- 标题：`正在整理旧数据`（整理中）、`旧数据已归档`（已归档）、`旧数据整理失败`（失败）
- 状态说明按状态：
  - 失败：`旧文件尚未清除。请解决下方问题后重试。`
  - 整理中或清理中：`软件正在安全归档旧版本留下的数据，完成前无法进入工作台。`
  - 已归档：`归档已经校验完成。你可以先导出备份，然后清理旧文件并继续。`
  - 无待整理数据：`旧数据整理完成，正在初始化工作台。`
- 整理中进度提示（`role="status"`）：`正在扫描、校验并归档，请保持应用运行。`
- 归档摘要（`dl`）标签：`旧数据目录` + `<数量> 个`、`文件` + `<数量> 个`、`数据量` + `<大小>`
- 数据量单位：`B`、`KB`、`MB`、`GB`、`TB`；小于 10 时保留一位小数，否则取整
- 导出成功提示（`role="status"`）：`归档已导出到你选择的位置。`
- 服务不可用错误：`旧数据整理服务不可用，请重新启动应用。`
- 其他失败：显示服务返回的错误文本
- 按钮：`导出旧数据`、`清理并继续`、`正在清理`、`重试`、`正在重试`

## 状态与恢复

- **整理中**：面板显示加载图标、标题 `正在整理旧数据` 与进度提示；无操作按钮；关闭窗口控件禁用。
- **已归档**：显示归档摘要与两个操作按钮；导出与清理互不阻塞，但同一时刻只允许一个操作进行。
- **导出成功**：在操作区上方显示 `归档已导出到你选择的位置。`；再次执行清理或重试时该提示消失。
- **导出失败**：显示错误文本，页面仍保持已归档形态，可再次导出或直接清理。
- **失败**：显示警告图标、标题 `旧数据整理失败`、错误文本与「重试」；重试成功后回到整理中或已归档形态。
- **服务不可用**：页面进入失败形态并显示 `旧数据整理服务不可用，请重新启动应用。`；「重试」禁用，只能关闭或重启应用。
- **自动完成**：检测到无待整理数据时，本屏短暂显示整理中说明后自动离开。
- 操作进行中：「导出旧数据」与「清理并继续」同时禁用，避免并发整理。

## 有损操作

- **清理并继续**：不可逆。永久删除旧版本遗留的数据（旧数据目录与旧版本号文件），删除后无法通过本应用恢复；当前数据目录不受影响。
  v0.4.1 点击该按钮即执行，没有二次确认对话框；唯一的保护是「导出旧数据」提供先备份的路径。
- **导出旧数据**：非破坏性。把已校验的归档写入用户选择的位置，不删除原始文件。
- **归档**：非破坏性。归档阶段复制并校验旧数据，原始文件在清理前仍然保留。

## 术语

界面使用「旧数据」「归档」「导出」「清理」「数据目录」，与 [`../glossary.md`](../glossary.md) 一致。
本页不出现内部术语。

## 产物

- **清理并继续成功**：旧文件被永久删除，整理状态变为已清理，本屏自动关闭并继续启动；若应用有新版本说明，先显示版本说明，再进入工作台。
- **导出成功**：归档文件保存到用户选择的位置，供后续人工留存。
- **重试成功**：重新进入整理中或已归档形态，不产生业务对象。
- **无待整理数据**：直接继续启动并进入工作台。
- 整理过程不修改已保存的题组、试卷和作答记录。
