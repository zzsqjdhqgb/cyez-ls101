# 评分单元草稿编辑器 · UI-GS-04

- 路由：`/schemas/drafts/:libraryId/:draftId`
- 入口：评分单元草稿库 → `新建结构` 或 `编辑`；或直接打开地址
- 对象：草稿库中的结构草稿

> 说明：v0.4.1 的评分单元主流程直接新建并保存正式评分单元（见 `UI-GS-01`、`UI-GS-02`）。
> 本页保留用于读取和补全历史草稿库数据，属于兼容路径。

## 布局

专注式布局，不显示一级导航。

1. 页头工具条：左侧是 `返回草稿库` 图标按钮、草稿名称与状态副标题；右侧是 `保存` 与 `发布正式版`。
2. 主栏 `aria-label="评分单元结构"`：草稿信息、评分管道、答案槽位、试卷模板输入四个小节。
3. 摘要栏 `aria-label="结构摘要"`：评分管道、答案槽位数量、试卷模板输入数量、草稿修订号。
4. 草稿不存在时，主栏被文本 `结构草稿不存在` 替换。
5. `发布正式版` 打开发布对话框，内部渲染与 `UI-GS-02` 相同的数据字段。

评分管道、答案槽位与 试卷模板输入在本页始终可编辑，不受正式版冻结限制。

## 状态与恢复

- **加载中**：整页显示 `正在加载结构草稿...`，不渲染页头。
- **未找到**：草稿库不存在或草稿不在库中时显示 `结构草稿不存在`；`保存`、`发布正式版` 均不可用。
- **读取失败**：读取草稿库失败与草稿不存在一样进入 `结构草稿不存在`；错误文本在此状态不展示。
- **校验失败**：`保存` 校验草稿结构，不通过就以 `请修正以下内容` 就地列出并保留内容；发布对话框内的校验同样就地列出，不关闭对话框。
- **保存成功**：以保存结果刷新基线，`有未保存修改` 消失，草稿修订号递增。
- **发布前保存**：`发布正式版` 在存在未保存修改时先执行保存；保存失败时不打开对话框。
- **保存失败**：错误写入主栏 `role="alert"`，草稿内容保留。
- **发布失败**：错误写入主栏 `role="alert"`，发布对话框保持打开，可重试或取消。
- **未保存离开**：有未保存修改时，`返回草稿库` 先打开确认框；确认才丢弃修改并返回草稿库。

## 有损操作

- **放弃未保存修改**：确认 `放弃未保存的修改？` 后丢弃本次结构修改并返回草稿库。
- **发布正式版**：冻结当前结构并创建新的稳定评分单元，发布后跳转到 `UI-GS-02`；草稿本身保留在草稿库。结构冻结后不能再改，属于不可逆后果。
- **覆盖保存**：`保存` 以当前结构与名称覆盖草稿并递增修订号；校验失败或保存失败时不写入，页面保留本次修改。
- 删除结构草稿不在本页进行，见 `UI-GS-03`。

## 术语

界面使用「评分单元」「评分管道」「答案槽位」「结构草稿」，与 [`../glossary.md`](../glossary.md) 一致；
`Schema`、`ID` 等内部术语已不再出现；结构小节标题与摘要字段使用 `试卷模板输入`，与术语表一致。

## 产物

- `保存` 更新草稿库中的结构草稿，修订号递增。
- `发布正式版` 产生「我的评分单元」中的正式评分单元，并进入 `UI-GS-02`。
- `返回草稿库` 进入 `UI-GS-03`。
- 本页不删除草稿库，也不修改已发布的正式评分单元。
