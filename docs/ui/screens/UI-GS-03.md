# 评分单元草稿库 · UI-GS-03

- 路由：`/schemas/drafts/:libraryId`
- 入口：无界面入口；由历史草稿库数据或直接 URL 进入
- 对象：评分单元草稿库、结构草稿

> 说明：v0.4.1 的评分单元主流程不再创建或依赖草稿库（见 `UI-GS-01`）。
> 本页保留用于读取历史草稿库数据，属于兼容路径。

## 布局

1. 加载中：整页文本，不渲染页头。
2. 草稿库不存在：页头标题「草稿库不存在」+「返回」按钮，可选错误提示。
3. 正常：页头（库名 + 返回 / 保存名称 / 新建结构）、错误提示、草稿库名称输入、`结构草稿` 小节标题、空状态或列表。
4. 列表行：草稿名称、结构摘要、版本徽标、编辑与删除操作。

## 文案

- 加载中：`正在加载草稿库...`
- 不存在：标题 `草稿库不存在`，按钮 `返回`
- 页头标题：库名，为空时 `未命名草稿库`
- 页头操作：`返回 Schema`、`保存名称` / `正在保存`、`新建结构`
- 名称字段标签：`草稿库名称`
- 小节标题：`结构草稿`
- 空状态：`暂无结构草稿`
- 行描述：`<题目类型> · <答案槽位数> 个答案槽位 · <输入项数> 个输入项`
- 行徽标：`草稿 r<revision>`
- 行操作：`编辑`、图标按钮 `删除结构草稿`
- 删除确认：标题 `删除结构草稿“<名称>”？`；正文 `删除后无法恢复，这不会影响已经发布的正式 Schema。`；确认按钮 `删除`
- 删除成功提示：`已删除结构草稿“<名称>”`
- 新建草稿的默认名称：`未命名结构`

## 状态与恢复

- **加载中**：整页显示 `正在加载草稿库...`。
- **草稿库不存在**：显示不存在页头与「返回」按钮；若同时有读取错误，另显示 `role="alert"`。
- **读取/保存失败**：错误写入页面 `role="alert"`；`保存名称`、`新建结构`、删除都会在失败后保留当前内容，可重试。
- **空状态**：没有任何结构草稿时显示 `暂无结构草稿`。
- 「新建结构」创建的草稿固定为客观题、单个文本答案槽位（`answer`），随后进入编辑器继续编辑。

## 有损操作

- **删除结构草稿**：不可逆，必须二次确认；确认文案明确说明不影响已经发布的正式评分单元。
- 删除会立即保存草稿库；保存失败时错误显示在页面上，草稿仍在列表中（以保存结果为准）。

## 术语

本页向用户暴露内部术语 `Schema`（`返回 Schema`、`正式 Schema`）。
该冲突已登记在 [`../open-questions.md`](../open-questions.md) 第 1 条；本规格按 v0.4.1 实际文案记录。

- 本页不发布评分单元；发布/保存到正式评分单元不在本页完成。
