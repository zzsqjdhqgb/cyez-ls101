# 题型库列表 · UI-IF-01

- 路由：`/interfaces`
- 入口：一级导航「题型库」；`/interfaces/drafts` 重定向到 `/interfaces?view=drafts`
- 对象：题型、题型草稿

## 布局

单页标准布局（`Page` / `PageHeader`，`InterfaceShared.module.css`）：

1. 页头：标题「题型库」；右侧操作随当前视图切换。
2. 标签页（`role="tablist"`，`aria-label="题型库内容"`）：题型 / 草稿。
3. 内容区：错误提示、加载提示、空状态或列表，自上而下依次判断。
4. 列表：每行左侧是一个主要进入按钮（名称 + 数量/描述），右侧是来源徽标（题型）或删除按钮（草稿）。

当前视图由查询参数决定：`?view=drafts` 为草稿视图，其余一律为题型视图。切换标签只改查询参数并即时过滤已加载的两个列表，不重新查询。

| --- | --- | --- | --- | --- |

| 导入题型 | 菜单项 | 导入进行中禁用并显示「正在导入」 | 打开系统文件选择；选中文件后导航 `/interfaces/import`；取消选择则停留本页 | 无 |

| 题型行 | 按钮（行主入口） | 始终可点 | 导航 `/interfaces/<interfaceId>` | 无 |

## 文案

- 页头标题：`题型库`
- 题型视图操作：`题型库操作`、菜单项 `导入题型`；导入进行中为 `正在导入`
- 草稿视图操作：`新建题型`
- 标签页：`题型`、`草稿`
- 加载中：`正在加载题型...`（题型视图）、`正在加载草稿...`（草稿视图）
- 空状态：`暂无题型`（题型视图）、`暂无草稿`（草稿视图）
- 题型行：名称、`<题组数> 个题组`、描述（未填写时 `暂无描述`）；内置来源显示徽标 `内置`
- 草稿行：名称（未命名时 `未命名题型`）、描述（未填写时 `暂无描述`）
- 删除草稿确认对话框：标题 `删除草稿“<名称>”？`；正文 `删除后无法恢复，但不会影响已经发布的题型。`；确认按钮 `删除`
- 删除成功提示：`已删除草稿“<名称>”`

## 状态与恢复

- **加载中**：题型与草稿两个列表由同一次并行查询加载；未完成时按当前视图显示对应加载文案，列表与空状态都不渲染。
- **查询失败**：页面显示 `role="alert"` 提示，文案来自 `errorMessage`；两个列表停留在空数组，因此空状态可能同时出现。页面不提供页内重试，重新进入页面会重新查询。
- **导入取消**：文件选择被取消时不会导航，停留在当前视图。
- **新建草稿失败**：错误写入 `role="alert"`，不产生草稿。
- **删除失败**：错误写入 `role="alert"`，确认对话框保持打开，可重试或取消。
- **内置题型变化**：收到运行时的内置题型变化通知后重新查询已发布题型；草稿列表不重查。
- **视图切换**：只过滤已加载列表，不改变数据。

## 有损操作

- **删除草稿**：不可逆，必须经过 `ConfirmModal` 二次确认。删除只移除草稿本身，不影响由它发布的题型，也不删除题组。删除成功后可再次从「新建题型」创建草稿。

## 术语

界面使用「题型」「题组」「草稿」「题型库」，与 [`../glossary.md`](../glossary.md) 一致。
界面不出现 `Interface`、`Instance`、`Draft` 等代码术语。本页无内部术语泄漏。

## 产物

- 点击题型行进入 `UI-IF-02`（题型详情）。
- 点击草稿行进入 `UI-IF-03`（题型草稿编辑器）。
- 「新建题型」产生一个空白题型草稿并进入 `UI-IF-03`。
- 「导入题型」打开题型文件并进入 `UI-IF-06`（题型导入）。
- 「删除草稿」的产物是该草稿从草稿视图消失。
