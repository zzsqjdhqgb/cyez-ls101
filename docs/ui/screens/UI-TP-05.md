# 生成试卷 · UI-TP-05

- 路由：`/templates/:templateId/generate`（本地模板）、`/templates/builtin/:templateId/generate`（内置模板）
- 入口：`UI-TP-02` 工具栏「生成试卷」（本地模板）；`UI-TP-01` 内置行「生成试卷」或 `UI-TP-03`「生成试卷」（内置模板）
- 对象：试卷模板、题组选择、语音音色配置、生成的试卷包

## 布局

独立全屏流程页（`layout: focus`，不显示一级导航），在同一个页面内依次呈现三个阶段：

1. 页头：左侧「返回试卷模板」图标按钮与「生成试卷」眉题，标题为当前试卷名称（回退到模板名或 `未命名试卷`）；居中阶段条（`aria-label="试卷生成阶段"` 的有序列表）：生成设置 / 生成过程 / 生成结果；右侧「关闭生成试卷」图标按钮。
2. 阶段内容：
   - **生成设置**：三段编号设置区（`01 试卷信息`、`02 题组选择`、`03 语音设置`）与底部栏。
   - **生成过程**：进度标题区 + 任务列表（`aria-label="试卷生成任务"`），失败时为「生成已中断」并显示操作按钮。
   - **生成结果**：成功标记、`试卷生成完成`、试卷名称、页面/资源/试卷包三个统计与三个操作按钮。
3. 覆盖层：离开确认对话框。

进入页面不会自动开始任务，必须显式点击「开始生成」。阶段条把「生成设置」标为当前，「生成过程」在运行/失败时标为当前，「生成结果」在完成后标为当前，已完成阶段显示对勾。本地模板从 `UI-TP-02` 进入时，编辑器会先保存未保存修改；生成始终以最后一次成功保存的模板内容为依据。内置模板分支使用内置模板的预览与编译来源，关闭后返回 `/templates`；本地分支关闭后返回 `/templates/<templateId>`。

生成设置的三段内容互不依赖：题组选择只在模板声明了题型要求时出现；语音设置只在模板包含 TTS 播放动作时要求配置，否则显示「此模板无需合成语音」。

## 文案

- 页头：眉题 `生成试卷`；标题为试卷名称，回退 `未命名试卷`；阶段名 `生成设置`、`生成过程`、`生成结果`
- 加载与缺失：`正在准备试卷生成设置...`；缺失时 `无法生成试卷`、`试卷模板不存在`、`返回试卷模板`
- 试卷信息：`试卷信息`、`试卷名称`
- 题组选择：`题组选择`、`<N> 项内容`、`此模板不需要选择题组`、`请选择题组`、`未知题型`、`未命名题组`
- 语音设置：`语音设置`、`3 组必选音色`、`无需处理`、`此模板无需合成语音`、`默认音色`、`男声音色`、`女声音色`、`服务商`、`模型`、`音色`、`请选择服务商`、`请选择模型`、`请选择音色`、`没有可用的语音服务商、模型和音色，请先在设置中完成配置。`
- 底部栏：模板名称、`版本 <版本号>`、`开始生成`
- 生成过程：`正在生成试卷`、`任务将按列表顺序执行`、`生成已中断`、`已完成的语音会在重试时继续复用`、`关闭`、`从中断位置重试`；阶段任务名 `准备试卷内容`、`合成语音 <序号>：<文本摘要>`、`合成语音`、`整理试卷资源`、`打包试卷`；无语音时任务日志 `此模板无需合成语音`；语音尝试 `第 <n> / 4 次尝试`、`第 <n> / 4 次尝试失败：<原因>`
- 生成结果：`试卷生成完成`、`页面`、`资源`、`试卷包`、`关闭`、`导出文件`、`再次导出文件`、`正在导出`、`加入试卷库`、`已加入试卷库`、`正在加入`
- 离开确认：运行中标题 `取消正在进行的试卷生成？`、正文 `离开后会取消当前生成任务，并释放已经完成的临时音频。`、确认 `取消生成并离开`；结果未保存标题 `放弃尚未保存的试卷？`、正文 `这份试卷尚未加入试卷库或导出文件，离开后本次生成结果将丢失。`、确认 `放弃结果并离开`
- 结果提示：`该试卷已经在试卷库中`、`已将“<标题>”加入试卷库`、`试卷文件已导出`
- 导出对话框：标题 `导出试卷`，默认文件名 `<试卷名称>.lsexam`，过滤器 `LS101 试卷包`（`lsexam`、`zip`）

## 状态与恢复

- **加载中**：显示整页 `正在准备试卷生成设置...`，不渲染页头与阶段条。
- **模板缺失**：显示 `无法生成试卷` 与错误原因（或 `试卷模板不存在`），只提供「返回试卷模板」。
- **生成设置**：题组选择默认取每个题型的第一个题组；语音三组默认取第一组可用组合。任一必填项不满足时「开始生成」保持禁用，页面不显示字段级错误文案。
- **无语音模板**：语音设置显示「此模板无需合成语音」，不阻塞生成；生成过程仍显示「合成语音」阶段并标记为已完成、日志为「此模板无需合成语音」。
- **语音服务不可用**：语音设置显示 `没有可用的语音服务商、模型和音色，请先在设置中完成配置。`，并按缺少语音配置处理。
- **语音失败与重试**：每条音频最多 4 次尝试；达到上限时立即中断整个流程，保留已完成与失败任务状态，显示「生成已中断」；「从中断位置重试」复用成功音频，从失败项继续，不从头合成。
- **离开保护**：生成运行中或结果尚未加入试卷库且未成功导出时，任何离开都会先弹出确认；确认后取消任务并释放临时音频，或丢弃结果。处于生成设置或生成已中断阶段时关闭不弹确认。
- **加入失败 / 导出失败**：错误写入结果区 `role="alert"`，结果页保持打开，可重试。
- **重复加入**：试卷库判定为重复时提示 `该试卷已经在试卷库中`，按钮仍进入已加入状态。
- 生成结果停留在结果页，不自动导出、不自动关闭；关闭后释放本次临时任务进度与音频结果。

## 有损操作

- **取消正在进行的生成**：不可逆地中断当前任务，已经完成的临时音频被释放；必须二次确认。
- **丢弃尚未保存的结果**：结果既未加入试卷库也未成功导出时关闭，必须二次确认，确认后本次生成结果丢失。
- **导出文件**：通过系统保存对话框写出 `.lsexam`；若用户选择已存在的文件则覆盖该文件。导出可重复执行，成功后仍停留在结果页。
- 「加入试卷库」不覆盖已有试卷；重复时按重复处理并提示。「从中断位置重试」不会丢弃已成功合成的音频。

## 术语

界面使用「试卷模板」「试卷」「题型」「题组」「试卷库」「音色」「版本」，与 [`../glossary.md`](../glossary.md) 一致；
语音设置按产品定义使用「默认音色」「男声音色」「女声音色」，不提供跟随默认音色的回退项。
编译失败时错误说明来自模板校验与编译文案，迁移后使用「题型」「评分单元」「采集器」「时间线」等用户用词，
并保留 `位置：<path>` 形式的路径。语音设置的三个下拉写作 `服务商`（含 `请选择服务商`、
`没有可用的语音服务商、模型和音色，请先在设置中完成配置。`），与术语表一致。

## 产物

- 「加入试卷库」把生成的试卷包写入试卷库，可在 `/exams` 中找到。
- 「导出文件」产出 `<试卷名称>.lsexam`。
- 「关闭」返回 `UI-TP-02`（本地模板）或 `UI-TP-01`（内置模板）；本地模板本身不被生成过程修改，生成依据是最后一次成功保存的版本。
- 未执行任一保存动作即关闭时，本次生成结果被丢弃。
