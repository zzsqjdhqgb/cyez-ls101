# 评分单元库 · UI-GS-01

- 路由：`/schemas`
- 入口：一级导航「评分单元」
- 对象：评分单元（`SchemaDefinition`）

## 布局

单页标准布局：

1. 页头：标题「评分单元」，右侧主操作「新建评分单元」。
2. 来源标签页（`role="tablist"`，`aria-label="评分单元来源"`）：我的评分单元 / 内置评分单元。
3. 内容区：错误提示、加载提示、空状态或列表。
4. 列表：每行是评分单元的名称、题目类型/满分/描述、来源徽标与操作按钮。

默认打开「内置评分单元」标签。切换标签只过滤当前已加载的列表，不重新查询。

## 控件清单

| 名称         | 类型               | 默认 / 加载 / 禁用 / 错误 | 触发结果                            | 快捷键 |
| ------------ | ------------------ | ------------------------- | ----------------------------------- | ------ |
| 新建评分单元 | 主按钮             | 始终可用                  | 导航 `/schemas/new`                 | 无     |
| 我的评分单元 | 标签页             | 默认未选中                | 列表只显示非内置评分单元            | 无     |
| 内置评分单元 | 标签页             | 默认选中                  | 列表只显示内置评分单元              | 无     |
| 评分单元名称 | 文本按钮（行标题） | 始终可点                  | 导航 `/schemas/<schemaId>`          | 无     |
| 复制并修改   | 按钮               | 仅内置行                  | 导航 `/schemas/new?copy=<schemaId>` | 无     |

## 文案

- 页头标题：`评分单元`
- 主操作：`新建评分单元`
- 标签页：`我的评分单元`、`内置评分单元`
- 加载中：`正在加载评分单元...`
- 空状态：`暂无内置评分单元`（内置标签）、`暂无我的评分单元`（我的标签）
- 行描述：`<题目类型> · 满分 <满分> · <描述>`
- 行徽标：内置行显示 `内置`，我的行显示 `版本 <修订号>`
- 行操作：`复制并修改`（内置）、`编辑`（我的）、图标按钮 `删除评分单元`
- 删除确认对话框：标题 `删除评分单元“<名称>”？`；正文 `删除后引用这个评分单元的模板将无法通过校验。`；确认按钮 `删除`
- 删除成功提示：`已删除评分单元“<名称>”`

## 状态与恢复

- **加载中**：显示 `正在加载评分单元...`；加载完成后进入列表或空状态。
- **查询失败**：页面顶部显示 `role="alert"` 提示，文案来自 `schemaErrorMessage`；列表不渲染。
- **空状态**：当前标签下没有评分单元时显示对应空状态标题，不提供快捷创建按钮。
- **删除失败**：错误写入页面顶部 `role="alert"`，对话框保持打开，可重试或取消。
- 页面在挂载时查询一次；删除成功后重新查询。

## 有损操作

- **删除评分单元**：不可逆。必须经过 `ConfirmModal` 二次确认，确认文案明确说明会使引用该评分单元的模板校验失败。
- 删除不修改历史作答中已经保存的评分单元快照，也不删除模板中的引用本身。

## 术语

界面使用「评分单元」「我的评分单元」「内置评分单元」，与 [`../glossary.md`](../glossary.md) 一致；
本屏不再出现 `Schema`、`revision` 等内部术语。

## 产物

- 点击行标题或「编辑」进入 `UI-GS-02`。
- 「新建评分单元」「复制并修改」进入评分单元编辑过程，其界面归入 `UI-GS-02`。
- 删除产生的结果是评分单元从「我的评分单元」列表消失；引用它的模板在后续校验中失败。
