# AI 引擎 · UI-ST-06

- 路由：`/settings/ai-router/*`
- 入口：设置总览（[`UI-ST-01`](./UI-ST-01.md)）→「AI 引擎」
- 对象：AI Provider、模型、API 密钥、本地模型包、语音评测扩展包

## 布局

本屏是设置分区页，采用「分类标签页 + 区域内设置分组」两级结构：

1. 分类标签页（`role="tablist"`，`aria-label="AI 引擎设置分类"`）固定按顺序排列五个标签：
   文本生成、图像生成、语音合成、语音识别、AI 语音评测。
2. 标签下方是对应的 `tabpanel`，内容由若干设置分组构成（分组标题 `h2` + 可选描述 + 分组体）。
3. `/settings/ai-router` 与未知子路径都重定向到「文本生成」，因此默认选中「文本生成」。
4. 切换标签会重新挂载区域内容：未保存的编辑草稿不跨标签保留。

各区域布局：

- **文本生成**：一个「Provider」列表分组。点击列表行或「添加 Provider」打开覆盖式编辑器对话框；编辑器内依次为「基础配置」「Model ID」「连接测试」三个分组，底部是操作栏。
- **图像生成**：一个「图像 Provider」列表分组。编辑器内依次为「基础配置」，在线 Provider 的「图像模型」或手动 Provider 的「测试生成」，以及在线 Provider 的「连接测试」；测试生成结果以图片预览显示在编辑器底部。
- **语音合成**：顶部是「语音 Provider」与「TTS 模型包」两个列表分组。编辑器内依次为「基础配置」，本地 Provider 的「模型包」「启用模型」「启用音色」或在线 Provider 的「Model ID」「Voice ID」，以及「连接测试」；测试结果以音频播放器显示。
- **语音识别**：顶部是「语音识别 Provider」与「ASR 模型包」两个列表分组。编辑器内依次为「基础配置」，本地 Provider 的「模型包」或在线 Provider 的「Model ID」，以及「启用模型」。
- **AI 语音评测**：单个「AI 语音评测」分组，展示扩展包名称、要求版本与导入状态；不提供后端切换。

编辑器是覆盖在当前区域之上的模态对话框，标题为配置名称（为空时显示占位名称），右上角是关闭按钮。删除确认框、区域错误块与操作反馈同样覆盖在当前区域之上。

## 状态与恢复

- **区域加载**：区域内容整体显示加载文案；加载失败时整块显示错误标题、错误文本与「重试」。语音合成与语音识别同时加载 Provider 列表和模型包列表，任一失败即进入错误块。
- **编辑器忙碌**：所有输入、选择与按钮禁用；关闭与取消不生效；保存按钮显示 `正在保存...`，连接测试显示 `正在测试...`。忙碌期间无法关闭编辑器。
- **保存后**：编辑器保持打开并替换为已保存的值，「保存 Provider」因无改动而禁用；再次编辑后重新可用。
- **未保存离开**：关闭编辑器（取消、右上角关闭、点击遮罩或按 Esc）与切换分类标签都直接丢弃草稿，v0.4.1 不提供未保存提示。
- **操作反馈**：成功反馈使用 `role="status"`，失败反馈使用 `role="alert"`，显示在对应分组内（密钥、模型列表、连接测试、编辑器底部）。
- **删除失败**：确认框保持打开并显示错误，可重试或取消；删除中确认按钮显示 `正在处理...` 并禁用。
- **列表刷新**：文本生成删除成功后直接过滤本地列表；图像生成删除成功后重新查询列表；语音合成与语音识别删除后本地过滤。
- **AI 语音评测**：未导入时提供「导入扩展包」；导入成功后状态变为已导入并显示资源数量与体积，按钮消失。

## 有损操作

- **删除 Provider（文本生成）**：不可逆。确认框标题 `删除 Provider 配置？`，正文 `将同时删除“<名称>”的普通配置和加密密钥。`，确认按钮 `删除配置`。删除后该 Provider 及其加密密钥一并消失，不影响已保存的题组、试卷和作答记录。
- **删除 Provider（图像生成）**：不可逆。确认框标题 `删除图像 Provider 配置？`；在线类型正文 `将删除“<名称>”的图像配置和加密密钥。`，手动类型正文 `将删除“<名称>”的手动生成配置。`；确认按钮 `删除配置`。
- **删除 Provider（语音合成）**：不可逆。确认框标题 `删除语音 Provider？`，正文 `将删除“<名称>”及其独立保存的 API Key。`，确认按钮 `删除 Provider`。
- **删除 Provider（语音识别）**：不可逆。确认框标题 `删除语音识别 Provider？`，正文 `将删除“<名称>”及其独立保存的 API Key。`，确认按钮 `删除 Provider`。
- **删除 TTS 模型包**：不可逆。确认框标题 `删除 TTS 模型包？`，正文 `将删除“<名称>”及未被其他模型包引用的资源。`，确认按钮 `删除模型包`。被 Provider 引用的模型包删除入口禁用。
- **删除 ASR 模型包**：不可逆。确认框标题 `删除 ASR 模型包？`，正文 `将删除“<名称>”及未被其他模型包引用的资源。`，确认按钮 `删除模型包`。被 Provider 引用的模型包删除入口禁用。
- **移除模型 / 音色**：只修改草稿，保存前不产生实际删除；关闭编辑器即放弃该修改。
- 「AI 语音评测」不提供删除或卸载扩展包的操作。

其中 `Provider` 的泄漏已在 [`../open-questions.md`](../open-questions.md) 第 1 条登记；本规格按 v0.4.1 实际文案记录，不擅自改写。

## 产物

- 保存 Provider 后，Provider 配置、模型启停状态与加密密钥被持久化；只有已启用模型会出现在考试与批改的配置步骤中。
- 导入模型包后，本地 Provider 可在编辑器中选择该包的模型与音色；删除模型包会同时移除未被其他包引用的资源。
- 导入语音评测扩展包后，固定阅读题的发音评测变为可用；扩展包版本必须与应用要求版本匹配。
- 各区域操作失败时不产生半成品配置，页面保留可重试的草稿或原列表。
- 本屏不产生题组、试卷、评分结果等业务对象。
