# 试卷库列表 · UI-EL-01

- 路由：`/exams`
- 入口：一级导航「试卷库」；工作台快捷卡片「进入试卷库」
- 对象：试卷（已导入本地的试卷包记录）

## 布局

单页标准布局，自上而下四个区域：

1. 页头：标题「试卷库」，右侧主操作「导入试卷包」。
2. 提示区：查询或导入失败时在页头下方显示带告警图标的错误条；无错误时不占位。
3. 内容区三态：加载提示、空状态或试卷表格，三者互斥。
4. 表格：列依次为「试卷」「导入时间」「页面」「资源」「大小」和无名操作列（列头 `aria-label="操作"`）。「试卷」列上行加粗显示试卷标题，下行小字显示试卷标识（`title` 为同一标识）；操作列依次为「开始考试」按钮与危险图标按钮「删除试卷」。

页面进入时查询一次，无默认选中行，也不保留上次的滚动位置或筛选条件。

## 控件清单

| 名称 | 类型 | 默认 / 加载 / 禁用 / 错误 | 触发结果 | 快捷键 |
| --- | --- | --- | --- | --- |
| 导入试卷包 | 主按钮 | 导入进行中禁用并改文案「正在导入」 | 打开系统文件选择框（标题「导入试卷包」），选中后导入并刷新列表 | 无 |
| 开始考试 | 按钮（行内） | 始终可用 | 导航 `/exams/player?packageId=<试卷标识>` | 无 |
| 删除试卷 | 图标按钮（危险，行内） | 导入进行中禁用 | 打开删除确认对话框 | 无 |
| 删除 | 确认按钮（危险，对话框内） | 仅对话框内 | 删除该试卷并刷新列表 | 无 |

表格中的试卷标题、导入时间、页面数、资源数与大小均为只读文本，不可点击。

## 文案

- 页头标题：`试卷库`
- 主操作：`导入试卷包`；导入中：`正在导入`
- 加载中：`正在加载考试库...`
- 空状态：`暂无试卷`
- 表头：`试卷`、`导入时间`、`页面`、`资源`、`大小`；操作列标题：`操作`
- 行操作：`开始考试`、图标按钮 `删除试卷`
- 删除确认对话框：标题 `删除试卷“<试卷标题>”？`；正文 `删除后，本地保存的原始试卷包也会一并移除。此操作无法撤销。`；确认按钮 `删除`
- 导入成功：`已导入试卷“<试卷标题>”`；重复：`该试卷包已经在考试库中`
- 删除成功：`已删除试卷“<试卷标题>”`
- 导入文件选择框：标题 `导入试卷包`；文件类型名 `LS101 试卷包`（扩展名 `lsexam`、`zip`）
- 数值格式：导入时间按 `YYYY/MM/DD HH:mm`（24 小时制）显示；大小小于 1 KB 显示 `<整数> B`，小于 1 MB 显示 `<数值> KB`（1 位小数），否则显示 `<数值> MB`（1 位小数）
- 错误文案按原因取以下之一：`无法导入试卷包：<原因>`、`考试库中已有相同编号、但内容不同的试卷包。`、`试卷包不存在或已经被删除。`、`考试库数据损坏：<原因>`；其余错误显示原始错误信息，无信息时为 `操作失败，请重试。`

## 状态与恢复

- **加载中**：显示 `正在加载考试库...`；表格与空状态都不渲染。
- **查询失败**：页头下方显示 `role="alert"` 错误条，试卷表格不渲染；因为本次没有可用记录，页面同时显示空状态 `暂无试卷`（错误条与空状态并存）。页面不提供页内重试入口，重新进入页面会重新查询。
- **空状态**：加载完成且没有试卷时显示 `暂无试卷`，不提供页内快捷导入入口。
- **导入取消**：文件选择框被取消时不改列表、不提示。
- **导入重复**：列表刷新后提示 `该试卷包已经在考试库中`，不新增行。
- **导入失败**：错误写入提示区，列表保留原内容，可再次点击「导入试卷包」重试。
- **删除失败**：错误写入提示区，对话框已关闭，列表保留原内容。
- 成功导入或删除后重新查询整张列表；查询期间「正在加载考试库...」会短暂替换表格。

## 有损操作

- **删除试卷**：不可逆。必须经过二次确认，确认文案说明本地保存的原始试卷包会一并移除。
- 删除只影响试卷库中的该条试卷记录，不改写已经导出的作答包，也不修改已有的作答记录。

## 术语

`试卷`、`试卷库`、`作答包`、`开始考试`，与 [`../glossary.md`](../glossary.md) 一致。界面不出现 `ExamPackage`、`Schema` 等内部术语。

已知用词不一致：加载提示与重复导入提示使用「考试库」（`正在加载考试库...`、`该试卷包已经在考试库中`），而页面标题与一级导航使用「试卷库」。

## 产物

- 导入成功产生一条试卷记录，出现在列表中。
- 「开始考试」进入 [`UI-EL-02`](./UI-EL-02.md)；考试完成后返回本页，原试卷仍可再次使用。
- 「删除试卷」的结果是该记录从列表消失。
