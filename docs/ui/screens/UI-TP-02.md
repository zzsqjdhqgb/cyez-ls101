# 模板编辑器 · UI-TP-02

- 路由：`/templates/:templateId`
- 入口：模板库列表「新建模板」「编辑」，或点击「我的模板」行标题
- 对象：试卷模板（页面结构、时间线、题型要求、评分 Schema 引用、函数库）

## 布局

专注式全屏工作区（`layout: focus`，不显示一级导航），自上而下：

1. 工具栏：左侧返回按钮与模板身份（名称 + `Revision <revision>`，有未保存修改时追加 `· 未保存`），右侧操作组（撤销 / 重做 / 保存 / 导出模板），最右固定「生成试卷」。
2. 工作区（`ResizableSplit`，`label="调整函数库宽度"`，初始 300、左栏最小 240、右栏最小 708）：
   - 左栏「函数库」：小节标题、来源标签页、库分组与函数卡片。
   - 中右栏（`ResizableSplit`，`label="调整属性栏宽度"`，初始 340、中栏最小 420、右栏最小 280，从右侧分配）：
     - 中栏编辑视图标签页（`aria-label="编辑视图"`）：结构 / 页面 / 预览，默认「结构」。
     - 右栏属性面板，或在预览视图下换成「预览配置」检查器。
3. 覆盖层：放弃修改确认、删除节点确认、重置损坏函数库确认、删除本地函数确认、删除函数库确认。

「页面」标签页只在当前选中节点是页面时可用；「预览」在未选中节点、选择题或变量节点上禁用。从预览进入时左栏替换为「预览序列」胶片条、中栏替换为预览画面。

结构视图节点树：根节点默认选中并标记「根节点」；每个节点行有折叠/展开按钮、选择按钮和当前选中时的节点操作。页面节点在行内展开时间线摘要，选择题/函数/变量节点在行内展开对应摘要编辑器，框架节点展开子节点。

## 文案

- 身份：名称缺失时 `未命名模板`；副标题 `Revision <revision>`、`Revision <revision> · 未保存`、`正在加载`、`无法加载`
- 操作：`撤销`、`重做`、`保存`、`正在保存`、`导出模板`、`正在导出`、`生成试卷`、`返回模板`
- 全局属性：`名称`、`描述`、`标签`（占位 `例如：听力, 高考`）
- 函数库：`函数库`、`组件素材`；来源标签 `内置`、`导入`、`本地`；空状态 `暂无内置函数库` / `暂无导入函数库` / `暂无本地函数库`；空状态描述 `当前没有可用的内置组件`、`导入函数库后会显示在这里`、`创建本地函数库后会显示在这里`；函数为空 `暂无函数`；函数库行副文本 `<数量> 项 · <导出状态>`，导出状态为 `未导出`、`已导出 v<版本>`、`v<版本> 后有修改`；非本地库显示 `<数量> 项 · v<版本>`
- 函数卡片：名称缺失时 `未命名函数`；类型副标题为 `框架`、`页面`、`选择题`、`变量`、`函数`
- 加载与错误：`正在加载函数库...`、`本地函数库 <libraryId> 已损坏，无法加载。`、`重置损坏函数库`、`函数库名称不能为空。`
- 结构视图：`结构`、`页面`、`预览`；节点副文本为 `<nodeId>` 或 `<nodeId> · 根节点`；空状态 `正在加载模板` / `模板不可用`
- 页面节点：`时间线`、`暂无时间线`、`编辑内容`、`TTS 播放`、`倒计时`、`录音`、`TTS 文本`、`秒`、`时长`、`输出名称`
- 选择题节点：`选择题内容`、`<数量> 个选项`
- 属性小节：`全局属性`、`评分 Schema`、`节点属性`、`内容块`、`可用变量`
- 预览：`预览序列`、`<数量> 个画面`、`预览配置`、`预览范围`、`节点`、`画面`、`刷新预览`、`当前 Timeline`、`类型`、`参数`、`来源`、`暂无 Timeline 信息`、`请选择实例`、`未命名实例`；胶片条状态 `预览加载失败`、`请先选择 Interface 实例`、`正在生成预览...`、`模板未通过校验`、`所选节点不产生页面`
- 确认对话框：`放弃未保存的修改？` / `离开后，本次尚未保存的修改会丢失。` / `放弃修改`；`删除节点“<nodeId>”？` / `该节点及其包含的全部子节点都会被删除。` / `删除`；`重置损坏的本地函数库？` / `损坏的本地函数库及其中的全部函数将被删除，并新建一个空白函数库。已经嵌入模板的函数副本不受影响。` / `重置函数库`；`删除本地函数“<函数名>”？` / `该函数会从本地函数库中删除，已经嵌入模板的函数副本不受影响。` / `删除`；`删除本地函数库“<名称>”？` 或 `删除导入函数库“<名称>”版本 <版本>？` / `函数库及其中的全部函数都会从本地删除，已经嵌入模板的函数不受影响。`（导入库为 `这个导入版本会从本机删除，其他版本和已经嵌入模板的函数不受影响。`）/ `删除`
- 结果提示：`模板已导出`

## 状态与恢复

- **加载中**：模板未就绪时身份副标题显示「正在加载」，中栏结构视图显示空状态「正在加载模板」，属性输入禁用。
- **加载失败**：模板不存在时错误为 `模板不存在。`；其他失败文案来自 `templateErrorMessage`，显示在「全局属性」小节的 `role="alert"`；中栏显示「模板不可用」。
- **编辑错误**：文档操作被拒绝时错误文本为 `<错误码>: <路径>`，写入「全局属性」`role="alert"`；成功的编辑会清除错误。
- **查询失败**：函数库或题型要求查询失败时，对应区域显示 `role="alert"`；损坏的本地函数库提供「重置损坏函数库」入口。
- **保存失败**：`session.error` 写入「全局属性」`role="alert"`，模板保持未保存状态，可重试。
- **未保存离开**：页内导航由未保存守卫拦截，或由返回按钮触发放弃确认；确认后丢弃本次修改，取消则留在编辑器。
- **预览失败**：预览检查器显示「预览加载失败」或「模板未通过校验」，校验结果列出每条错误的说明与路径，点击可定位到对应节点。
- 编辑历史上限 200 步；保存成功后当前状态成为干净状态，撤销/重做可用性随之更新。

## 有损操作

- **删除节点**：不可逆。必须二次确认；确认文案说明该节点及其全部子节点都会被删除。
- **删除本地函数 / 删除函数库 / 删除导入函数库版本**：不可逆。必须二次确认；确认文案说明只从本机删除，已经嵌入模板的函数副本不受影响。
- **重置损坏函数库**：不可逆。必须二次确认；损坏库及其全部函数被删除，并新建一个空白函数库。
- **放弃未保存修改**：不可逆。离开有未保存修改的编辑器必须确认；确认文案说明本次修改会丢失。
- **覆盖保存**：保存会以当前编辑内容覆盖该模板的当前 revision；这是显式「保存」动作，不额外确认。已经导出的模板文件与由该模板生成的试卷不回溯更新。

## 术语

界面主体使用「试卷模板」「题型」「题组」「函数库」「评分单元」「标签」，与 [`../glossary.md`](../glossary.md) 一致。
以下位置向用户暴露了内部术语，按 v0.4.1 实际文案记录：

- 题型要求面板标题与按钮：`Interface 配置`、`添加 Interface`、`正在加载 Interface...`、`暂无已发布 Interface`、`尚未配置 Interface`、`选择 Interface`、`新 Interface 别名`、`移除 Interface <别名>`、`Interface <别名> 别名`。
- 预览绑定面板：`Interface 实例`、`请先选择 Interface 实例`、`预览 Interface <别名> 实例`。
- 属性小节标题：`评分 Schema`；Schema 面板：`暂无正式 Schema`、`Schema 不存在或 ID 无效`。
- 校验与编译错误文案：`Interface`、`Schema`、`Timeline`、`Collector` 等词会随错误说明出现（例如 `选择题 Collector`、`暂无 Timeline 信息`）。
- 身份副标题直接显示代码字段名 `Revision <revision>`。

这些属于界面用词与内部术语的冲突，与 [`../open-questions.md`](../open-questions.md) 第 1 条同类；本规格只记录现状，不修改该文件。

## 产物

- 「生成试卷」进入 `UI-TP-05`；本地模板会先保存未保存修改。
- 「编辑<函数名>」进入 `UI-TP-04`（函数编辑器），返回时回到当前模板。
- 「导出模板」产出 `<名称>-r<revision>.lstemplate`（文件对话框标题 `导出模板`）。
- 保存的结果是该模板 revision 递增并成为后续生成的最新依据；失败或放弃修改不产生新版本。
- 删除节点、函数、函数库的结果是相应对象从当前模板或本地函数库中消失。
