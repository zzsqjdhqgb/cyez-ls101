# 关于 · UI-ST-05

- 路由：`/settings/about/*`
- 入口：设置总览（`UI-ST-01`）→「关于」
- 对象：应用标识、版本、版本说明、项目团队、版权与许可

## 布局

本页渲染在共享设置明细容器内：容器给出页头标题「关于」、说明「查看应用版本、项目团队和软件许可」与「返回设置」按钮；以下为页面内容。

1. 产品信息块：应用图标、名称「曹二听说101」、副标题「英语听说考试系统」、版本行。
2. 「版本说明」整行按钮：左侧图标，中间标题与一行摘要，右侧箭头。
3. 「项目发起人」分组：一名成员行（头像、姓名、身份说明，无链接）。
4. 「开发者」分组：两名成员行（头像、姓名、身份说明，整行为外部链接，带外链图标）。
5. 「版权与许可」分组：版权文本、许可说明，右侧为「项目主页」外部链接。
6. 版本说明对话框按触发叠加显示。

本页只显示名称、版本、版本说明、团队成员与许可信息，不显示运行环境信息（操作系统、运行时、硬件、安装路径）。

## 状态与恢复

- **版本号获取中**：版本行显示 `版本 正在获取...`。
- **版本号不可用**：无版本接口或获取失败时显示 `版本 未知`；页面其余内容照常渲染。
- **版本说明缺失**：按已安装版本选择说明；没有对应版本的说明时回退显示最新版本的说明。
- **版本说明对话框**：由本页「版本说明」按钮打开，只能通过「关闭版本说明」按钮关闭；按 Esc、点击遮罩或对话框外部都不关闭。
- 本页无空状态、无中断与未保存离开处理。
