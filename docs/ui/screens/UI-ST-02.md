# 存储 · UI-ST-02

- 路由：`/settings/storage/*`
- 入口：设置总览（`UI-ST-01`）→「存储」
- 对象：数据目录（当前目录、默认位置、旧数据目录）

## 布局

本页渲染在共享设置明细容器内：容器给出页头标题「存储」、说明「查看和更改软件数据的保存位置」与「返回设置」按钮；以下为页面内容。

1. 加载/不可用状态：整块状态文本；存在错误时额外显示「重试」按钮。
2. 正常状态：
   - 「数据位置」分组，分组标题下方为分组描述。
   - 「当前目录」行：说明为「<占用大小> · 默认位置」或「<占用大小> · 自定义位置」；右侧为当前路径（等宽字体，过长时省略，悬停显示完整路径）和「更改位置」「恢复默认位置」两个按钮。
   - 「旧数据目录」行：仅在记录到旧数据目录时出现。说明为「暂时不可访问」，或「<占用大小> · 迁移前的数据副本」，或「<占用大小> · 等待继续删除」；右侧为旧路径和删除按钮。
3. 分组下方为说明注释。
4. 页面内容顶部可选错误提示（`role="alert"`）。
5. 迁移/切换确认框、删除确认框按触发叠加显示。

占用大小按二进制单位显示：小于 1024 字节显示「<字节数> B」，否则使用 KB / MB / GB / TB；数值小于 10 时保留一位小数，否则取整。位置是否等于默认位置在 Windows 上忽略大小写比较，在 Linux/macOS 上区分大小写。

## 文案

- 容器页头：标题 `存储`，说明 `查看和更改软件数据的保存位置`，按钮 `返回设置`
- 加载中：`正在加载存储设置...`
- 不可用且无错误：`存储设置不可用`
- 服务不可用：`数据目录服务不可用`，并提供 `重试`
- 分组标题与描述：`数据位置`、`模板、题库、配置、API 密钥和本地模型保存在这里。`
- 行标签：`当前目录`、`旧数据目录`
- 位置说明：`默认位置`、`自定义位置`
- 旧数据目录说明：`暂时不可访问`、`迁移前的数据副本`、`等待继续删除`
- 按钮：`更改位置`、`恢复默认位置`、`删除旧数据`、`继续删除`、`重试`
- 位置按钮禁用原因（悬停提示）：`请先删除旧数据目录`、`请先完成旧版数据归档清理`
- 分组下注释：`Electron 缓存和可重新生成的 Qwen TTS 运行文件不会移动。旧版数据归档清理或旧数据目录删除完成前不能更改位置。`
- 系统目录选择框标题：`选择数据目录`
- 迁移确认框：标题 `迁移数据目录？`；确认 `复制并重启`；消息 `应用将重启，把当前的 <占用大小> 数据复制到“<目标路径>”。复制成功前不会切换目录，原数据不会删除。`
- 使用已有目录确认框：标题 `使用已有数据目录？`；确认 `使用并重启`；消息 `应用将重启并直接使用“<目标路径>”中的现有数据（<占用大小>）。当前数据不会复制或删除。`
- 删除确认框：标题 `删除旧数据目录？`；确认 `永久删除`；消息 `将永久删除“<旧目录路径>”及其中的全部数据。当前目录不受影响，此操作无法撤销。`
- 确认框通用：取消 `取消`；处理中确认按钮显示 `正在处理...`
- 重启后复制迁移进度窗口：标题 `正在迁移数据`；正文 `正在将软件数据复制到 <目标路径>`

## 状态与恢复

- **加载中**：整块显示 `正在加载存储设置...`。
- **读取失败或服务不可用**：整块显示错误文本并提供 `重试`；服务不可用时错误文本为 `数据目录服务不可用`。
- **处理中**：迁移/切换/删除进行中，相关按钮与确认框按钮禁用，确认框保持打开，避免重复提交。
- **迁移或切换失败**：确认框关闭，页面内容顶部显示错误文本（`role="alert"`），候选选择清除；当前目录不变，可重新选择。典型错误包括目标不可用、`请选择空目录，或选择一个已有的 LS101 数据目录`、`迁移校验失败：<相对路径>`、`迁移校验失败：文件数量不一致`、`迁移目标在复制期间被写入，已停止迁移并保留目标内容`、`迁移目标在提交期间被其他程序占用，已停止迁移并保留目标内容`。
- **删除失败**：错误显示在删除确认框内（`role="alert"`），确认框保持打开；旧数据目录记录保留，后续启动继续尝试删除。旧目录不可访问时错误为 `旧数据目录暂时不可访问，将在后续启动时继续删除`。
- **位置更改被阻止**：存在旧数据目录时两个位置按钮禁用，提示 `请先删除旧数据目录`；旧版数据归档待清理时提示 `请先完成旧版数据归档清理`。删除旧数据目录或完成归档清理后自动恢复可用。
- **选择结果无变化**：在系统目录选择框中选中当前目录，或取消选择时，页面不显示确认框、不改变任何状态。
- **成功后**：应用安排重启，页面不显示成功状态；重启后迁移在启动阶段完成后才进入界面。

## 有损操作

- **迁移数据目录（更改位置到空目录，或恢复默认位置到空目录）**：确认框标题 `迁移数据目录？`，确认按钮 `复制并重启`。应用先复制到目标目录旁的隐藏暂存目录，完成复制并逐文件校验后才原子切换到目标；复制或校验失败即停止，保留原目录与目标内容，不切换。成功后应用重启，原目录保留为「旧数据目录」并显示在页面。迁移过程本身不删除原数据。
- **使用已有数据目录（更改位置选中可识别的已有数据目录，或恢复默认位置时默认目录已是这类目录）**：确认框标题 `使用已有数据目录？`，确认按钮 `使用并重启`。重启后直接改用所选目录中的现有数据；当前目录不复制也不删除，会作为「旧数据目录」保留。该切换可通过再次更改位置回退，但回退前需要先删除旧数据目录。
- **恢复默认位置**：先校验默认位置；空目录按迁移处理（`复制并重启`），已是可识别数据目录则按使用已有目录处理（`使用并重启`）。确认文案与上述两种一致。
- **删除旧数据目录**：确认框标题 `删除旧数据目录？`，确认按钮 `永久删除`，消息 `将永久删除“<旧目录路径>”及其中的全部数据。当前目录不受影响，此操作无法撤销。` 删除不可撤销；删除中断时旧目录说明变为「等待继续删除」，按钮变为 `继续删除`，并在后续启动继续删除。删除完成前不能更改位置。
- 迁移只覆盖空目录：目标非空且不是可识别数据目录时，选择阶段即报错，不进入确认框。

## 术语

界面使用「存储」「数据位置」「当前目录」「默认位置」「旧数据目录」，与 [`../glossary.md`](../glossary.md) 的用户可见用词要求一致。

发现的内部术语泄漏（不属于本批术语替换，按现状记录）：

- 注释文案 `Electron 缓存和可重新生成的 Qwen TTS 运行文件不会移动。` 向用户暴露 `Electron` 与 `Qwen TTS`。
- 错误与对话框文案使用产品名「曹二听说101 数据目录」，不再出现内部代号 `LS101`。

分组描述中的 `API 密钥` 已是术语表的规范用词，不再计为泄漏。

## 产物

- 更改位置或恢复默认位置后：应用在新目录读写数据，原目录成为「旧数据目录」。
- 删除旧数据目录后：旧数据目录行消失，两个位置按钮恢复可用。
- 本页不产生业务对象，也不展示数据目录的内容。
