# 评分工作区 · UI-SR-02

- 路由：`/submissions/grading`、`/submissions/:submissionId/grade`
- 入口：作答记录列表（UI-SR-01）→ 行内或批量「开始评分 / 继续评分 / 进入结算」
- 对象：一次评分会话中的作答记录、评分单元、评分结果、AI 评分运行记录

## 布局

专注式界面，不显示一级导航。两条路由渲染同一套界面：`/submissions/grading` 以查询参数 `submissionId`（可重复）传入本次会话的作答；`/submissions/:submissionId/grade` 只带单条作答且跳过评分方式选择，直接进入人工评分。

1. **预检**：整屏居中显示 `正在准备评分...`。若本次会话的作答全部已完成评分，则直接重定向到评分结算页（替换当前历史记录）；预检失败显示错误面板。
2. **评分方式选择**（仅 `/submissions/grading` 且未预设方式）：页头含返回按钮、eyebrow「开始评分会话」与标题「选择评分方式」；主区是两张并排的方式卡片。
3. **人工评分页**：64 像素页头（左「暂停并返回」，中作答人身份，右进度）+ 两栏工作区。工作区左栏为「评分材料」、右栏为「人工评分」，两栏各自是「58 像素面板标题 + 可滚动内容区」，左栏下限 420 像素、右栏约为左栏的 0.82 倍。
4. **AI 评分会话页**：页头（左「暂停并返回」，中 eyebrow「AI 评分会话」与标题「<份数> 份作答 · <评分单元数> 个评分单元」）+ 按阶段切换的主区（模型配置、执行、决策、抽查、保存）。
5. **AI 审查页**：与人工评分页相同的两栏结构，页头中为「AI 评分审查」与评分单元名称，右栏为「AI 评分结果」。

客观题评分单元在会话开始时已由系统自动判定完成，不计入人工或 AI 的待办，但计入总评分单元数。

## 文案

**预检与方式选择**

- 预检中：`正在准备评分...`
- 预检失败：告警图标 + 具体原因（无原因时 `无法准备评分`）+ 按钮 `返回作答记录`
- 方式选择页：eyebrow `开始评分会话`；标题 `选择评分方式`；返回按钮 `返回作答记录`
- 人工评分卡片：`人工评分` / `逐个评分单元查看作答并填写分数与评语`
- AI 评分卡片：`AI 评分` / `先完成整场评分，再选择完成、全部审查或抽查`

**人工评分**

- 页头：`暂停并返回`；身份 `<姓名>` 与 `<考生号> · <试卷>`；进度 `第 <当前份>/<总份数> 份 · 评分单元 <当前单元>/<总单元数>`
- 左栏「评分材料」面板标题：`第 <题号> 题` 与评分单元名称；区块标题依次为 `题目`、各辅助输入的名称、`评分标准`
- 右栏「人工评分」面板标题：`人工评分` 与 `满分 <满分>`；区块标题 `学生答案`
- 表单标签：`分数`（后跟 `/ <满分>`）、`评语`；提示 `提交后不可修改`；按钮 `提交本题` / `正在提交`
- 校验错误：`请输入分数`
- 空/等待状态：`正在准备批改...`；未指定作答时 `未指定需要评分的作答记录。`
- 文本答案无内容时显示 `未作答`；录音答案显示时长（`<秒数> 秒` 或 `<分>:<秒>`）
- 录音无法播放：`录音无法播放，请导出作答包后检查音频文件。`

**AI 评分会话**

- 页头：`暂停并返回`；eyebrow `AI 评分会话`；标题 `<份数> 份作答 · <评分单元数> 个评分单元`
- 准备中：`正在准备评分会话...`
- 模型字段：`语音识别模型`、`文本评分模型`；无可用模型时下拉项 `没有已启用模型`，加载时 `正在读取模型...`，失败时 `模型加载失败`
- 未选齐模型时点击开始：`请选择语音识别模型和文本模型`
- 执行中：`正在执行 AI 评分` 或（有失败时）`部分题目评分失败`；进度 `<已处理>/<总数>`；失败项逐条显示 `<评分单元名称>：<原因>`；按钮 `重试失败题目`
- 决策：`AI 评分已完成`；按钮 `完成`、`全部审查`、`抽查`
- 抽查规则：`整场题目数`、`按评分单元分组`；分组行显示组名与 `<题数> 题`；按钮 `开始抽查`
- 保存中：`正在保存评分结果...`

**AI 审查**

- 页头：`AI 评分审查` 与评分单元名称；进度 `<当前题>/<总题数>`
- 左栏「题目」面板标题：`题目` 与评分单元名称；区块标题依次为 `题目`、各辅助输入的名称、`评分标准`
- 右栏「AI 评分结果」面板标题：`AI 评分结果` 与 `满分 <满分>`；区块标题 `学生答案`、`语音识别与发音纠正`
- 语音结果：`参考文本：<参考文本>`（存在时）、`识别文本：<识别文本>`，识别为空时 `未识别到清晰内容`
- 表单标签：`分数`（后跟 `/ <满分>`）、`评语`；提示 `确认后不可修改`；按钮 `确认本题`
- 校验错误：`分数必须在 0 到 <满分> 之间且最多三位小数`

**通用错误**

失败提示按原因取作答记录模块的统一错误文案（见 [`UI-SR-01`](./UI-SR-01.md)），例如 `该评分单元已经提交，不能再次修改。`、`该作答已经完成全部评分单元，不能继续提交评分。`、`所选作答尚未完成全部评分，不能结算。`。

## 状态与恢复

- **预检**：加载所选作答的评分工作区。全部已完成评分时直接重定向到评分结算；任一所选作答不存在或读取失败时进入错误面板，只能返回作答记录。
- **评分方式**：仅在批量入口且未预设方式时出现；选择后本次会话固定一种方式，页面不提供途中改用另一种方式的入口。
- **人工评分**：从第一个未评分单元开始，逐题提交。提交成功后进入下一单元；该作答全部单元完成后自动切到下一条作答，最后一条完成后进入评分结算。作答页停留期间表单内容不写盘。
- **人工评分校验**：分数为空时停留在本题并显示 `请输入分数`；分数范围由输入控件约束，提交失败时显示模块错误文案。
- **AI 模型加载**：读取可用模型期间显示 `正在准备评分会话...`；失败时错误写入页内提示区，可用模型为空时无法开始。
- **AI 执行**：逐题保存运行记录（处理中、成功或失败）。某一题失败不中断其他题目；存在失败题时停留在执行阶段，只能「重试失败题目」。「重试」会跳过已成功且所选语音识别与文本模型都相同的题目，只重跑其余题目。
- **AI 决策**：全部题目成功后才出现「完成 / 全部审查 / 抽查」。
- **抽查**：题数按分组分别取 0 到该组题数之间的整数，超出范围会被截断；未抽中的题目直接采用 AI 结果，抽中的题目进入审查；抽中 0 题时直接进入评分结算。抽查结果由随机数决定，同一输入不保证复现同一批题目。
- **AI 审查**：逐题显示 AI 结果并允许改分与改评语；确认后保存最终结果并进入下一题，最后一题确认后进入评分结算。审查后的结果仍记为 AI 评分结果。
- **中断与返回**：人工页「暂停并返回」回到未结算列表，已提交的评分单元保留；AI 会话页「暂停并返回」回到作答记录。离开页面会中止仍在进行的 AI 请求，未完成或失败的题目可在下次会话继续。
- **录音回放失败**：在对应答案下方显示 `录音无法播放，请导出作答包后检查音频文件。`，不影响其他题目。

## 有损操作

- **提交本题（人工）**：提交后不可修改，是评分单元级不可逆操作。页面在按钮旁固定提示 `提交后不可修改`。
- **确认本题（AI 审查）**：确认后不可修改，页面固定提示 `确认后不可修改`。确认只覆盖该题的最终分数与评语，不改写原始作答内容。
- **完成（AI）**：不审查即采用全部 AI 结果，直接进入结算；一旦结算，需回到作答记录执行「重新评分」才能重来。
- 本屏不删除作答记录、评分结果或结算批次；重置与删除只在 [`UI-SR-01`](./UI-SR-01.md) 提供。

## 术语

`作答记录`、`评分单元`、`评分结果`、`评分会话`、`人工评分`、`AI 评分`、`审查`、`抽查`，与 [`../glossary.md`](../glossary.md) 一致。
抽查规则的分段按钮已迁移为 `按评分单元分组`，本屏不再出现 `Schema` 等内部术语。

## 产物

- 人工评分或 AI 评分产生逐评分单元的评分结果；AI 会话另保存所选模型、识别文本、发音纠正、评分提示词、模型原始响应与失败信息。
- 全部单元完成后进入 [`UI-SR-03`](./UI-SR-03.md)。
- 「暂停并返回」保留已提交的评分进度，作答记录回到未结算列表继续显示「评分中」或「可结算」。
