# 题型草稿编辑器 · UI-IF-03

- 路由：`/interfaces/drafts/:draftId`
- 入口：题型库列表（`UI-IF-01`）「草稿」视图 → 新建题型或点击草稿行；题型详情（`UI-IF-02`）→ 题型定义 → 复制为草稿
- 对象：题型草稿

## 布局

专注式编辑器（`InterfaceDraftEditorPage.module.css`），不显示一级导航；顶部工具栏 62px，下方为可调宽的左右分栏：

1. 工具栏：左侧返回按钮 + 草稿名称与状态；右侧「保存」「发布」。
2. 左栏 `aria-label="题型内容"`：`基本信息`（名称、描述）与 `提示词`（生成要求）两个表单区，可滚动。
3. 右栏 `aria-label="字段结构"`：头部显示节点计数与当前添加目标，以及「添加字段」「添加字段组」；下方再分为字段树与属性面板两栏，可调宽。

左/右主分栏可拖动调整宽度（默认 390px，左栏最小 280px、右栏最小 410px）；字段树与属性面板之间同样可调宽（默认 220px）。两处分隔条的辅助标签分别为 `调整题型内容与字段编辑区宽度`、`调整字段树与属性面板宽度`。

## 文案

- 工具栏：草稿名（未命名时 `未命名题型`）、状态 `有未保存修改` 或 `草稿`；按钮 `保存`、`发布`
- 左栏小节：`基本信息`（`名称`、`描述`）、`提示词`（`生成要求`）
- 占位文案：名称 `例如：上海高考听说`；描述 `简要说明这个题型的用途`；生成要求 `描述 AI 应该如何生成这一题型的内容`
- 右栏头部：`字段结构`；计数 `<节点数> 个节点 · 添加到：<目标路径>`；目标为根层时显示 `根级`
- 字段树空状态：`添加第一个字段或字段组`
- 字段树节点：类型标签 `组` / `text` / `image`；文本字段显示变量名，图片字段显示 `<变量名>.inst / .img`
- 属性面板：`节点配置`、当前路径（以 ` / ` 连接）、`字段标识`、`类型`（`文本` / `图片`）、`变量名`、`描述`、`示例`；字段组提示 `选中此字段组后，新字段会添加到组内。`
- 占位文案：变量名 `例如：questionText`；描述 `告诉 AI 这个字段包含什么`；示例 `给出一个符合要求的示例值`
- 未选中节点：`选择一个节点编辑字段配置`
- 字段标识就地错误：`字段标识不能为空、包含点号或带有首尾空格。`、`同一层级已经存在这个字段标识。`
- 发布校验提示：标题 `发布前需要修正以下内容`；条目为 `<字段路径>：<校验说明>`，无路径时为纯说明。校验说明包括 `题型 ID 无效`、`题型名称不能为空`、`提示词不能为空`、`至少需要一个字段`、`字段组中至少需要一个字段`、`字段顺序无效`、`字段标识不能为空、包含点号或带有首尾空格`、`变量名不能为空`、`变量名只能包含字母、数字、下划线或连字符`、`字段描述不能为空`、`示例值不能为空`、`变量名不能重复`
- 发布确认框：标题 `发布当前题型草稿？`；正文 `发布后会生成不可直接修改的稳定题型，当前草稿仍会保留。`；确认按钮 `发布题型`
- 删除字段组确认框：标题 `删除字段组“<名称>”？`；正文 `字段组中的所有子字段也会一并从当前草稿中删除。`；确认按钮 `删除字段组`
- 未保存离开确认框：标题 `放弃未保存的修改？`；正文 `离开后，本次尚未保存的修改会丢失。`；确认按钮 `放弃修改`
- 保存成功提示：`草稿已保存`；发布成功提示：`题型已发布`
- 加载中：`正在加载草稿...`；草稿不存在：`草稿不存在`

## 状态与恢复

- **加载中**：读取草稿完成前只显示 `正在加载草稿...`。
- **加载失败 / 草稿不存在**：错误写入 `role="alert"`；草稿数据为空时主编辑区显示 `草稿不存在`，「保存」「发布」保持禁用。
- **编辑器内操作失败**：保存或发布失败时错误写入左栏 `role="alert"`，草稿与选中路径保持不变。
- **发布校验失败**：先保存草稿，再执行发布校验；失败时不清空草稿、不导航，在「题型内容」区域显示 `role="alert"` 校验清单与每个错误对应的可点击条目。
- **字段标识冲突**：就地显示错误并保留用户输入，不静默改写字段树。
- **未保存离开**：存在未保存修改时，返回、导航与关闭窗口都会先弹「放弃未保存的修改？」确认；「取消」留在编辑器并保留修改，「放弃修改」放弃修改后继续导航。发布成功后放行本次导航。
- **字段组折叠**：只影响字段树显示，不删除节点，也不影响保存内容。

## 有损操作

- **删除叶子字段**：选中叶子字段后点「删除节点」立即从当前草稿移除；未保存前可通过放弃修改整体回退。
- **删除非空字段组**：不可逆地连同全部子字段移除。必须经过 `ConfirmModal` 二次确认，确认文案明确子字段一并删除；「取消」不改变字段树。删除空字段组不弹确认。
- **发布**：不删除草稿，产生一个不可直接修改的稳定题型；原草稿保留在草稿视图。
- **放弃未保存修改**：放弃后重新打开草稿只显示上次保存的内容。

## 术语

界面使用「题型」「题组」「草稿」「字段」「字段组」「变量名」「生成要求」「发布」，与 [`../glossary.md`](../glossary.md) 一致。
内部术语泄漏：发布校验文案 `题型 ID 无效` 暴露代码术语 `ID`，术语表没有对应条目。本规格按 v0.4.1 实际文案记录；同类界面用词冲突的登记与处置方式见 [`../open-questions.md`](../open-questions.md)。

## 产物

- 「保存」写回草稿；「发布」从草稿产生稳定题型并进入 `UI-IF-02`（题型详情），草稿仍保留在 `UI-IF-01` 的草稿视图。
- 「返回草稿列表」回到 `UI-IF-01` 的 `/interfaces?view=drafts`。
