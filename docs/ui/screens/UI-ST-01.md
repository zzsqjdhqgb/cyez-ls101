# 设置总览 · UI-ST-01

- 路由：`/settings`
- 入口：底部导航「设置」
- 对象：无业务对象；本页是按分组列出已注册的设置页面

## 布局

单页标准布局：

1. 页头：标题「设置」，无操作按钮。
2. 分组：每个分组是一个 `section`，带分组标题（`h2`）和该组设置项列表。
3. 设置项：整行按钮，左侧图标，中间标题与可选描述，右侧箭头。

分组与设置项都来自设置页注册表（`register-settings.ts`），不是硬编码列表：

- 分组按 `group.order` 升序，设置项按 `order` 升序，未声明 `order` 时按注册顺序。
- v0.4.1 注册结果：`通用` 组包含 `外观`、`存储`、`许可`、`关于`；`AI` 组包含 `AI 引擎`。

## 控件清单

| 名称 | 类型 | 默认 / 加载 / 禁用 / 错误 | 触发结果 | 快捷键 |
| --- | --- | --- | --- | --- |
| 外观 | 行按钮 | 始终可用 | 导航 `/settings/appearance` | 无 |
| 存储 | 行按钮 | 始终可用 | 导航 `/settings/storage` | 无 |
| 许可 | 行按钮 | 始终可用 | 导航 `/settings/license` | 无 |
| 关于 | 行按钮 | 始终可用 | 导航 `/settings/about` | 无 |
| AI 引擎 | 行按钮 | 始终可用 | 导航 `/settings/ai-router` | 无 |

本页没有写入、删除或提交操作，也没有加载与错误状态：注册表是同步数据。

## 文案

- 页头标题：`设置`
- 分组标题：`通用`、`AI`
- 设置项标题与描述（当前版本）：

| 设置项 | 描述 |
| --- | --- |
| `外观` | 调整应用主题和动态效果 |
| `存储` | 查看和更改软件数据的保存位置 |
| `许可` | 管理软件激活状态 |
| `关于` | 查看应用版本、项目团队和软件许可 |
| `AI 引擎` | 配置 AI Provider 和各类可用模型 |

- 空状态：`暂无设置项`（仅在没有任何已注册设置页时出现）

## 状态与恢复

- 无加载、无失败、无禁用状态；列表同步渲染。
- 设置项描述为空时不渲染描述行。
- 没有已注册设置页时显示空状态；v0.4.1 正常构建下不会出现。

## 有损操作

无。本页只做导航。

## 术语

界面使用「设置」「外观」「存储」「许可」「关于」「AI 引擎」，与 [`../glossary.md`](../glossary.md) 一致。
本页不出现内部术语。

## 产物

- 点击设置项进入对应的明细页（`UI-ST-02`…`UI-ST-06`），明细页共用路由 `/settings/:settingsPageId/*`。
- 本页不产生或修改任何业务对象。
