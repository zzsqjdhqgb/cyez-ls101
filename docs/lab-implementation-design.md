状态：设计草案，等待整体审核；本清单完成表示设计产物已完成，不表示功能已经实现。

功能范围以[机房练习软件设计](./lab-deployment-design.md)为准。本文组织后续实现设计；字段与 HTTP 响应由 [API 设计](./lab-server-api-design.md)和 OpenAPI 文件共同约束。发现冲突时先修正文档，不在实现中另行猜测。

## 1. 本轮待办

- [x] 服务端存储：数据模型、唯一约束、收卷事务、删除、备份和故障恢复。
- [x] 学生端状态：准入、前台练习、提交队列、重启恢复、任务执行和换绑。
- [x] 桌面边界：构建入口、宿主接口、HTTPS 信任、播放器复用和后台服务生命周期。
- [x] 接口与教师流程：完整 OpenAPI、字段来源、错误行为、操作确认和页面流程。
- [x] 交叉检查：接口覆盖、引用解析、schema 校验、示例与边界场景核对。

## 3. 实现顺序与验收门槛

1. 建立独立学生、教师、服务端构建入口，验证许可检查、本机后台服务生命周期和 HTTPS 绑定；产物不携带主软件的 AI 与编辑模块。
2. 实现服务初始化、入网、设备配置、状态及心跳，验证重启、迟到请求和修订号冲突。
3. 实现一份试卷的上传、完整缓存、开始许可、播放器、本地落盘、收卷与回执；先完成单机房基本流程。
4. 加入故障注入：每个文件与数据库提交边界中止进程，验证恢复；覆盖维护切换和上传竞争、网络响应丢失。
5. 实现教师列表、批量导出删除和学生异常历史，再实现部署测试、清理、备份与安装升级。
6. 运行对应单元与契约测试（包含 `scripts/__tests__/lab-design-contract.test.js`）；renderer、preload 或 main 变更使用 `xvfb-run -a yarn test:smoke`，相关 Electron 专项及跨模块完整集成测试。Windows 安装、服务托管、文件持久化和音频仍需目标系统验收。

本轮不安装运行依赖，不修改应用代码，不创建数据库，不改变主软件现有业务。设计中的包名、接口名是拟定实现名称。
