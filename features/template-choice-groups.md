# Template 选择题组作用域

## 背景

Template 的选择题题目可以定义在内嵌函数中，但选择题 Collector 当前属于
Frame。函数中的题目可以被调用方的 Collector 收集，函数中的 ChoiceView 却不能引用
调用方的 Collector；函数一旦定义自己的 Collector，又不能和外部 Collector 组合。

听力模板需要把“前 10 题”“后 10 题”和“全卷”封装成可组合函数，因此选择题组必须
成为一种可传递的编译期上下文，而不是函数内部私有的 Collector。

## 核心模型

一个全局 Template 仍然只有一份 ChoiceCollector。Collector 的页面题数序列就是全局
选择题组的形状，例如：

```text
[2, 3, 4]
```

表示三页，分别有 2、3、4 道题。编译完成后 Player 仍然只接收这一份全局
`choiceMeta`；选择题组变量不会成为运行时答案或第二份题组。

函数输入可以声明三种选择题组形状：

```text
question              单题，不限制所在页面
range [2, 3, 4]       连续页面，页面题数必须匹配
all [2, 3, 4]         完整选择题组，形状必须完全匹配
```

函数调用方传入的是一个选择题组绑定：

- `question` 绑定一个真实的全局题目；
- `range` 绑定源选择题组中的连续页面，并显式指定起始页；
- `all` 绑定源选择题组的全部页面。

范围匹配只比较连续页面的题数形状。全局形状为 `[2, 3, 4, 2, 3, 4]` 时，形状为
`[2, 3, 4]` 的函数既可以绑定前三页，也可以绑定后三页；调用方必须明确选择起始
页，不能由编译器在重复匹配时猜测。

## 作用域换算

选择题组绑定在函数调用边界建立局部坐标系。函数内部的 ChoiceView 只使用当前函数
收到的局部选择题组和局部页/题坐标，编译器沿调用链把坐标换算回全局题目索引：

```text
全局 [1, 2, 3, 4, 5]
  -> 函数收到范围 [2, 3, 4]
    -> 函数内部第一页第二题
      -> 全局第二页第二题
```

函数收到的 `all` 绑定使用恒等映射；`range` 绑定增加页面偏移；`question` 绑定
直接解析为一个全局题目。函数还可以把自己的局部选择题组再次传给子函数，子函数
的范围和题目坐标先相对父函数换算，再继续换算到全局。

最终所有 `focus`、`range` 和 `free` ChoiceView 都只能解析为同一个全局
`choiceMeta.pages/questions`。函数之间不会产生嵌套 Collector，也不会产生局部
ChoiceMeta。

## 校验规则

编译前必须拒绝以下情况：

- 函数输入声明的形状与调用方绑定的实际形状不一致；
- `range` 超出源选择题组，或起始页不是整数；
- `all` 绑定的源形状不完全相等；
- `question` 指向不存在的全局题目；
- 函数内部引用了未声明的选择题组变量；
- ChoiceView 的局部页/题坐标超出当前选择题组；
- 全局 Collector 仍然不是唯一 Collector，或全局 Collector 没有收集到题目。

普通 Template 直接使用全局 ChoiceView 的现有语义继续保留；只有声明了选择题组
变量的函数才使用局部坐标换算。

## 实现边界

选择题组是编译期结构值，不是 `string`、`number` 或运行期 `choice`。函数资源身份
必须包含输入形状声明；调用节点保存选择题组绑定；Compiler 的作用域同时保存普通
静态值和当前选择题组映射。Renderer 和 Player 不需要认识局部选择题组，只消费最终
的全局 `choiceMeta`。
